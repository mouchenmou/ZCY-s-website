第1题：V带是放在一个开口槽里面的，因此是开口传动。

第2题：传动比约等于 $\frac{d_2}{d_1}$，==传动比增大可以理解成 $d_2$ 增大 $d_1$ 减小。 $d_2$ 增大 $d_1$ 减小==，脑补一下就能想象出来小带轮包角减小，大带轮包角增大。（把小带轮包角和大带轮包角分别想象成带跟这两个轮子的切线，应该很相近的）

第3题：补天视频有讲，中心距无穷大的时候大带轮和小带轮的包角都无限接近于180度。中心距越小，小带轮包角越小，大带轮包角越大。

第4题：V带的两个侧面都承受摩擦力，而平带只有一个地面承受，因此V带能承受更大的摩擦，因此能接受更大的速度，传动比更大。

第5题：记忆方法：V带轮能承受更大的摩擦，说明摩擦消耗掉热量更多，这就导致能量损失更大，因此V带传动比平带传动效率更低。

第6题：==V带比平带厚很多，因此重力比平带大很多，如果V带太长的话，中间那一段受重力的影响很大。而平带很薄，重力很小，长一点也没关系

第7题：V带的带轮主要受压，铸铁抗压能力好

第8题：带长增加，那么单位时间内，带跟两个带轮的接触时间少了，弯曲次数少，寿命更长了，因此死的没那么早，活着的时候能传递的功率更多。

第9题：跟第8题一样，小带轮的直径增加同样能够减小弯曲应力，弯曲应力小了寿命也更长，活的时间更长，能传递的功率更多。

第10题：补天视频中说过，小带轮越小，弯曲应力越大，脑补一下也能想象出来。因此要限制小带轮，不能让它太小。

第11题：补天视频讲过，产生弹性滑动就是因为紧边和松边拉力大小不一样。

第12题：随着直径的增加，如果一直用实心的话，材料会浪费很多，因此直径增大到一定程度就不再用实心的了。

第13题：补天视频讲过，最大有效拉力跟小带轮的包角有关。

第14题：那么多题目中都是通过减小弯曲应力来减小疲劳强度，可想而知肯定选疲劳强度。

第15题：增大小轮的直径，能够使弯曲应力减小，这样子的话，带子就能活的更长一点。假设，原本需要100根带子来平均承受这么多弯曲应力，现在弯曲应力减小了一半，那么只需要50个带子就能够平均下来。

第16题：带的长度减小了的话，单位时间内循环次数增加，带在单位时间内承受弯曲应力的时间更长，这就会导致寿命减小。

第17题：如果传动承载能力比普通V带还小的话，那窄V带设计出来的意义何在？

第18题：补天视频中讲过，同步带传动是唯一一个用啮合来传动的带传动。
