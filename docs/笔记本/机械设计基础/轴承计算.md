### 正装
![](附件/Pasted%20image%2020260626231734.png)

![](附件/Pasted%20image%2020260626223956.png)

令载荷系数为 $K_p$ 

$$当量动载荷F_p=K_p(X \times F_R+Y\times F_A)$$
记忆方法：题目中都是先给出径向力 $F_R$ 之后，我们才求得轴向力 $F_A$ 的，就像一次函数中也是通过X求得Y的，因此将 X 与 $F_R$ 配对，Y 与 $F_A$ 配对。

放松的轴承，就只受自己的派生轴承力，想象一下一个滑块被一根绳子拉着在光滑的曲线上运动，那就只受这个绳子的拉力是一个道理。

压紧的轴承，受到除了自己的派生轴承力以外的别的力的合力，想象一下一个被一只手压在墙上的物体...

### 反装：跟正装反一下：

![](附件/Pasted%20image%2020260627003513.png)
像这道题，$F_{A1}=450N方向向左, \ F_A=350N方向向左\ ,F_{A2}=900N方向向右$

由于$F_{A1}+F_A=800N<F_{A2}=900N$，这里是反装，并不会被压紧，只会被拉紧。由于$F_{A1}+F_A=800N<F_{A2}=900N$。说明有向右被拉着的趋势，所以1被拉紧了，2是放松的。

因此1的轴向力 $A_1=F_{A2}-F_A=550N$，2的轴向力 $A_2=F_{A2}=900N$。

## 记忆方法：
正装的时候，两个派生轴向力都是指向内部的，因此只会产生压力。而反装的时候两个派生力都是指向外部的，因此只会产生拉力。
