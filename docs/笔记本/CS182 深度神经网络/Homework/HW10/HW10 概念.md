## 1. Attention中的一些概念

### 1.1 attention weights

#### 1.1.1 我自己的解释
Attention weight 就是每个 token 对其它 token 权重，对于用 softmax 来求解的 attention，attention weight 就是 $softmax(\frac{QK^T}{\sqrt{d_k}})$

#### 1.1.1.2 AI的解释
输出写成 value 的线性组合时，每个 value 前面的系数。定义不要求它是概率。

$$\text{输出} = \sum_i c_i\,\mathbf{v}_i$$

- softmax attention：系数是 $\text{softmax}(\mathbf{q}^\top K^\top/\sqrt{d})$，恰好是 softmax 的输出。
- ridge-attention：第 $i$ 个系数是 $\beta_i = \mathbf{q}^\top(\lambda I + A^\top A)^{-1}\mathbf{k}_i$，这就是 (g) 的答案。
- 找法：把输出写成（某个行向量）乘 $V$，乘在 $V$ 左边的那个行向量就是权重。
- 把所有 query 放在一起，权重是一个 $n\times n$ 矩阵，第 $t$ 行是第 $t$ 个 query 的权重。

### 1.2 attention output

attention output 就是执行完整个 attention 之后的输出，对于用 softmax 来求解的 attention，attention weight 就是 $softmax(\frac{QK^T}{\sqrt{d_k}})V$

## 2. 数计算代价

一条规则就够：

$$(p\times m)\ \text{矩阵} \times (m\times r)\ \text{矩阵} \quad\Rightarrow\quad p\cdot m\cdot r\ \text{次乘法}$$

结果有 $p\times r$ 个元素，每个元素是一行乘一列，要 $m$ 次乘法。

题目只给了三条，其余形状要自己按上面的规则数：

- $d\times d$ 矩阵求逆：$d^3$
- 两个 $d\times d$ 矩阵相乘：$d^3$
- $d\times d$ 矩阵乘 $d$ 维向量：$d^2$

### (c) 的逐步计数

| 步骤 | 形状 | 代价 |
| --- | --- | --- |
| $A^\top A = \sum_i \mathbf{k}_i\mathbf{k}_i^\top$ | $n$ 个外积，每个 $(d\times 1)(1\times d)$ | $nd^2$ |
| 对 $M$ 求逆 | $d\times d$ | $d^3$ |
| $A^\top B = \sum_i \mathbf{k}_i\mathbf{v}_i^\top$ | $n$ 个外积 | $nd^2$ |
| $M^{-1}(A^\top B)$ | $(d\times d)(d\times d)$ | $d^3$ |
| $n$ 个 query 各算 $W_*^\top\mathbf{q}$ | $n$ 次 $(d\times d)(d\times 1)$ | $nd^2$ |

题目给了 $d < n$，所以 $d^3 < nd^2$，总量是 $O(nd^2)$。

### 要点

- 一个外积 $\mathbf{k}_i\mathbf{k}_i^\top$ 有 $d^2$ 个元素，每个元素一次乘法，所以是 $d^2$。
- 矩阵乘法满足结合律，先乘哪两个可以自己选。先算 $M^{-1}A^\top$ 再乘 $B$，也是 $O(nd^2)$。
- $W_*$ 只算一次，所有 query 共用，所以关于 $n$ 是线性的。
- 固定做法：写出每个矩阵的形状，每次乘法按 $p\cdot m\cdot r$ 数，求逆按题目给的数，加起来留下最大的一项。
