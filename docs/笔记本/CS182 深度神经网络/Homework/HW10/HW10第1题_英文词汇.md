## 2. 数学读法

| 写法 | 读法 |
| --- | --- |
| $d^2$ | d squared |
| $d^3$ | d cubed |
| $d^4$ | d to the fourth |
| $d^n$ | d to the n |
| $O(nd^2)$ | O of n d squared |
| $M^{-1}$ | M inverse |
| $A^\top$ | A transpose |
| $\sqrt{d}$ | square root of d |
| linear / quadratic / cubic | 一次的 / 二次的 / 三次的 |

例句：softmax attention is **quadratic in** the context length = 代价关于上下文长度是平方级的。

## 3. 容易读错的句子

**(g) 里有两个不同的 outputs**

- "the outputs **of the softmax**"：softmax 这个函数的输出，即 $\text{softmax}(QK^\top/\sqrt{d})$，不含 $V$。
- "the **attention outputs**"：attention 这一层的输出，即 $\text{softmax}(QK^\top/\sqrt{d})\,V$。

**(g) 第一句是倒装**

"consider important the ability to …" 的正常语序是 "consider [the ability to …] important"，意思是"认为……这个能力很重要"。

**(g) 第三句逐块对应**

| 原文 | 指什么 |
| --- | --- |
| They | attention weights |
| the attention outputs at this position | 这个位置上 attention 层的输出 |
| the values being fed in at this and other positions | 本位置和其他位置输入进来的 value，即 $\mathbf{v}_1,\dots,\mathbf{v}_n$ |
| the exact amounts | 每个 value 具体占多少，即系数 |

整句：attention weights 告诉你，这个位置的输出是各个 value 的线性组合，其中每个 value 具体占多少。

**(c) 括号里的 Note**

"the keys are playing the role of the $A$ matrix … each query is like the $\mathbf{x}$ we are testing on"：key 对应带下标的 $\mathbf{x}_i$（在 $A$ 里），query 对应不带下标的新 $\mathbf{x}$。题目用同一个字母 $\mathbf{x}$ 写了两种东西。

## 4. 读题方法

- **先读粗体句。** 粗体才是要做的事，其余都是背景。
- **看选项符号。** 方框 □ 是多选，圆圈 ○ 是单选。
- **先圈出 causal 还是 non-causal。** 它决定每个位置能用多少配对，复杂度可以差一个 $n$。
- **"$O(n^2)$" 可能省略了 $d$。** 讨论上下文长度时常把 $d$ 当常数，意思是"关于 $n$ 是平方级"。(f) 里要避免的量严格写是 $O(n^2d^2)$。
- **带引号的词是类比。** 比如 "training data" 带引号，不是真的在训练。
- **定义可能要自己拼。** ridge-attention 的公式题目没写，只给了公式 (1) 和 (c) 括号里的替换说明。
