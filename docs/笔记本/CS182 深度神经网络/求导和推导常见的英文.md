## 1. 求导和推导

| 英文                                        | 词性                | 中文含义      |
| ----------------------------------------- | ----------------- | --------- |
| **Derive**                                | 动词                | 推导出、得出    |
| **Derivation**                            | 名词                | 推导过程      |
| **Derived**                               | 形容词 / 过去分词        | 推导得到的、派生的 |
| **Derivative**                            | 名词                | 导数        |
| **Differentiate**                         | 动词                | 求导、微分     |
| **Differentiation**                       | 名词                | 求导、微分运算   |
| **Partial Derivative**                    | 名词                | 偏导数       |
| **Partial Differentiation**               | 名词                | 偏微分、求偏导   |
| **Gradient**                              | 名词                | 梯度        |
| **Differentiable**                        | 形容词               | 可微的、可求导的  |
| 英文表达                                      | 中文意思              |           |
| Derive the above expression.              | 推导上面的表达式。         |           |
| Show your derivation.                     | 展示你的推导过程。         |           |
| Derive the gradient of the loss function. | 推导损失函数的梯度。        |           |
| Differentiate with respect to \(x\).      | 对 \(x\) 求导。       |           |

| Set the gradient to zero.                 | 令梯度为零。            |           |

| Prove that the solution is optimal.       | 证明该解是最优的。         |           |
| Show that the matrix is invertible.       | 证明这个矩阵可逆。         |           |
| Verify the optimality conditions.         | 验证最优性条件。          |           |

## 2. 向量和矩阵

## 2.1 最基础的数学对象

|英文|中文|定义|
|---|---|---|
|**Scalar**|标量|一个数，如 \(3\)|
|**Vector**|向量|一组有顺序的数，如 \((1,2,3)\)|
|**Matrix**|矩阵|由行和列组成的二维数组|
|**Tensor**|张量|在深度学习中泛指任意维度的数组|
|**Row Vector**|行向量|\(1\times n\)|
|**Column Vector**|列向量|\(n\times1\)|
|**Dimension**|维度|向量的特征数，或张量的轴|
|**Shape**|形状|各轴的长度，如 \((32,784)\)|
|**Rank**|秩|矩阵中线性无关的行或列的最大数量|
|**Batch Size**|批量大小|一次处理多少个样本|

## 2.2 **CS182 最常见的矩阵类型**

| 英文                            | 中文      | 关键性质                                 |
| ----------------------------- | ------- | ------------------------------------ |
| Square Matrix                 | 方阵      | $m\times m$                          |
| Rectangular Matrix            | 长方矩阵    | 行数和列数不同                              |
| Identity Matrix               | 单位矩阵    | $I$                                  |
| Zero Matrix                   | 零矩阵     | 所有元素为 0                              |
| Diagonal Matrix               | 对角矩阵    | 非对角线元素为 0                            |
| Symmetric Matrix              | 对称矩阵    | $A^\top=A$                           |
| **Orthogonal Matrix**         | 正交矩阵    | $Q^\top Q=QQ^\top=I$                 |
| **Column-Orthonormal Matrix** | 列正交归一矩阵 | $U^\top U=I$                         |
| Invertible Matrix             | 可逆矩阵    | 存在 $A^{-1}$                          |
| Singular Matrix               | 奇异矩阵    | 方阵不可逆                                |
| Full-Rank Matrix              | 满秩矩阵    | \(\operatorname{rank}(A)=\min(m,n)\) |
| Low-Rank Matrix               | 低秩矩阵    | 秩远小于矩阵维度                             |
| Sparse Matrix                 | 稀疏矩阵    | 大部分元素为 0                             |
| Dense Matrix                  | 稠密矩阵    | 大部分元素非零                              |
| Positive Definite Matrix      | 正定矩阵    | \(x^\top Ax>0\)，对所有非零 \(x\)          |
| Positive Semidefinite Matrix  | 半正定矩阵   | \(x^\top Ax\geq0\)                   |
| Projection Matrix             | 投影矩阵    | \(P^2=P\)                            |
| Covariance Matrix             | 协方差矩阵   | 描述特征方差和协方差                           |
| Adjacency Matrix              | 邻接矩阵    | 描述图中节点连接关系                           |
| Stochastic Matrix             | 随机矩阵    | 元素非负，行和或列和为 1                        |
| DPLR Matrix                   | 对角加低秩矩阵 | \(A=D+UV^\top\)                      |

### 2.4 各种 Norm

| 英文              | 中文           | 公式                           |
| --------------- | ------------ | ---------------------------- |
| L1 Norm         | L1 范数        | \(\sum_i\|x_i\|\)            |
| L2 Norm         | L2 范数        | \(\sqrt{\sum_i x_i^2}\)      |
| Squared L2 Norm | L2 范数平方      | \(\sum_i x_i^2\)             |
| Infinity Norm   | 无穷范数         | \(\max_i\|x_i\|\)            |
| Frobenius Norm  | Frobenius 范数 | \(\sqrt{\sum_{ij}A_{ij}^2}\) |
| Spectral Norm   | 谱范数          | 最大奇异值                        |
