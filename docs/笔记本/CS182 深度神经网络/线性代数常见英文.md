## 0. 先统一符号

- **Scalar（标量）**常写作 $a,\lambda,x$；**Vector（向量）**常写作 $\mathbf{x},\mathbf{u}$；**Matrix（矩阵）**常写作 $A,W,X$；**Tensor（张量）**常写作 $\mathcal T$。这些只是惯例，不是强制规定。
- $\mathbb R^{m\times n}$：$m$ 行、$n$ 列的实数矩阵集合；$\mathbb R^d$：$d$ 维实向量集合。
- **Shape（形状）**：各个轴的长度，如 $(32,784)$；**Dimension / Axis（维度 / 轴）**：语境不同，可能指向量的特征数，也可能指张量的某个轴。
- **Rank（秩）**对于矩阵指线性无关行/列的最大数目；**Order（阶数）**对于张量指轴的数量。不要把它们混淆。

## 1. 最基本的数据对象

| 英文 | 中文 | 定义与例子 |
|---|---|---|
| **Scalar** | 标量 | 单个数，例如 $3.2$、$\lambda=0.1$；0 个轴（0D tensor） |
| **Vector** | 向量 | 有顺序的一组数，例如 $\mathbf x=[1,2,3]^\top\in\mathbb R^3$；1 个轴 |
| **Column Vector** | 列向量 | $d\times1$ 的矩阵表示，如 $[1,2,3]^\top$ |
| **Row Vector** | 行向量 | $1\times d$ 的矩阵表示，如 $[1,2,3]$ |
| **Matrix** | 矩阵 | 有行和列的数据，例如 $A\in\mathbb R^{3\times2}$；2 个轴 |
| **Tensor** | 张量 | 机器学习中泛指可有任意数量轴的数组；如图片批次 $(B,C,H,W)$ 是 4D tensor |
| **Feature** | 特征 | 描述一个样本的数值分量；例：784 个像素可看作 784 个特征 |
| **Feature Dimension** | 特征维度 | 每个样本有多少个特征，例 $d=784$ |
| **Batch** | 批次 | 一次送进网络的一组样本 |
| **Batch Size** | 批量大小 | 一批样本的个数 $B$；例 Tensor shape 为 $(32,784)$ |
| **Shape** | 形状 | 每个轴的长度，如 `x.shape == (32, 784)` |
| **Element / Entry** | 元素 | 矩阵 $A_{ij}$ 表示第 $i$ 行第 $j$ 列的数 |

> 注意：Tensor 不一定是“比矩阵更神秘的新运算”。在 PyTorch 中，它主要是支持自动求导、GPU 计算等功能的多维数组。

## 2. 常见矩阵类型（考试词汇重点）

| 英文 | 中文 | 定义 / 判别条件 |
|---|---|---|
| **Square Matrix** | 方阵 | 行列数相等，$A\in\mathbb R^{m\times m}$ |
| **Rectangular Matrix** | 长方矩阵 | 行列数不同，例 $A\in\mathbb R^{3\times5}$ |
| **Identity Matrix** | 单位矩阵 | $I_m=\operatorname{diag}(1,\ldots,1)$，满足 $AI=IA=A$（维度合适时） |
| **Zero Matrix** | 零矩阵 | 所有元素均为 0，记作 $0$ |
| **Diagonal Matrix** | 对角矩阵 | 非对角线元素全是 0，例如 $\operatorname{diag}(2,5,1)$ |
| **Scalar Matrix** | 数量矩阵 | $cI$，对角线全是同一个数 $c$ |
| **Symmetric Matrix** | 对称矩阵 | 必须是方阵，$A^\top=A$ |
| **Skew-Symmetric Matrix** | 反对称矩阵 | $A^\top=-A$（实矩阵对角元素必为 0） |
| **Orthogonal Matrix** | 正交矩阵 | 实方阵 $Q$ 满足 $Q^\top Q=QQ^\top=I$，因此 $Q^{-1}=Q^\top$ |
| **Column-Orthonormal Matrix** | 列正交归一矩阵 | 可为长方矩阵 $U\in\mathbb R^{m\times k}$，$U^\top U=I_k$，不一定满足 $UU^\top=I_m$ |
| **Unitary Matrix** | 酉矩阵 | 复数版本的正交矩阵，$Q^*Q=I$，$Q^*$ 表示共轭转置 |
| **Upper Triangular Matrix** | 上三角矩阵 | 主对角线下面都是 0 |
| **Lower Triangular Matrix** | 下三角矩阵 | 主对角线上面都是 0 |
| **Invertible / Nonsingular Matrix** | 可逆 / 非奇异矩阵 | 方阵，存在 $A^{-1}$，使 $AA^{-1}=I$；等价于满秩 |
| **Singular Matrix** | 奇异矩阵 | 方阵但不可逆，$\det(A)=0$ |
| **Full-Rank Matrix** | 满秩矩阵 | $\operatorname{rank}(A)=\min(m,n)$；长方矩阵也可满秩 |
| **Rank-Deficient Matrix** | 秩亏矩阵 | $\operatorname{rank}(A)<\min(m,n)$ |
| **Low-Rank Matrix** | 低秩矩阵 | 秩远小于维度；例 $AB$，$A\in\mathbb R^{m\times k}$、$B\in\mathbb R^{k\times n}$，则 $\operatorname{rank}(AB)\le k$ |
| **Sparse Matrix** | 稀疏矩阵 | 大部分元素是 0；GNN 的图邻接矩阵常很稀疏 |
| **Dense Matrix** | 稠密矩阵 | 大部分元素非零 |
| **Positive Semidefinite (PSD) Matrix** | 半正定矩阵 | 实对称 $A$ 满足所有 $x$ 都有 $x^\top Ax\ge0$；特征值均非负 |
| **Positive Definite (PD) Matrix** | 正定矩阵 | 实对称 $A$ 满足所有非零 $x$ 都有 $x^\top Ax>0$；特征值均正 |
| **Projection Matrix** | 投影矩阵 | 满足 $P^2=P$；若是**正交投影**还满足 $P^\top=P$ |
| **Gram Matrix** | Gram 矩阵 | 由两两内积构成，例如 $X^\top X$；对称、半正定 |
| **Covariance Matrix** | 协方差矩阵 | 描述各特征方差及共同变化，零中心数据可写作 $\Sigma=\tfrac1nXX^\top$（使用 $1/n$ 的约定） |
| **Adjacency Matrix** | 邻接矩阵 | 图中节点之间是否相连，如 $A_{ij}=1$ 表示有边（具体定义视图而定） |
| **Stochastic Matrix** | 随机矩阵/概率转移矩阵 | 元素非负，且每行之和为 1（row-stochastic）或每列之和为 1（column-stochastic） |
| **Block-Diagonal Matrix** | 分块对角矩阵 | 对角线由小矩阵块组成，其余块均为 0 |
| **Diagonal-Plus-Low-Rank (DPLR) Matrix** | 对角加低秩矩阵 | 形如 $A=D+UV^\top$；HW08 Q5(f) 的 $I+pp^\top$ 是特例 |

### 正交（Orthogonal）和正交归一（Orthonormal）的区别

- **Orthogonal（正交）**：两个向量的内积为 0，即 $u^\top v=0$。
- **Normalized / Unit Vector（单位化 / 单位向量）**：向量长度等于 1，即 $\|u\|_2=1$。
- **Orthonormal（正交归一）**：既相互正交，每个向量又长度为 1。

例如 $u=(1,0)^\top$ 与 $v=(0,1)^\top$ 正交归一；但 $(2,0)^\top$ 与 $(0,3)^\top$ 只有正交，没有归一。

**不能混淆：**

$$
Q\in\mathbb R^{m\times m},\quad Q^\top Q=I_m \quad\text{（正交方阵）}
$$

$$
U_k\in\mathbb R^{m\times k},\quad U_k^\top U_k=I_k,\quad k<m \quad\text{（列正交归一）}
$$

在第二种情况下，$U_kU_k^\top$ 通常**不是** $I_m$，而是秩为 $k$ 的正交投影矩阵。

## 3. 常见向量和矩阵运算

| 英文 | 中文 | 公式 / 说明 |
|---|---|---|
| **Transpose** | 转置 | $A^\top$，行列交换，$(A^\top)_{ij}=A_{ji}$ |
| **Conjugate Transpose** | 共轭转置 | $A^*$ 或 $A^H$；复数先取共轭再转置，实矩阵时等于转置 |
| **Dot Product / Inner Product** | 点积 / 内积 | $u^\top v=\sum_i u_iv_i$，结果为标量；需要维度兼容 |
| **Outer Product** | 外积 | $uv^\top$，列向量 $u\in\mathbb R^m$、$v\in\mathbb R^n$ 产生 $m\times n$ 矩阵，若均非零则秩为 1 |
| **Matrix Multiplication** | 矩阵乘法 | $A_{m\times k}B_{k\times n}$ 得 $m\times n$；一般 $AB\ne BA$ |
| **Element-wise Multiplication / Hadamard Product** | 逐元素乘法 | $A\odot B$，同位置元素相乘；区别于 $AB$ |
| **Matrix Power** | 矩阵幂 | $A^2=AA$、$A^3=AAA$，仅方阵；不是逐元素平方 |
| **Inverse** | 逆矩阵 | 对可逆方阵，$AA^{-1}=I$ |
| **Pseudoinverse / Moore–Penrose Inverse** | 伪逆 | $A^+$；适用于不可逆或非方阵情形，常用于最小二乘 |
| **Trace** | 迹 | $\operatorname{tr}(A)=\sum_i A_{ii}$，方阵对角元素之和 |
| **Determinant** | 行列式 | $\det(A)$；仅方阵，等于 0 表示不可逆 |
| **Rank** | 矩阵的秩 | 最大线性无关列数，也等于最大线性无关行数 |
| **Range / Column Space** | 值域 / 列空间 | 矩阵列向量张成的所有向量 |
| **Null Space / Kernel** | 零空间 / 核 | 所有满足 $Ax=0$ 的向量的集合；和卷积核 *kernel* 是不同用法 |
| **Basis** | 基 | 一组线性无关且张成某空间的向量 |
| **Subspace** | 子空间 | 对向量加法和数乘封闭的空间 |
| **Linear Combination** | 线性组合 | $c_1u_1+\cdots+c_ku_k$ |
| **Linear Independence** | 线性无关 | 只有 $c_1=\cdots=c_k=0$ 时线性组合才等于 0 |
| **Projection** | 投影 | 投到某个子空间；若 $U_k^\top U_k=I$，则 $P=U_kU_k^\top$ |
| **Diagonalization** | 对角化 | $A=P\Lambda P^{-1}$（适用于可对角化方阵） |
| **Broadcasting** | 广播 | NumPy/PyTorch 按兼容轴规则扩展形状，不是矩阵乘法 |
| **Concatenate / Stack** | 拼接 / 堆叠 | `torch.cat` 沿现有轴拼接；`torch.stack` 引入新轴 |

### 一个维度检查例子

$$
X\in\mathbb R^{m\times n},\qquad W\in\mathbb R^{k\times m}
$$

则 $WX\in\mathbb R^{k\times n}$，因为内侧两个 $m$ 必须相同。

如果使用 PyTorch 的批量数据表示，常把**样本放在行上**：$X_{\rm batch}\in\mathbb R^{B\times m}$，那么 `nn.Linear(m,k)` 内部计算可写为 $Y=X_{\rm batch}W^\top+b$，输出 $B\times k$。这与理论中按列排列样本的 $WX$ 并不矛盾，只是数据摆放方式不同。

## 4. Eigenvalue、Singular Value、SVD、PCA

### 4.1 Eigenvalue / Eigenvector（特征值 / 特征向量）

对**方阵** $A$：

$$
Av=\lambda v,\qquad v\ne0
$$

- **Eigenvalue**：$\lambda$，特征值。
- **Eigenvector**：$v$，特征向量。
- 若 $A$ 为实对称矩阵，其特征值为实数，可以选一组正交归一特征向量。

### 4.2 Singular Value / Singular Vector（奇异值 / 奇异向量）

对**任意长方矩阵** $X\in\mathbb R^{m\times n}$：

$$
X=U\Sigma V^\top
$$

- **Singular Values（奇异值）**：$\Sigma$ 对角线上的非负数 $s_1\ge s_2\ge\cdots\ge0$。
- **Left Singular Vectors（左奇异向量）**：$U$ 的列向量，属于 $\mathbb R^m$。
- **Right Singular Vectors（右奇异向量）**：$V$ 的列向量，属于 $\mathbb R^n$。
- $s_i^2$ 是 $X^\top X$ 的特征值（非零时也等于 $XX^\top$ 的对应特征值）。

**Full SVD（完整 SVD）**：

$$
U\in\mathbb R^{m\times m},\quad\Sigma\in\mathbb R^{m\times n},\quad V\in\mathbb R^{n\times n}
$$

**Compact / Thin SVD（紧致 / 经济型 SVD）**，秩为 $r$ 时可写：

$$
U_r\in\mathbb R^{m\times r},\quad\Sigma_r\in\mathbb R^{r\times r},\quad V_r\in\mathbb R^{n\times r}
$$

### 4.3 Principal Component / PCA（主成分 / 主成分分析）

对零中心数据 $X\in\mathbb R^{m\times n}$，定义 $U_k=[u_1,\ldots,u_k]\in\mathbb R^{m\times k}$ 为按奇异值从大到小排序后的前 $k$ 个**左**奇异向量：

$$
U_k^\top U_k=I_k
$$

**$U_k$ 的全部 $k$ 个奇异值都等于 1**，因为 $U_k^\top U_k=I_k$。但这**不是**说原数据 $X$ 的奇异值等于 1。

**Projector（正交投影矩阵）**：

$$
P_k=U_kU_k^\top\in\mathbb R^{m\times m},\quad P_k^2=P_k,\quad P_k^\top=P_k
$$

**Truncated SVD（截断 SVD）/ 最佳秩 $k$ 重建**：

$$
X_k=P_kX=U_kU_k^\top X=U_k\Sigma_kV_k^\top
$$

这里没有“丢掉 $V_k$”：它仍然包含在 $U_k^\top X=\Sigma_kV_k^\top$ 里。关键是 $U_k$ 由**与最大 $k$ 个奇异值对应**的左奇异向量组成，而不是任取 $k$ 列。

**为什么不直接用 $D_k=\operatorname{diag}(1,\ldots,1,0,\ldots,0)$ 乘 $X$？**

$D_k$ 只有在 $X$ 已经用左奇异向量坐标表示时才截断正确；原始坐标中正确的投影为 $UD_kU^\top=U_kU_k^\top$。

### 4.4 Covariance（协方差）

对于零中心、按列排列的样本：

$$
\Sigma_{\rm cov}=\frac1nXX^\top
$$

它是 $m\times m$ 对称半正定矩阵；其特征向量是数据的主成分方向，其特征值表示沿这些方向的方差。若 $X$ 的奇异值为 $s_i$，则对应特征值是 $s_i^2/n$。

> **HW08 Q3 特别注意**：题目把 $\tfrac1nXX^\top$ 的特征值记作 $\sigma_i^2$，因此此处 $\sigma_i=s_i(X)/\sqrt n$。不要把两套符号混在一起。

## 5. Norm（范数）与距离

| 英文 | 中文 | 数学定义 / 意义 |
|---|---|---|
| **L1 Norm** | L1 范数 | $\|x\|_1=\sum_i|x_i|$ |
| **L2 / Euclidean Norm** | L2 / 欧几里得范数 | $\|x\|_2=\sqrt{\sum_i x_i^2}$ |
| **Squared L2 Norm** | L2 范数平方 | $\|x\|_2^2=\sum_i x_i^2$；不要再开根号 |
| **L-infinity Norm** | 无穷范数 | $\|x\|_\infty=\max_i|x_i|$ |
| **Frobenius Norm** | Frobenius 范数 | $\|A\|_F=\sqrt{\sum_{ij}A_{ij}^2}=\sqrt{\sum_i s_i(A)^2}$ |
| **Squared Frobenius Norm** | Frobenius 范数平方 | $\|A\|_F^2=\sum_{ij}A_{ij}^2=\sum_i s_i(A)^2$ |
| **Spectral Norm / Matrix 2-Norm** | 谱范数 / 矩阵诱导二范数 | $\|A\|_2=s_{\max}(A)$，**不是** Frobenius 范数 |
| **Distance** | 距离 | 例如欧氏距离 $\|x-y\|_2$ |

**特别容易错：**

$$
\|A\|_F=\sqrt{\sum_i s_i^2},\qquad\|A\|_F^2=\sum_i s_i^2
$$

- **Orthonormal columns** $U_k$ 满足每个奇异值为 1，所以 $\|U_k\|_F^2=k$。
- **L2 Regularization / Weight Decay** 经常出现 $\lambda\|W\|_F^2$。
- **MSE（Mean Squared Error）**使用平均平方误差；题目把损失写成 $\tfrac1n\|X-\hat X\|_F^2$ 时，平均的是样本，而 PyTorch 默认 `MSELoss()` 平均的是所有元素。

## 7. 最容易混淆的 10 个点（考前复习）

1. **Scalar vs Vector vs Matrix vs Tensor**：0D / 1D / 2D / 任意维数组；Tensor 的 *order* 不是矩阵的 *rank*。
2. **Orthogonal vs Orthonormal**：前者要求内积为 0，后者还要求每个向量范数为 1。
3. **Orthogonal Matrix vs Column-Orthonormal Matrix**：前者必须方阵；后者可为 $m\times k$ 长方矩阵。
4. **$U$ vs $U_k$**：完整 SVD 中 $U$ 是 $m\times m$；前 $k$ 列构成 $U_k\in\mathbb R^{m\times k}$。
5. **Eigenvalue vs Singular Value**：特征值可为负（甚至复数）；奇异值总是非负。不是每个长方矩阵都有特征值。
6. **$\|A\|_F$ vs $\|A\|_F^2$**：前者带根号，后者才等于奇异值平方和。
7. **$AB$ vs $A\odot B$**：前者矩阵乘法，后者逐元素乘法。
8. **$U_k^\top U_k$ vs $U_kU_k^\top$**：前者等于 $I_k$，后者是 $m\times m$ 的投影矩阵，不一定是 $I_m$。
9. **PCA 保留最大奇异值，不是直接保留原始数据前 $k$ 个坐标**：需要用主成分方向投影。
10. **Matrix Rank vs Tensor Shape**：秩看线性无关性；形状只说每个轴多长。

## 8. 一页背诵版：常见英语表达

| 英文句子 | 中文 |
|---|---|
| Let $A$ be a square matrix. | 设 $A$ 为一个方阵。 |
| Assume that $A$ is invertible. | 假设 $A$ 可逆。 |
| The columns are orthonormal. | 这些列向量两两正交且各自长度为 1。 |
| $A$ is positive semidefinite. | $A$ 是半正定矩阵。 |
| The matrix is rank deficient. | 这个矩阵秩亏。 |
| Consider a low-rank approximation. | 考虑一个低秩近似。 |
| The singular values are sorted in descending order. | 奇异值按降序排列。 |
| The corresponding singular values are reciprocals. | 对应的奇异值互为倒数。 |
| Project $x$ onto the subspace spanned by $U_k$. | 将 $x$ 投影到由 $U_k$ 各列张成的子空间。 |
| Take the transpose of $X$. | 对 $X$ 转置。 |
| Compute the Frobenius norm squared. | 计算 Frobenius 范数的平方。 |
