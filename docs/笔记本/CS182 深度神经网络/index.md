# CS182 深度神经网络

Berkeley CS182: Deep Neural Networks 是一门专门讲深度学习的课程。相比 CS231n 更偏计算机视觉应用的路线，CS182 更强调深度神经网络背后的数学基础、优化方法、表示学习以及现代架构。

我把这门课当作 CS231n 之后继续往深处补的一门课：一方面补线性代数、概率论、优化这些底层工具，另一方面也希望理解 neural networks 为什么能学、怎么训练、以及这些方法如何连接到 robot learning 等更实际的研究问题。
