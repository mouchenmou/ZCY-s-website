2802. Definition
2803. A binary search tree is a binary tree. It may be empty. If it is not empty, it satisfies the following properties: (1) Every node has a key which is an integer, and the keys are distinct. (2) The keys in a nonempty left subtree must be smaller than the key in the root. (3) The keys in a nonempty right subtree must be larger than the key in the root. (4) The left and right subtrees are also binary search trees.
