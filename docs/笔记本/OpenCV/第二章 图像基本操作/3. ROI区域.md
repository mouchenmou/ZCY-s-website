
ROI 是 **Region of Interest** 的缩写，意思是感兴趣区域。

在图像处理中，ROI 就是从整张图片里面截取出我们真正关心的一小块区域。

### 3.1 截取部分图像数据

先读取一张图片。

```python
img = cv2.imread('cat.jpg')
```

图像在 OpenCV 里面本质上是一个数组，所以可以直接用数组切片截取局部区域。

```python
cat = img[0:50, 0:200]
cv_show('cat', cat)
```

这里的切片规则是：

```python
img[y1:y2, x1:x2]
```

- 第一维是高度方向，也就是第几行，对应 `y`。
- 第二维是宽度方向，也就是第几列，对应 `x`。
- `0:50` 表示取第 0 行到第 49 行。
- `0:200` 表示取第 0 列到第 199 列。

所以：

```python
img[0:50, 0:200]
```

表示截取图片左上角高度为 50、宽度为 200 的区域。

需要注意，数组切片是左闭右开的，也就是包含起点，不包含终点。

### 3.2 颜色通道提取

OpenCV 读取彩色图像时，通道顺序是 BGR。

可以用 `cv2.split()` 把三个颜色通道拆开。

```python
b, g, r = cv2.split(img)
```

拆开之后，`b`、`g`、`r` 都是二维数组。

```python
b.shape
```

因为单独一个颜色通道只有亮度信息，所以它没有第三维的通道数。

原图的形状一般是：

```python
img.shape
```

结果类似：

```python
(height, width, 3)
```

单独一个通道的形状是：

```python
(height, width)
```

### 3.3 颜色通道合并

拆开的通道也可以用 `cv2.merge()` 合并回去。

```python
img = cv2.merge((b, g, r))
img.shape
```

这里合并时仍然要按照 OpenCV 的 BGR 顺序。

### 3.4 只保留某一个颜色通道

如果想观察某一个颜色通道，可以把其他通道设置成 0。

只保留 R 通道：

```python
cur_img = img.copy()
cur_img[:, :, 0] = 0
cur_img[:, :, 1] = 0
cv_show('R', cur_img)
```

解释一下：

- `cur_img[:, :, 0]` 表示 B 通道。
- `cur_img[:, :, 1]` 表示 G 通道。
- `cur_img[:, :, 2]` 表示 R 通道。

因为 OpenCV 的通道顺序是 BGR，所以把第 0 个和第 1 个通道变成 0，就只剩下 R 通道。

只保留 G 通道：

```python
cur_img = img.copy()
cur_img[:, :, 0] = 0
cur_img[:, :, 2] = 0
cv_show('G', cur_img)
```

只保留 B 通道：

```python
cur_img = img.copy()
cur_img[:, :, 1] = 0
cur_img[:, :, 2] = 0
cv_show('B', cur_img)
```

这里使用 `img.copy()` 是为了复制一份新的图片数据。如果直接在原图 `img` 上修改，原图本身也会被改掉。
