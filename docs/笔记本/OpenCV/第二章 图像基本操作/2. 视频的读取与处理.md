

视频本质上可以看成一帧一帧连续的图片。OpenCV 中用 `cv2.VideoCapture()` 读取视频。

- 如果参数是数字，例如 `0`、`1`，表示读取摄像头设备。
- 如果参数是视频文件路径，例如 `'test.mp4'`，表示读取本地视频文件。

```python
vc = cv2.VideoCapture('test.mp4')
```

读取前可以先判断视频是否成功打开。

```python
if vc.isOpened():
    open, frame = vc.read()
else:
    open = False
```

`read()` 会返回两个值：

- `ret`：是否成功读取到当前帧。
- `frame`：当前读到的图像帧，本质上就是一张图片。

循环读取视频时，每次读取一帧，然后对这一帧做处理。

```python
while open:
    ret, frame = vc.read()
    if frame is None:
        break
    if ret == True:
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        cv2.imshow('result', gray)
        if cv2.waitKey(10) & 0xFF == 27:
            break

vc.release()
cv2.destroyAllWindows()
```

这里的关键点：

- `cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)`：把当前帧从 BGR 彩色图转成灰度图。
- `cv2.waitKey(10)`：每一帧之间等待 10 ms，控制播放速度。
- `0xFF == 27`：`27` 是键盘上 `Esc` 的 ASCII 码，表示按下 `Esc` 退出。
- `vc.release()`：释放视频资源。
- `cv2.destroyAllWindows()`：关闭所有 OpenCV 创建的窗口。

如果要读取摄像头，只需要把文件路径换成摄像头编号。

```python
vc = cv2.VideoCapture(0)
```

常用的视频属性也可以通过 `get()` 读取。

```python
width = vc.get(cv2.CAP_PROP_FRAME_WIDTH)
height = vc.get(cv2.CAP_PROP_FRAME_HEIGHT)
fps = vc.get(cv2.CAP_PROP_FPS)
frame_count = vc.get(cv2.CAP_PROP_FRAME_COUNT)
```

- `CAP_PROP_FRAME_WIDTH`：视频帧宽度。
- `CAP_PROP_FRAME_HEIGHT`：视频帧高度。
- `CAP_PROP_FPS`：视频帧率。
- `CAP_PROP_FRAME_COUNT`：视频总帧数。
