## 1. 图像基本操作

### 1.1 图像读取

OpenCV 读取图片用的是 `cv2.imread()`。

```python
import cv2
import matplotlib.pyplot as plt
import numpy as np

%matplotlib inline

img = cv2.imread('cat.jpg')
```

OpenCV 默认按照 **BGR** 的通道顺序读取图片，而不是常见的 RGB。

```python
img.shape
```

`shape` 的结果一般是 `(height, width, channels)`：

- `height`：图像高度，也就是有多少行像素。
- `width`：图像宽度，也就是有多少列像素。
- `channels`：颜色通道数，彩色图像通常是 3。

### 1.2 图像的显示

waitKey是设置毫秒级的等待时间的。如果是0的话，会一直显示，但是按键盘上的任意键都能终止显示。

```python
cv2.imshow('image', img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```

`cv2.imshow()` 适合在本地窗口中显示图像；如果是在 Jupyter Notebook 中，更常用 `matplotlib` 显示。

```python
plt.imshow(img)
```

因为 `matplotlib` 默认按照 RGB 显示，而 OpenCV 读进来是 BGR，所以直接显示颜色会不对。可以先做颜色空间转换。

```python
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
plt.imshow(img_rgb)
```

### 1.3 图像保存

保存图片使用 `cv2.imwrite()`。

```python
cv2.imwrite('cat_save.jpg', img)
```
