你这里是把 Frozen（冻结） 理解成了“模型停止工作”。但在 Deep Learning 里面，冻结模型并不是不让模型运行，而是不让模型更新参数。

这是两个完全不同的概念。

## 1. Frozen 到底是什么意思？

假设我们有一个训练好的 World Model：

$$ y=f_\theta(x)$$

其中：

- \(x\)：输入，例如机器人观察到的视频。
- ($f_\theta$)：World Model。
- ($\theta$)：模型的参数（Weights）。
- ($y$)：模型输出，例如预测的未来场景。
    

在 Deep Learning 中，模型主要有两个过程：

① Forward Pass（前向传播）

$$ x\xrightarrow{f_\theta}y$$

把输入送进模型，计算输出。

② Backward Pass（反向传播）

通过 Loss 和 Gradient 更新模型参数：

$$\theta\leftarrow\theta-\eta\nabla_\theta L$$

而 Freeze（冻结）只是让模型的参数 \(\theta\) 保持不变，不再通过训练更新。

## 1. Planning-based Approach（基于规划的方法）

**核心思想：冻结预训练 World Model，在推理阶段搜索并评估候选动作。**

**工作流程：**

1. 机器人获取当前 Observation 和 Task Instruction。
2. 规划算法生成多组 Candidate Action Sequences。
3. 使用 Frozen World Model 预测执行不同动作序列后的未来状态（Imagined Rollouts）。
4. 根据任务目标评估这些预测结果，选择最优的动作序列。
5. 执行动作，并根据新的 Observation 重新规划（如 MPC）。

**特点：**

- World Model 的参数保持冻结，但仍然可以进行 Forward Pass，预测未来。
- 在推理阶段显式搜索、比较不同候选动作及其预测结果。
- 不需要为了执行规划而微调整个 World Model。

**主要缺点：**

每次决策都可能需要大量 Imagined Rollouts，导致推理成本高、控制频率受限。此外，任务目标通常通过 Goal Image 或人工设计的 Cost Function 表达。

## 2. World-Action Model（WAM）

**核心思想：Fine-tune 预训练的大型 World Model，让它具备机器人动作预测能力。**

**工作流程：**

1. 使用已经预训练的 World Model，例如视频生成模型或其他视觉基础模型。
2. 收集机器人示范数据（Robot Demonstrations），包括 Observation、Instruction、Action 和 Future Observation。
3. 使用这些数据 Fine-tune 大型 World Model Backbone，并训练动作预测部分。
4. 使模型能够结合未来预测与 Action Prediction，直接生成机器人动作。
    

**特点：**

- 不一定使用 V-JEPA，可以采用其他预训练 World Model。
- 在论文讨论的这类 WAM 中，需要更新大型 Backbone 的参数。
- 可以联合学习 Future Prediction 和 Action Prediction。
- 推理时通常不需要像 Planning-based Approach 一样显式搜索大量候选动作。

**主要缺点：**

Fine-tuning 大型 World Model 需要大量机器人数据和计算资源，训练成本较高。

## 3. RoboActualizer（本文方法）

**核心思想：冻结预训练 World Model，训练一个轻量级 Actualizer，学习 Task-conditioned Future Prediction 和 Action Generation。**

**工作流程：**

1. 使用预训练的 **Frozen V-JEPA 2.1 Encoder** 处理最近几帧 Observation，得到当前 Latent Representation：

    $$  
    z_t=g_\phi(x_{t-\Delta})  
    $$
    
2. V-JEPA 的参数保持冻结，不参与下游训练。作者认为其 Latent Representation 已经包含丰富的场景动态信息和潜在未来信息。
    
3. 将当前 Latent、Task Instruction 和机器人自身状态输入 Actualizer。
    
4. Actualizer 包含两个轻量级 DiT Experts，通过 Flow Matching 联合训练：
    
    - **Latent Expert：** 根据任务指令预测 Task-conditioned Future Latent。
        
    - **Action Expert：** 预测实现该任务的 Robot Action Chunk。
        
5. 训练时，使用同一个 Frozen V-JEPA Encoder 对示范数据中的未来视频进行编码，得到 Future Latent Ground Truth，监督 Latent Expert；同时使用真实机器人动作监督 Action Expert。
    
6. 推理时，V-JEPA Encoder 对当前视频执行一次 Forward Pass，Actualizer 通过迭代去噪生成动作，不需要在线搜索大量候选未来。实际部署时省去显式的 Future Latent 输出。
    

**特点：**

- V-JEPA 2.1 Encoder：约 300M 参数，Frozen。
    
- Actualizer：约 60M 可训练参数。
    
- 训练时可以提前计算并缓存视频 Latents，降低计算成本。
    
- 不需要重新训练大型 World Model Backbone。
    
- 仍然需要 Robot Demonstrations 来学习任务条件下的 Future Latent Prediction 和 Action Generation。
    

**主要局限：**

- 依赖预训练 World Model 提供的视觉动态表示。
    
- 仍需要机器人示范数据，并非 Zero-shot。
    
- 作者认为 World Model 的 Representation Space 已包含多种潜在未来，但这不意味着它已经显式生成所有未来，也不意味着它包含现成的 Robot Action Latent Space。

## 5. Key Difference: Explicit Search vs. Learned Selection

**Planning-based Approach：**

在推理阶段实际生成或评估多个候选方案，使用 World Model 预测结果，再通过规划算法选择最优动作。

**WAM：**

通过 Fine-tuning 大型 World Model，让模型学习根据 Observation 和 Instruction 生成动作，同时利用 Future Prediction 进行训练。

**RoboActualizer：**

作者认为，World Model 的预训练 Representation Space 已经隐含丰富的未来动态信息。因此，不必重新学习整个场景动态，只需训练一个小型 Actualizer，学习根据 Task Instruction 预测相应的 Future Latent，并生成实现任务的动作。

需要注意：RoboActualizer 中的 **Selection 是学习得到的隐式选择，不是从 World Model 显式生成的一组未来中逐个比较、执行 Argmax。**

## 2. Related works

### 2.1
# Video World Models：两条技术路线及其区别

> [!abstract] 核心概念  
> Video World Model（视频世界模型）的目标是学习真实世界随时间变化的规律，从而理解或预测未来场景。
> 
> 论文 _One from Infinity_ 的 Section 2 将相关工作分为两条主要技术路线：
> 
> 1. **Pixel-space Prediction**：在像素空间预测未来。
>     
> 2. **Representation-space Prediction**：在特征表示空间（Latent Space）预测未来。
>     
> 
> 第二条路线又有不同的实现方式，例如 V-JEPA 的视频预测式预训练，以及 DINO-WM / NWM 在冻结视觉特征上额外学习 Dynamics。

## 1. Line 1：Pixel-space Prediction（像素空间预测）

### 1.1 核心思想

直接预测未来的视频画面，即模型最终需要生成未来的 RGB Frames。

假设我们观察到一段小球向右滚动的视频：

$$  
x_1,x_2,x_3  
$$

模型需要预测未来的视频帧：

$$  
\hat x_4,\hat x_5,\ldots  
$$

其中 $x_t$ 是一张 RGB 图像。

例如，输入的视频显示一个球正在向桌子边缘滚动，World Model 需要生成球继续滚动、掉落等可能的未来画面。

**重点：模型预测的是未来画面本身，而不仅仅是某种抽象特征。**

### 1.2 典型架构（概念性示例）

```
Observed Video Frames
         │
         ▼
 Video Generation Model
         │
         ▼
Predicted Future Frames
```

实际模型可以包含多个神经网络模块，例如 Encoder、Diffusion Transformer、Decoder 等。

即使内部使用 Latent 进行计算，只要其任务最终是生成未来 RGB 视频，仍然可以属于这一类视频生成路线。

### 1.3 优点

- 能够直接生成未来场景，预测结果直观、容易可视化。
- 可以作为模拟器，帮助预测场景随时间如何变化。
- 可以在不同条件下生成多种可能的未来。

### 1.4 局限

- 需要处理或重建大量视觉细节。
- 生成视频可能需要较大的计算开销。
- 对机器人控制而言，并非所有像素细节都是必要的。


## 2. Line 2：Representation-space Prediction（特征空间预测）

### 2.1 核心思想

与 Line 1 不同，Line 2 不要求直接生成未来 RGB 图片，而是预测未来场景对应的 **Latent Representation**。

首先使用一个 Encoder：

$$  
z_t=E_\phi(x_t)  
$$

其中：

- $x_t$：当前图像或视频。
- $E_\phi$：视觉编码器。
- $z_t$：视觉特征表示（Visual Features / Latents）。

然后预测未来的 Latent：

$$  
\hat z_{t+1}=F_\theta(z_t)  
$$

如果是动作条件化的 World Model，则可以写成：

$$  
\hat z_{t+1}=F_\theta(z_t,a_t)  
$$

其中 $a_t$ 是动作。

这些公式是典型的简化示例，并不代表所有 Latent World Models 都使用完全相同的预测形式。

### 2.2 为什么要预测 Latent？

假设一个小球正在滚动。

Line 1 需要生成下一帧完整画面，包括小球的位置、颜色、阴影、背景纹理等。

Line 2 则学习预测下一时刻的特征表示，不要求生成全部 RGB 像素。

这些 Latents 是神经网络学习的数值表示，可能包含物体位置、形状、运动和场景关系等信息，但通常不能将某一维直接解释成某个固定的物理量。

**重要：Latent Prediction 并不等于显式预测坐标或速度，而是预测神经网络特征。**

### 2.3 优点

- 不必直接合成完整的像素画面。
    
- 可以在特征空间中建模场景变化。
    
- 预训练表示能够被其他下游任务复用，例如 Robot Control。
    

### 2.4 第二条路线内部的两种做法

论文列举了：

1. V-JEPA：通过视频中被遮挡的时空 Latent Prediction 学习 Representation。
2. DINO-WM / NWM：在 Frozen Visual Features 基础上学习 Dynamics。
    

二者都在 Representation Space 中工作，但构建和训练方式不同。


## 3. Line 2 — Approach A：V-JEPA

### 3.1 核心思想

**通过预测视频中被遮挡的时空 Latents，预训练能够理解视频的视觉表示。**

V-JEPA 的预训练不仅需要识别画面中的物体，还要利用视频的时间关系来预测未观察到的时空特征。

### 3.2 预训练时的结构

V-JEPA 的训练涉及多个神经网络组件，主要包括：

- **Context Encoder**：处理可见视频内容，提取上下文特征。
- **Predictor**：根据可见特征，预测被遮挡区域对应的 Latent。
- **Target Encoder**：为预测目标提供特征表示。
    

简化流程：

```
               Original Video
                     │
           ┌─────────┴─────────┐
           │                   │
           ▼                   ▼
    Visible Context       Target Video
           │                   │
           ▼                   ▼
    Context Encoder       Target Encoder
           │                   │
           ▼                   │
     Context Latents           │
           │                   │
           ▼                   ▼
        Predictor       Target Latents
           │                   │
           ▼                   │
   Predicted Latents ◄─────────┘
           │
           ▼
       Training Loss
```

实际 JEPA 预训练涉及掩码设计和目标编码器的参数更新机制。上图只解释主要模块之间的关系。

### 3.3 为什么 V-JEPA 能学到 Dynamics？

因为输入是视频，而不是孤立的图片。

例如：

- Frame 1：球在左边。
- Frame 2：球移动到中间。
- Frame 3：球继续向右运动。
    

为了根据上下文预测未观察到的时空 Latent，模型需要利用位置、运动、时间关系等信息。

因此，V-JEPA 的视频表示可以包含有关场景动态的信息。

但需要注意：

**V-JEPA Encoder 学到了 Dynamics-aware Features，不等于单独调用 Encoder 就可以预测任意未来。**

在预训练结构中，Predictor 负责执行 Latent Prediction。

### 3.4 RoboActualizer 怎样使用 V-JEPA？

RoboActualizer 使用冻结的 V-JEPA 2.1 Video Encoder：

$$  
z_t=g_\phi(x_{t-\Delta})  
$$

其中：

- 输入：最近一段时间的视频帧。
    
- 输出：当前场景的 Spatiotemporal Latent Representation。
    
- $\phi$：预训练参数，保持冻结。
    

然后 RoboActualizer 另外训练一个 Actualizer，学习任务条件下的 Future Latent Prediction 和 Action Generation。

**RoboActualizer 不是直接调用原来的 V-JEPA Predictor 来完成机器人动作预测。**


## 4. Line 2 — Approach B：DINO-WM / NWM

### 4.1 核心思想

**使用预训练好的 Visual Encoder 提取特征，并冻结 Encoder；再另外训练 Dynamics Model，学习特征如何随时间或动作发生变化。**

这里和 V-JEPA 最容易混淆的地方是：

并不是先训练一个完整 World Model，再从中挑出 Visual Features 冻结。

而是可以先利用已有的视觉表征模型，再构建一个在该表示空间中预测动态的模型。

### 4.2 什么是 Frozen Visual Features？

假设使用已经预训练好的 DINO Encoder：

$$  
z_t=E_\phi(x_t)  
$$

输入图片 $x_t$，输出 $z_t$。

因为这些特征由视觉编码器提取，所以称为 Visual Features。

Frozen 的意思是 Encoder 参数 $\phi$ 不再更新：

$$  
\phi=\text{constant}  
$$

但不同的输入图片仍然会产生不同的特征：

$$  
E_\phi(x_1)\ne E_\phi(x_2)  
$$

所以 **Frozen Encoder ≠ Frozen Feature Values**。

### 4.3 如何学习 Dynamics？

假设我们有以下数据：

- $x_t$：机器人推方块之前的图像。
    
- $a_t$：机器人向右推动方块的动作。
    
- $x_{t+1}$：推动后的图像。
    

先使用 Frozen Encoder 提取特征：

$$  
z_t=E_\phi(x_t)  
$$

$$  
z_{t+1}=E_\phi(x_{t+1})  
$$

接着训练 Dynamics Model：

$$  
\hat z_{t+1}=F_\theta(z_t,a_t)  
$$

模型尝试根据当前特征和动作预测下一时刻的特征。

可以使用真实下一时刻的 $z_{t+1}$ 作为监督目标。

### 4.4 模型结构

```
        Current Image x_t
                │
                ▼
      Pretrained Visual Encoder
              FROZEN
                │
                ▼
        Visual Features z_t
                │
                │  + Action a_t
                ▼
       Trainable Dynamics Model
                │
                ▼
     Predicted Future Latent
```

因此，一个这样的 World Model 可以由两个主要组件组成：

$$
\text{Frozen Visual Encoder}  
+  
\text{Trainable Dynamics Model}  
$$

**注意：这是这类方法的概念性结构，不表示 DINO-WM 与 NWM 具有完全相同的网络、输入或训练损失。** 论文 Section 2 没有展开二者的具体实现。

### 4.5 与 V-JEPA 最核心的区别

DINO-WM / NWM 这类方法侧重：

**在已有视觉表示上，另外学习状态随时间或动作变化的动态模型。**

V-JEPA 则侧重：

**在大规模视频预训练过程中，利用时空 Latent Prediction 学习具备动态信息的 Representation。**

这里并不是说 V-JEPA 完全不需要 Predictor，也不是说 DINO-WM 的 Frozen Encoder 没有任何运动相关信息。

区别在于它们怎样组织视觉表征学习与动态预测学习。

|维度|Line 1：Pixel-space|Line 2：Representation-space|
|---|---|---|
|预测目标|未来 RGB Frames|未来 Latent Representations|

|是否必须生成 RGB|是，作为主要输出目标|否|
|是否使用 Encoder|可能使用|通常使用|

## 6. Line 2 内部两种做法的比较

|维度|V-JEPA|DINO-WM / NWM 类方法|
|---|---|---|
|核心思路|通过视频预测任务学习时空 Representation|在已有 Visual Features 上学习 Dynamics|
|视觉表征来源|视频预测式预训练|已预训练的视觉特征提取器|
|Dynamics 如何学习|视频时空特征预测预训练|训练额外的动态预测模型|
|Encoder 是否冻结|RoboActualizer 下游使用时冻结|在这种 Dynamics 学习方法中冻结|
|预测目标|Masked Spatiotemporal Latents（预训练阶段）|未来状态对应的 Visual Latents|
|是否一定需要机器人动作作为输入|V-JEPA 视觉预训练不要求机器人动作|取决于模型，动作条件化预测可使用动作|
|与 RoboActualizer 的关系|提供冻结的视频时空表示|是论文讨论的其他 Latent World Models|

### 必须澄清的三个容易混淆的概念

**1. World Model 不一定是一个单独的神经网络。**

它可以由 Encoder、Predictor、Dynamics Model 等不同模块构成。哪些模块需要训练，取决于具体架构和训练阶段。

**2. Visual Features 不是从 World Model 里手动筛选出来的一部分特征。**

Visual Features 通常指 Visual Encoder 输出的 Representation。研究者知道它的来源，因为 Encoder 是模型架构中明确设计的模块，而不是因为每个特征维度都有明确标签。

**3. Latent World Model 不是一定比 Pixel World Model 更懂物理规律。**

两者区别主要是预测空间。一个模型是否理解物体运动、接触、因果和动作影响，还取决于训练数据、目标函数与模型结构。

## 7. 与 RoboActualizer 的联系

RoboActualizer 选择了 Representation-space 这条路线，并采用预训练 V-JEPA 2.1 的视频 Encoder。

其主要流程是：

$$  
\text{Observation History}  
\xrightarrow{\text{Frozen V-JEPA}}  
z_t  
$$

然后：

$$  
(z_t,\ell,s_t)  
\xrightarrow{\text{Actualizer}}  
(\hat z^+,\hat a)  
$$

其中：

- $z_t$：当前视频的 Latent。
    
- $\ell$：Task Instruction。
    
- $s_t$：Robot Proprioceptive State。
    
- $\hat z^+$：预测的任务条件化 Future Latent。
    
- $\hat a$：预测的机器人 Action Chunk。
    

论文的核心假设是：**V-JEPA 通过视频预训练获得的时空表示已经隐含丰富的未来动态信息，因此 Actualizer 不必从零学习全部 Dynamics，而可以专注于任务条件下的未来选择和动作实现。**

但这不代表 V-JEPA 预先生成了一组未来供 Actualizer 显式挑选，也不代表 Actualizer 完全不需要学习未来预测。

---

## 8. 最终总结

- **Line 1：** 预测未来的视频画面（Pixel-space Prediction）。
- **Line 2：** 预测未来的特征表示（Representation-space Prediction）。
- **Line 2 — V-JEPA：** 通过视频时空 Latent Prediction 预训练具有动态信息的视觉表示。
- **Line 2 — DINO-WM / NWM：** 在已有的 Frozen Visual Features 上额外学习 Dynamics Prediction。
- **RoboActualizer：** 冻结预训练 V-JEPA Video Encoder，训练小型 Actualizer，学习任务条件化的未来表示与机器人动作。

> [!important] 一句话理解  
> Pixel-space 与 Latent-space 区分的是**预测什么**；V-JEPA 与 DINO-WM / NWM 这类方法的区别主要是**如何组织视觉表征和动态预测的学习**；RoboActualizer 则研究**如何利用已经预训练好的动态表示生成机器人动作**。
