### 1. 
If we reduce a model’s size or width, its capacity usually decreases, so during training we can use a larger model as a **teacher** and the smaller model as a **student**. The student learns not only from the ground-truth labels, but also from the teacher’s outputs. This is called **knowledge distillation**.

### 2.
This article also taught me that we can combine components from different models into a single multi-task model, so that one shared network can perform multiple tasks. By sharing feature extraction instead of running separate models independently, we can reduce computation, memory usage, and hardware pressure.
