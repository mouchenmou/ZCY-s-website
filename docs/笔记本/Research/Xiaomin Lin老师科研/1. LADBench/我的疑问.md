### 1. 语义理解和 logical reasoning
语义理解就是给你一张图，你能够描述出这幅图在做什么。比如给你一张小孩喂鳄鱼的图片，vlm可以描述出这幅图是小孩在喂鳄鱼，那就是语义理解到位。

**logical reasoning 是一种“根据已有信息和规则，建立关系、进行推断、检查一致性并得出结论”的能力**。比如人类的 logical reasoning 可以包括：

- 已知 A 和 B，推出 C；
- 根据因果关系判断结果；
- 根据物理规律推断某件事能不能发生；
- 判断两个事实是否互相矛盾；
- 根据社会规则或流程判断下一步应该是什么；
- 发现某个场景违反了已有规则。

而这篇 LADBench **并没有测试 logical reasoning 的全部能力**。它只是选了其中一个具体切面：

> **给 VLM 一张图，让它根据现实世界中的物理、生物、社会、程序、因果等知识，发现图里是否存在 logical anomaly。**

---

### 2. reverse reasoning
### 普通 reasoning

你知道规则 / 原因，然后推导结果。

比如：

```
正常规则：
海豚是哺乳动物
        ↓
海豚用肺呼吸
        ↓
不应该有鱼鳃
```

这是：

**rule → conclusion**

---

但 LADBench 给模型的是最终图片。

比如模型直接看到：

> 一个长着鳃的海豚。

它要反过来做：

```
看到：
dolphin with gills
        ↓
想起：
dolphin 应该是什么样
        ↓
比较：
现实中的规则 vs 当前图片
        ↓
发现矛盾
```

也就是说：

> **从已经观察到的场景，反过来判断它是否符合正常世界的因果、物理、社会规则。**

所以作者把它叫 `reverse reasoning`。

严格说，我觉得这里的用词不是特别标准。你在 slide 上都没必要专门讲 `reverse reasoning`，知道作者是什么意思就够了。

### 3. open-ended responses

### Closed-ended question

```
Is there an anomaly?

A. Yes
B. No
```

或者：

```
Which anomaly exists?

A. mailbox
B. dolphin
C. road
D. none
```

答案空间有限。


而 LADBench 不是这样。

模型可能回答：

> “The mailbox is strangely positioned in the middle of the road, creating an unsafe and unrealistic situation.”

也可能说：

> “A mailbox has been placed directly in the roadway.”

也可能：

> “The mailbox should be on the roadside rather than in traffic.”

三个说法文字完全不同，但实际上意思一样。

这就叫：

> **open-ended response**

也就是让模型自由生成自然语言答案，而不是选择题或者固定标签。

### 他们还是在测试 VLM。

所谓 LADBench，其实不是一个会“回答问题的模型”。

它是一整套：

```
Dataset
+
Prompting protocol
+
Scoring method
+
Evaluation pipeline
```

组成的 **benchmark**。

因此整个实验其实是：

```
LADBench
     ↓
给 VLM 输入图片
     ↓
看 VLM 回答什么
     ↓
LADBench 的 grading system 打分
```

## 那为什么额外放 100 张正常图片？

因为原来的 1000+ 张图片有一个问题：

> **每一张都有 anomaly。**

所以如果一个 VLM 很喜欢乱说：

> “There is an anomaly!”

它可能反而得到不错的结果。

因此作者必须检查另一件事：

> **如果图片其实完全正常，模型会不会凭空捏造一个 anomaly？**

这就是这 100 张正常图片的作用。

也就是：

### negative controls

可以理解成“阴性样本”。

# 6. Weighted Accuracy 是什么意思？

这个是整篇论文最重要的数字之一。

作者认为：

> Level 1 自己发现异常，比别人提醒以后才发现更厉害。

所以每张图根据**第一次成功检测的 Level**得到不同分数：

```
Level 1 成功 → 1
Level 2 成功 → 2/3
Level 3 成功 → 1/3
都失败       → 0
```

然后在所有图片上取平均。

这就是：

> **Weighted Accuracy**

# 7. Table 里面 Level 1 / Level 2 / Level 3 accuracy 为什么不是越来越高？

这是你 Table I 最大的理解障碍。

关键就在论文这一句话：

> **Each level considers a sample space limited to the images tested at that level, excluding previous passes.**

意思是：

## Level 1、2、3 根本不是在同一批图片上算 accuracy。

比如假设有：

### 100 张图片

Level 1：

```
100 张都进去
↓
40 张成功
↓
Level 1 accuracy = 40%
```

那么这 40 张：

> **已经退出了。**

不会再进 Level 2。

---

现在 Level 2 只有：

```
剩下的 60 张
```

假设提示之后：

```
30 张成功
```

那么：

Level2 Accuracy=3060=50%Level2\ Accuracy = \frac{30}{60} = 50\%

不是：

70100\frac{70}{100}

---

接下来 Level 3 只剩：

```
30 张
```

而且注意：

> 这 30 张已经属于模型在 Level 1 和 Level 2 **连续两次都没搞定的 hardest cases**。

假设给 category hint 后：

```
9 张成功
```

那么：

Level3 Accuracy=930=30%Level3\ Accuracy = \frac9{30} = 30\%

于是你看到：

```
Level 1   40%
Level 2   50%
Level 3   30%
```

你可能觉得：

> 怎么提示越来越多，accuracy 反而掉了？

实际上不是。

因为：

```
Level 1:
全部题

Level 2:
Level 1 不会的难题

Level 3:
Level 1 + Level 2 都不会的超级难题
```

所以 **sample difficulty 在不断提高**。

这就是最核心的原因。

---

甚至我们直接拿 GPT-5-mini 的 Total 来看：

```
Level 1: 35.05%
Level 2: 64.83%
Level 3: 37.39%
```

并不是：

> 同样 1007 张图，Level 3 只有 37%。

而是：

```
Level 1：
1007 张全部测试
↓
35.05% 过关


剩下的进入 Level 2
↓
其中 64.83% 过关


又剩下一批最难的进入 Level 3
↓
其中 37.39% 过关
```

这样就完全合理了。

# 8. `Toned Accuracy / 调整后的 Accuracy` 是什么？

这个东西其实和 **GPT-5-nano 自动评分是否准确**有关。

论文没有让人类检查全部几千上万个回答。

而是：

```
VLM response
     ↓
GPT-5-nano judge
     ↓
correct / incorrect
```

但 GPT-5-nano 自己也可能判错啊。

比如模型回答：

> “The dolphin has fish-like respiratory organs that are biologically inconsistent.”

ground truth：

> “The dolphin has gills.”

Judge 万一判：

> incorrect

那就是一个 **false negative grading error**。

反过来也可能把错误答案判成正确。

---

所以作者随机抽取了大约：

> **9.83% 的 responses**

人工检查。

然后计算 GPT-5-nano judge 的：

- false positives
- false negatives

再把人工抽查中观察到的误差：

> **project 到整个 benchmark**

最后对原来的 Weighted Accuracy 做修正。

这个就是：

> **Toned Accuracy**

你翻译成 **校正后 / 调整后的 accuracy** 更好理解。
