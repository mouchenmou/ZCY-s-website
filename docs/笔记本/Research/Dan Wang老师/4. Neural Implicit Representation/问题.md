Yes — exactly. The paper’s **two stages** are:

1. **Object-level shape reconstruction at each state**
    
    - They separately reconstruct the object in state 0 and state 1.
    - At this point they are mainly trying to recover the overall 3D geometry.
    - They are **not yet deciding which geometry belongs to which moving part**.
2. **Articulation model reconstruction**
    
    - Then they recover how the object is articulated, including:
        - **part segmentation**: which points belong to which part
        - **part motion / rigid transformation**
        - from that, the **joint articulation**, such as joint type, axis, and relative state

### 1.1
What is SDF representation?
### analysis
SDF means **Signed Distance Function**.

For any 3D point $x$, the SDF tells you:

$$\boxed{\text{how far }x\text{ is from the object's surface}}$$

and the **sign** tells you whether the point is inside or outside the object.

A common convention is:

$$ \mathrm{SDF}(x) \begin{cases} <0, & x \text{ is inside the object}\\ =0, & x \text{ is exactly on the surface}\\ >0, & x \text{ is outside the object} \end{cases} $$

So imagine a sphere. For a point:

- exactly on the sphere surface: SDF = $0$
- slightly outside the sphere: SDF = positive
- slightly inside the sphere: SDF = negative

### 1.2
 PARIS takes multi- view posed images as input and optimizes an implicit rep- resentation directly from the input data without pretraining, ensuring better generalizability. However, the optimization process of PARIS depends significantly on initializations and lacks stability

I do not understand why this method depends significantly on initializations and lacks stability

### analysis
PARIS does **per-object optimization**. It does not use a pretrained network that already knows what a “door,” “drawer,” etc. should look like. Instead, for each new object, it starts with some initial values for things like the neural fields and motion parameters, then uses gradient descent to optimize them so that the rendered images match the observations. The paper describes PARIS as modeling a static part field, a mobile part field, and the transformation of the mobile part, and optimizing them jointly with an image-rendering objective.

So imagine the optimization problem is something like

$$ \min_\theta L(\theta), 
$$

where $\theta$ contains a lot of unknowns:

$$ \theta= \{ \text{static-part field}, \text{moving-part field}, \text{joint axis}, \text{joint motion}, \dots \}. $$

Gradient descent starts from some initial point

$$ \theta_0 $$

and repeatedly updates

$$ \theta_{k+1} = \theta_k-\eta\nabla L(\theta_k)$$

The problem is that this loss landscape is **not a simple bowl with one minimum**. There can be many different local minima or bad solutions.

For example, suppose the true object is a cabinet with one moving door. The correct solution might be:

$$\text{cabinet body}=\text{static field},\ \ \ \ \ \text{door}=\text{mobile field}$$

But another possible solution may also explain the rendered RGB images reasonably well:

$$ \text{part of the cabinet body incorrectly assigned to mobile field} $$
