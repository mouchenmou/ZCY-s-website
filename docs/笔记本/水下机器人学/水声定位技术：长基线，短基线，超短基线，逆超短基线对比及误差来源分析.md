## 1. “基线”到底是什么？

**基线 baseline = 参与定位的几个声学传感器之间的距离。**

比如你在陆地上定位一个人，可以用三个已知位置的基站。三个基站彼此之间的距离，就是一种“基线”。水下也是一样，只不过基站变成了声学信标、水听器、换能器。

所以：

**长基线 LBL**：几个声学基站之间隔得很远，可能几百米到几千米。

**短基线 SBL**：几个换能器装在船底，彼此隔几米到几十米。

**超短基线 USBL**：几个水听器挤在一个很小的阵列里，彼此只有几厘米到几十厘米，甚至小于 1 m。

**逆超短基线 iUSBL**：不是新原理，而是把 USBL 的“水听器阵列”从水面船上搬到 AUV 上。

你可以先这么记：

> **长短说的是传感器之间的距离，不是 AUV 到船的距离。**

## 2. 长基线 LBL：海底提前布几个“声学基站”

LBL 的全称是 Long Baseline。PPT 说它要在 AUV 任务前，在作业区域海底预先部署一组声学信标，这些信标位置已知，AUV 接收或请求这些信标的声信号，然后通过声波传播时间算距离，再用三边测量 / 多边测量算自己的位置。

你可以想象成这样：
![](附件/Pasted%20image%2020260625014728.png)

信标 A、B、C、D 的坐标提前知道。AUV 要定位自己，就问：

我离 A 多远？  
我离 B 多远？  
我离 C 多远？

如果知道三个以上距离，就可以把位置算出来。

数学上就是：

$(x-x_i)^2+(y-y_i)^2+(z-z_i)^2=r_i^2$

这里 $(x_i,y_i,z_i)$是第 $i$ 个信标的位置，$r_i$​ 是 AUV 到这个信标的距离。多个球面相交，就能确定 AUV 的位置。

### LBL 里的 OWTT 和 TWTT

PPT 还讲了两种测距方式。

**OWTT：单程传播时间**  
比如信标在某个精确时刻发声，AUV 记录自己什么时候收到。传播时间乘以声速就是距离。这个方法精度高，但要求双方时钟同步。PPT 里说 OWTT 可以分主动式和被动式，被动式是多个声学信标按约定时间发信号，AUV 测量单程传播时间，再自己三边定位。

**TWTT：双程传播时间**  
AUV 先发一个声学信号，信标收到后立刻回应，AUV 记录“从发出到收到回应”的总时间。然后用：

r=c(Δt−τ)2r=\frac{c(\Delta t-\tau)}{2}r=2c(Δt−τ)​

其中 ccc 是水中声速，Δt\Delta tΔt 是往返总时间，τ\tauτ 是信标处理 / 转发延迟。PPT 里说 TWTT 就是 AUV 发送请求，信标确认回应，AUV 测量往返传输时间，然后换算成距离并三边定位。

你之前问过一个很关键的问题：**信号传过去的过程中 AUV 不也在动吗？**

是的，AUV 确实在动。所以严格来说，TWTT 测到的不是“同一时刻的距离”，而是这段时间里的近似距离。一般处理方法是：

如果 AUV 速度不快、往返时间不长，就近似认为它没怎么动；  
如果要高精度，就用 IMU / DVL 估计 AUV 在这段时间里的运动，对测距时刻做补偿；  
也可以把测量时间看成“中间时刻”的距离。

所以这个确实是误差来源之一。

### LBL 的优缺点

LBL 的优点是**精度高、适合大范围深海作业、误差不容易随航行时间无限积累**。PPT 也提到它常用于深海探测、海底测绘等，高精度但部署复杂、成本较高。

缺点是很明显的：你要提前把一堆信标放到海底，还要测准它们的位置，任务结束还得回收，工程量很大。所以 LBL 像是“高精度但麻烦”的方案。

## 3. 短基线 SBL：船底装几个换能器，组成一个小阵列


SBL 的全称是 Short Baseline。PPT 说，SBL 采用测距定位技术，通过时间测量得到目标与每个水声换能器之间的距离，再计算目标相对位置；水面收发装置通常是安装在船体底部的水声换能器组，基线长度一般为数十米，水下端是一个应答器。

- **AUV = 被定位的东西。**  
- **船 / 海底信标 / 浮标 = 帮 AUV 定位的参考物。**

![](附件/Pasted%20image%2020260625015117.png)

就像 GPS 里：

```
手机 = 要被定位的东西卫星 = 帮手机定位的参考物
```

水下没有 GPS 信号，所以要换成：

```
AUV = 要被定位的东西船 / 海底声学信标 = 帮 AUV 定位的参考物
```

PPT 里也说，GPS 只能在水面用于初始化或校正，水下定位要靠长基线 LBL、超短基线 USBL 这些声学系统；其中 USBL 就是利用船上的换能器和水下载体上的应答器通信来测位置。
AUV 上有一个应答器。船底几个换能器分别测自己到 AUV 的距离。因为船底换能器的位置相对于船是已知的，所以可以算出 AUV 相对于船的位置。

SBL 的“基线”就是船底几个换能器之间的距离。PPT 对比图里给的量级是 **1～50 m** 左右。

### SBL 和 LBL 的区别

LBL 的基站在海底，范围大，基线长。  
SBL 的基站在船上，范围小，基线短。

所以 SBL 的好处是不用在海底布一大片信标，使用更方便；但它的定位结果强烈依赖船的位置、姿态、摇晃、换能器安装误差。

比如船一晃，船底换能器的位置和方向就变了。如果你没有准确的姿态传感器补偿，AUV 的位置就会算歪。

## 4. 超短基线 USBL：船上只有一个很小的水听器阵列

![](附件/Pasted%20image%2020260625020141.png)

USBL 的全称是 Ultra-short Baseline。PPT 说，超短基线系统的基阵长度通常只有几厘米到几十厘米。它有两种工作方式：一种是声学应答模式，水面发询问信号，水下应答器回应，通过时间差算距离；另一种是同步时钟触发模式，通过同步触发时刻到接收时刻的时间差算距离。

USBL 和 SBL 最大的区别是：

SBL 是船底几个换能器隔得比较开。  
USBL 是几个水听器挤在一个小阵列里。

USBL 测两个东西：

**第一，距离**：靠声波传播时间，和 LBL/SBL 类似。

**第二，方位角**：靠阵列中不同水听器接收到同一个声波的相位差 / 到达时间差。

PPT 第 156 页也明确写了：USBL 用一组精确布置的水听器阵列测量到声学信标的距离和方位；距离利用 OWTT 或 TWTT，方位利用每个水听器接收到信号的相位差。

你可以这么理解：

```
船上 USBL 阵列   o o o o    ← 几个水听器很近       \  声波从某个方向来        \        AUV 应答器
```

声波从 AUV 传到船上阵列时，会先到达靠近 AUV 那一侧的水听器，再到达另一侧的水听器。虽然这个时间差非常小，但可以用相位差测出来。根据这些差异，就能估计声波来的方向。

然后 USBL 得到：

AUV位置=船的位置+距离×方向\text{AUV位置} = \text{船的位置} + \text{距离} \times \text{方向}AUV位置=船的位置+距离×方向

### USBL 为什么方便但误差容易大？

因为它只需要船上一个小设备，部署很方便，适合实时跟踪 ROV/AUV。PPT 也说 USBL 便于操作、成本低，但基线短，方向校准要求精确，定位依赖外围姿态传感器。

但是它的缺点也来自“超短”两个字。

基线太短，意味着几个水听器之间的相位差本来就很小。只要测量有一点点误差，角度就可能偏很多。角度一偏，距离越远，横向位置误差越大。

比如 USBL 的角度误差是 0.5∘0.5^\circ0.5∘，AUV 离船 1000 m，那么横向误差大约是：

1000×sin⁡0.5∘≈8.7m1000 \times \sin 0.5^\circ \approx 8.7m1000×sin0.5∘≈8.7m

所以 USBL 近距离还不错，距离一远，角度误差会被放大。

## 5. 逆超短基线 iUSBL：把 USBL 反过来装

PPT 里写得很关键：

传统 USBL：  
**AUV 包含声学信标，水面端包含水听器阵列。**

逆 USBL：  
**AUV 包含水听器阵列，水面端包含声学信标。**

也就是说，传统 USBL 是船在“听”AUV，然后船算 AUV 在哪里。

逆 USBL 是 AUV 自己在“听”水面信标，然后 AUV 自己算自己在哪里。

可以画成这样：

传统 USBL：

```
船：水听器阵列  ← 接收 AUV 的声信号AUV：声学信标位置主要由船上系统解算
```

逆 USBL：

```
船 / 浮标：声学信标AUV：水听器阵列  ← 接收水面信标位置可以由 AUV 自己解算
```

为什么要这么反过来？

因为 AUV 是自主航行器，它不一定想每次都等船告诉它位置。如果 AUV 自己有水听器阵列，它接收到水面信标后，就可以自己估计“我相对于水面信标的距离和方位”。如果水面信标的位置由 GPS 给出，那么 AUV 就能得到自己的绝对位置。

但是逆 USBL 的误差来源也很明显：AUV 自己的姿态、阵列安装误差、航向角误差都会影响定位。如果 AUV 的 IMU 航向不准，测出来的方向也会歪。

你考试可以按这个表来记：

| 方法        | 基线在哪里          | 基线长度             | 主要测什么    | 优点               | 缺点                    |
| --------- | -------------- | ---------------- | -------- | ---------------- | --------------------- |
| LBL 长基线   | 海底 / 水面预布多个信标  | 约 100～6000 m     | 多个距离     | 精度高，适合大范围        | 部署复杂，成本高，要回收信标        |

## 7. 误差来源怎么分析？

老师如果考“误差来源分析”，你不要只写“有误差”。要按下面几类写。

### 第一类：声速误差

水声定位最基本公式是：

距离=声速×时间距离 = 声速 \times 时间距离=声速×时间

但水中声速不是固定的，受温度、盐度、压力影响。你假设声速是 1500 m/s，但真实可能是 1497 m/s 或 1503 m/s，这样距离就会错。

误差大概是：

δr=rδcc\delta r = r \frac{\delta c}{c}δr=rcδc​

例如 AUV 距离信标 1000 m，声速误差 1 m/s：

δr≈1000×11500≈0.67m\delta r \approx 1000 \times \frac{1}{1500} \approx 0.67mδr≈1000×15001​≈0.67m

所以距离越远，声速误差越明显。

### 第二类：时间测量误差 / 时钟同步误差

OWTT 要求发射端和接收端时钟同步。只要时钟差一点，距离就错。

因为声速约 1500 m/s，如果时间误差是 1 ms，那么距离误差就是：

1500×0.001=1.5m1500 \times 0.001 = 1.5m1500×0.001=1.5m

TWTT 不太依赖两边时钟同步，但它依赖应答器的响应延迟是否准确，而且 AUV 在往返传播期间会移动。

### 第三类：基站位置误差

LBL 里海底信标的位置必须提前测准。如果海底信标坐标本身错了，AUV 算出来的位置也会错。

这有点像你用尺子量东西，尺子刻度本身是错的，那后面怎么算都不可能完全对。

### 第四类：几何构型误差

几个信标的摆放形状也很重要。

如果信标把 AUV 包围起来，定位效果好。  
如果几个信标几乎在一条线上，或者 AUV 跑到信标阵列外很远，定位效果差。

这叫几何精度因子，也可以理解成“几何形状放大误差”。

### 第五类：多径和非视距 NLOS

声波可能不是直线到达，而是：

从海面反射一下；  
从海底反射一下；  
被船体、礁石、地形反射；  
绕路传播。

如果接收机把反射路径当成直达路径，就会以为声波传播时间更长，于是距离算大了。

### 第六类：船体姿态和安装误差

这个对 SBL 和 USBL 特别重要。

船会横摇、纵摇、艏摇。USBL 阵列装在船上，如果船的姿态角没补偿准，那么声波方向就会算错。

尤其 USBL 是靠角度定位，角度误差会随距离放大：

横向误差≈距离×角度误差横向误差 \approx 距离 \times 角度误差横向误差≈距离×角度误差

所以 USBL 的“方向校准要求精确”，PPT 表格里也强调了这一点。

### 第七类：AUV 运动误差

AUV 在声波传播过程中不是静止的。尤其 TWTT 时，声波去一趟再回来，期间 AUV 已经移动了。

如果不补偿，就会产生动态误差。通常要结合 IMU、DVL、运动模型来修正。

## 8. 最后用一句话总结每个系统

**LBL：**  
提前在海底布几个已知位置的声学信标，AUV 测自己到多个信标的距离，用三边测量定位。**精度高，但麻烦、贵。**

**SBL：**  
船底装几个相隔几米到几十米的换能器，测 AUV 到这些换能器的距离。**比 LBL 方便，但受船运动和姿态影响。**

**USBL：**  
船上一个很小的水听器阵列，测 AUV 的距离和方位。**最方便，实时性好，但角度误差容易被距离放大。**

**逆 USBL：**  
把 USBL 反过来，AUV 带水听器阵列，水面端发信标，AUV 自己算位置。**更适合自主 AUV，但依赖 AUV 姿态和阵列标定。**

考试写对比题时，你就抓住四个维度：**基线长度、设备布置、定位原理、误差来源**。这四个写出来，基本就不会空。
