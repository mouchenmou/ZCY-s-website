## 1. IMU 到底是什么？

IMU 全称是 **Inertial Measurement Unit，惯性测量单元**。

它通常测两个东西：

```
加速度：我沿 x、y、z 三个方向有没有加速？角速度：我绕 x、y、z 三个轴有没有转？
```

AUV 有三个姿态角：

```
roll  横滚：左右歪pitch 俯仰：头抬起来 / 低下去yaw   航向：朝东南西北哪个方向
```

所以 IMU 的任务就是帮助算这三个角。

---

## 2. MEMS IMU 是什么？

MEMS 是 **Micro-Electro-Mechanical Systems，微机电系统**。

你可以把它理解成：**把很小的机械结构做进芯片里**。手机里的陀螺仪、加速度计很多就是 MEMS。

PPT 里说 MEMS IMU 通常在一个芯片中包含 9 个传感器：

```
3 个加速度计：测 x、y、z 三个方向的线性加速度
3 个陀螺仪：测绕 x、y、z 三个轴的角速度
3 个磁力计：测 x、y、z 三个方向的地磁场
```

然后 AHRS 算法把这 9 轴数据融合，算出横滚角、俯仰角和航向角。

---

## 3. MEMS IMU 里面三个东西分别干什么？

### 加速度计：主要帮你判断横滚和俯仰

加速度计不只是测“运动加速度”，它还会测到**重力加速度**。

比如 AUV 平着放：

```
z 轴方向大约测到 gx、y 方向接近 0
```

说明 z 轴大概朝下。

如果 AUV 头抬起来了，重力就会分到 x 轴和 z 轴上。根据重力在各轴上的分量，就能估计 pitch 和 roll。PPT 里也说，加速度计测量值包含重力加速度，可以帮助测量横滚角和俯仰角。

但是加速度计有个问题：AUV 真正在加速、转弯、受水流扰动时，它测到的不只是重力，所以不能单独完全相信。

---

### 陀螺仪：测你转得有多快

陀螺仪测的是角速度，比如：

```
绕 z 轴每秒转 10°
```

那我积分一下，就能知道过了一段时间转了多少：

角度=∫角速度 dt角度 = \int 角速度 \, dt角度=∫角速度dt

比如 AUV 每秒转 10∘10^\circ10∘，转了 3 秒，那大概转了：

10∘/s×3s=30∘10^\circ/s \times 3s = 30^\circ10∘/s×3s=30∘

但是问题来了：**只要陀螺仪有一点点偏差，积分久了就会越积越错。**

比如陀螺仪静止时本来应该测 0，但它偏偏测成 0.01∘/s0.01^\circ/s0.01∘/s。那积分 1000 秒以后，就会漂掉：

0.01∘/s×1000s=10∘0.01^\circ/s \times 1000s = 10^\circ0.01∘/s×1000s=10∘

这就是 IMU 最重要的误差：**漂移 drift**。PPT 里也说，不完美测量值的积分会导致横滚角、俯仰角和偏航角解算值偏离实际值。

---

### 磁力计：主要帮你判断航向

磁力计测地磁场，类似电子指南针。

理论上它可以告诉你：

```
x 轴是不是指向北方？AUV 当前航向是多少？
```

PPT 里说磁力计测三维磁场强度，可帮助测量磁航向角，之后还要把磁航向转换成真航向。

但是水下机器人上有电机、金属壳体、电缆、电磁干扰，所以磁力计不一定可靠。因此高精度系统往往不喜欢依赖磁力计。

---

## 4. 那为什么还要“融合”？

因为三个传感器各有缺点。

```
加速度计：长期不漂，但动态运动时容易受干扰陀螺仪：短时间很准，但长期积分会漂磁力计：能给航向参考，但容易受磁干扰
```

所以要用卡尔曼滤波或者互补滤波融合它们。

简单理解：

```
短时间相信陀螺仪长时间用加速度计修正 roll / pitch用磁力计修正 yaw / 航向
```

PPT 里也写到，使用卡尔曼滤波器融合所有测量值，以获得横滚角、俯仰角和航向角的解算值。

---

## 5. 光纤 IMU / 光纤陀螺 FOG 是什么？

FOG 是 **Fiber-Optic Gyroscope，光纤陀螺仪**。

它和 MEMS 陀螺不一样。MEMS 陀螺是芯片里的微小机械结构在感受转动；FOG 是用**光**来测转动。

PPT 里说，FOG IMU 使用光来计算运动，是被动系统；它向长光纤线圈中发送方向相反的两束激光，旋转时两束光走过的等效路径不同，会产生相位差，测这个相位差就能知道旋转变化。

你可以想象成这样：

```
一圈很长的光纤线圈光束 A 顺时针走光束 B 逆时针走如果设备在旋转，两束光回来时会有一点时间差 / 相位差通过这个差值算角速度
```

这个原理叫 **Sagnac 效应**。你不用背名字也行，考试写“基于光纤干涉效应 / 相位差测角速度”就够了。

---

## 6. 光纤 IMU 为什么更准？

因为它没有 MEMS 那种微小机械结构，受机械磨损、微结构加工误差的影响更小，零偏稳定性更好。

简单说：

```
MEMS：便宜、小、轻，但漂得快FOG：贵、大、耗电一些，但漂得慢、精度高
```

PPT 里也说 FOG IMU 由极其精确的陀螺仪组成，无需磁力计，但需要初始化至北方，才能获得以北为参考的航向。

这个“初始化至北方”很关键。

因为 FOG 可以很准确地感知“我转了多少”，但是一开始你要告诉它：

```
现在这个方向是北
```

之后它才能根据角速度积分，持续维护航向。

---

## 7. MEMS IMU 和光纤 IMU 的核心区别

|对比项|MEMS IMU|光纤 IMU / FOG IMU|
|---|---|---|
|核心原理|微机械结构测加速度和角速度|光纤干涉 / 相位差测角速度|
|典型组成|3 加速度计 + 3 陀螺仪 + 3 磁力计|通常是高精度光纤陀螺 + 加速度计，不依赖磁力计|
|体积|小|较大|
|成本|低|高|
|精度|较低|高|
|漂移|比较明显|小很多|
|是否怕磁干扰|磁力计部分怕|不靠磁力计，抗磁干扰更好|
|适合场景|低成本 AUV / ROV 姿态控制|高精度长时间水下导航|

## 8. 在水下导航里，它们到底干什么？

IMU 不是单独完成定位的，它主要提供**姿态**。

PPT 里讲速度辅助惯性导航时说：水下可以用 DVL 测量 AUV 相对于水体或海底的机体系速度，再利用 IMU 给出的俯仰、横滚、偏航角，把机体系速度转换到地球坐标系，然后积分得到位置变化；直到 AUV 浮出水面重新获得 GPS。

也就是说：

```
DVL：告诉我 AUV 在自己身体坐标系下怎么运动IMU：告诉我 AUV 的身体现在朝哪个方向二者结合：才能知道 AUV 在地球坐标系里往哪里走
```

比如 DVL 说：

```
AUV 沿自己的前方走了 10 m
```

但是“自己的前方”到底是东、南、西、北哪个方向？这就要 IMU 告诉你航向角。

所以：

```
没有 IMU：只知道相对自己怎么动，不知道相对地球怎么动没有 DVL：只靠 IMU 积分加速度，位置会漂得非常快
```

## 9. 你考试可以这样写

如果题目问：**MEMS IMU 与光纤 IMU 的组成与对比**

你可以写：

> MEMS IMU 通常由三轴加速度计、三轴陀螺仪和三轴磁力计组成，通过 AHRS 算法融合 9 轴数据，得到横滚角、俯仰角和航向角。加速度计可利用重力方向辅助估计横滚和俯仰，陀螺仪通过积分角速度得到姿态变化，磁力计用于辅助航向估计。但 MEMS IMU 成本低、体积小，同时零偏和噪声较大，积分误差会随时间累积，需要 DVL、GPS、水声定位等外部信息校正。
> 
> 光纤 IMU 的核心是光纤陀螺 FOG，利用光纤线圈中两束反向传播激光的相位差测量角速度。其精度和稳定性高，不依赖磁力计，抗磁干扰能力强，适合长时间、高精度水下导航任务。但光纤 IMU 成本较高、体积和功耗通常大于 MEMS IMU，并且需要初始对准，例如初始化至北方。

最后你就记一句：

> **MEMS IMU 像手机里的姿态传感器：便宜、小，但容易漂；光纤 IMU 像高端导航设备：贵，但稳、准，适合长时间水下导航。**
