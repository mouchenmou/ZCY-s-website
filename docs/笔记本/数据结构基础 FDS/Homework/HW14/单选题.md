### 2-1

> The average search time of searching a hash table with N elements is:

- A. $O(1)$
- B. $O(logN)$
- C. $O(N)$
- D. cannot be determined

??? success "答案与解析"
    **答案：D**

    如果不做任何假设，哈希表的平均查找时间**无法确定**——它取决于哈希函数的质量、装载密度和冲突解决策略。理想情况下（均匀哈希 + 合理装载密度）是 O(1)，但如果哈希函数设计得很差（比如所有元素映射到同一个桶），就会退化为 O(N)。题目没有给出这些前提条件，所以选 D。

### 2-2

> Which of the following statements about HASH is true?

- A. the expected number of probes for insertions is greater than that for successful searches in linear probing method
- B. if the table size is prime and the table is at least half empty, a new element can always be inserted with quadratic probing
- C. in separate chaining method, if duplicate elements are allowed in the list, insertions are generally quicker than deletions
- D. all of the above

??? success "答案与解析"
    **答案：D**

    逐一验证：

    **A ✅** 线性探测中，插入需要探测到第一个空位，成功查找只需探测到目标元素。$\lambda = 0.5$ 时插入约需 2 次探测，成功查找约需 1.5 次，插入的期望探测数更大。

    **B ✅** 这是二次探测的核心定理：我在笔记中证明过了

    **C ✅** 分离链接中允许重复元素时，插入只需在链表头部添加（O(1)），删除需要先找到目标元素再移除（需遍历链表），插入比删除快。

    因此 A、B、C 都正确，选 D。

### 2-3

> Given an initially empty hash table `HT` with length 7, together with a hash function H(k)=k%7. Let us use linear probing to solve collisions. What is the average search length for successful searches after inserting 22, 43, 15 one by one into `HT`?

- A. 1.5
- B. 1.6
- C. 2
- D. 3

??? success "答案与解析"
    **答案：C**

    逐一插入：

    1. **22**：$22 \% 7 = 1$，位置 1 空 → 直接插入（1 次探测）
    2. **43**：$43 \% 7 = 1$，位置 1 被占 → 线性探测到位置 2，空 → 插入（2 次探测）
    3. **15**：$15 \% 7 = 1$，位置 1、2 都被占 → 探测到位置 3，空 → 插入（3 次探测）

    成功查找的平均探测次数 = $(1 + 2 + 3) / 3 = 6 / 3 = 2$。

### 2-4

> What is a collision in hashing?

- A. Everything else are the same for the two elements except their keys
- B. Two elements have different data but share the same key
- C. Two elements with different keys share the same hash value
- D. Two elements with different hash values share the same key

??? success "答案与解析"
    **答案：C**

    **Collision（冲突）** 的定义是：两个不同的 key 经过哈希函数算出了相同的哈希值（即映射到了同一个桶）。

    - **A** ❌ 含糊不清，没有描述 hash value 的关系。
    - **B** ❌ 同一个 key 就是同一个元素，不存在"两个元素"。
    - **C** ✅ 不同 key + 相同 hash value = collision。
    - **D** ❌ 同一个 key 必然算出相同的 hash value，不可能不同 hash value。

### 2-5

> Insert {18, 23, 11, 20, 2, 7, 27, 33, 42, 15} one by one into an initially empty hash table of size 11 with the hash function H(Key)=Key%11, and linear probing is used to resolve collisions. What is the loading density when the first collision occurs?

- A. 0.27
- B. 0.45
- C. 0.64
- D. 0.73

??? success "答案与解析"
    **答案：B**

    逐一插入，直到第一次碰撞：

    | 插入顺序 | Key | H(Key) | 位置 | 结果 |
    |:--:|:--:|:--:|:--:|:--:|
    | 1 | 18 | 7 | 空 | ✅ 插入 |
    | 2 | 23 | 1 | 空 | ✅ 插入 |
    | 3 | 11 | 0 | 空 | ✅ 插入 |
    | 4 | 20 | 9 | 空 | ✅ 插入 |
    | 5 | 2 | 2 | 空 | ✅ 插入 |
    | 6 | **7** | **7** | **被 18 占了** | ❌ **碰撞！** |

    第一次碰撞发生在插入第 6 个元素时，此时表中已有 5 个元素。
    装载密度 $\lambda = 5 / 11 \approx 0.45$。

### 2-6

> Suppose that the range of a hash table is `[0, 18]`, and the hash function is $H(Key)=Key\ \%\ 17$ . If linear probing is used to resolve collisions, then after inserting { 16, 32, 14, 34, 48 } one by one into the hash table, the index of 48 is:

- A. 14
- B. 0
- C. 17
- D. 1

??? success "答案与解析"
    **答案：C**

    逐一插入：

    1. **16**：$16 \% 17 = 16$，位置 16 空 → 插入 ✅
    2. **32**：$32 \% 17 = 15$，位置 15 空 → 插入 ✅
    3. **14**：$14 \% 17 = 14$，位置 14 空 → 插入 ✅
    4. **34**：$34 \% 17 = 0$，位置 0 空 → 插入 ✅
    5. **48**：$48 \% 17 = 14$，位置 14 被占 → 线性探测：
       - 位置 15：被 32 占 ❌
       - 位置 16：被 16 占 ❌
       - 位置 **17**：空 ✅ → 48 插入到位置 17

    因此 48 的索引为 17。
