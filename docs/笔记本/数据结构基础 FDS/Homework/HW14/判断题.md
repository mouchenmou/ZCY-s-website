## 1-1

> In hashing, functions "insert" and "find" have the same time complexity.

- T
- F

??? success "答案与解析"
    **答案：T**

    在哈希表中，insert 和 find 的执行流程基本一致：先算哈希值，再沿着探测序列找目标位置/空位。两者在平均情况下都是 O(1)，最坏情况下都是 O(N)。所以 时间复杂度相同。

## 1-2

> Linear probing isn't equivalent to double hashing with a secondary hash function of Hash2​(k)=1.

- T
- F

??? success "答案与解析"
    **答案：F**

    双重哈希的公式是 $h_i(x) = (\mathrm{hash}(x) + i \cdot \mathrm{hash}_2(x)) \bmod \mathrm{TableSize}$。如果 $\mathrm{hash}_2(x) = 1$，则 $h_i(x) = (\mathrm{hash}(x) + i) \bmod \mathrm{TableSize}$ —— 这正是线性探测。所以两者是等价的，题目说 "isn't equivalent"（不等价）是错误的。

## 1-3

> Store M elements in a hash table which is represented by an array of size S, the loading density is then M/S.

- T
- F

??? success "答案与解析"
    **答案：T**

    装载密度 $\lambda = n / (s \cdot b)$。对于开放地址法，每个桶只有 1 个槽位（$s = 1$），桶数 $b$ 就是数组大小 $S$，所以 $\lambda = M / S$。即使对于分离链接法，$M/S$ 也常被用来近似衡量表的拥挤程度。因此该说法正确。
