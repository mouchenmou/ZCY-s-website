### 1-1
In Robin Hood hashing, a newly inserted key may displace an existing key even if the existing key has a shorter probe distance from its original bucket, as long as the new key's hash value is smaller.

- T
- F

??? success "答案与解析"
    **答案：F**

    Robin Hood Hashing 是否发生交换，与两个 key 的哈希值谁大谁小无关，只比较它们在当前位置的**探测距离**。

    设新 key 的当前探测距离为 $d_{new}$，原有 key 的探测距离为 $d_{old}$。只有当

    $$
    d_{new}>d_{old}
    $$

    时，新 key 才会抢占当前位置，原有 key 被继续向后移动。因此，“只要新 key 的哈希值更小就可以替换”是错误的。

### 1-2

In Robin Hood hashing, rich elements are those in the table with low probe sequence length.

- T
- F

??? success "答案与解析"
    **答案：T**

    Robin Hood Hashing 中：

    - **rich element** 的探测序列长度较短，离自己的理想桶较近；
    - **poor element** 的探测序列长度较长，已经离自己的理想桶较远。

    插入时让 poor element 抢占 rich element 的位置，即“劫富济贫”，从而降低各元素探测距离的方差，使查找代价更加均匀。
