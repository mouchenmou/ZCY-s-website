### 2-1

Given a hash table of size 13 and the hash function h(x)=x%13. Assume that quadratic probing is used to solve collisions. After filling in the hash table one by one with input sequence { 10, 23, 1, 36, 19, 5 }, which number is placed in the position of index 0?

- A. 23
- B. 36
- C. 10
- D. none

??? success "答案与解析"
    **答案：D. none**

    表长为 13，二次探测位置为

    $$
    h_i(x)=\big(h(x)+i^2\big)\bmod 13
    $$

    逐个插入：

    1. $10\to 10$；
    2. $23\to 10$ 冲突，探测 $10+1^2=11$，放入下标 11；
    3. $1\to 1$；
    4. $36\to 10$ 冲突，再依次探测 11、1、6，放入下标 6；
    5. $19\to 6$ 冲突，探测下标 7；
    6. $5\to 5$。

    最终占用的下标为 1、5、6、7、10、11，下标 0 为空，因此选择 D。

### 2-2

Given input {4371, 1323, 6173, 4199, 4344, 9679, 1989} and a hash function h(X)=X%10. If the collisions are solved by separate chaining with table size being 10, then the indices of the input numbers in the hash table are: (-1 means the insertion cannot be successful)

- A. 1, 3, 3, 9, 4, 9, 9
- B. 1, 3, 4, 9, 7, 5, -1
- C. 1, 3, 4, 9, 5, 0, 8
- D. 1, 3, 4, 9, 5, 0, 2

??? success "答案与解析"
    **答案：A. 1, 3, 3, 9, 4, 9, 9**

    Separate Chaining 允许多个元素存入同一个桶的链表，因此发生冲突时不需要寻找其他下标，也不会插入失败。每个数的桶下标就是其个位数：

    $$
    4371,1323,6173,4199,4344,9679,1989
    \xrightarrow{\bmod 10}
    1,3,3,9,4,9,9
    $$

    因此选择 A。

### 2-3

Given input {4371, 1323, 6173, 4199, 4344, 9679, 1989} and a hash function $h(X)=X \%10$. If the collisions are solved by open addressing hash table with second hash function $h_2(X)=7−(X\%7)$ and table size being 10, then the indices of the input numbers in the hash table are: (-1 means the insertion cannot be successful)

- A. 1, 3, 3, 9, 4, 9, 9
- B. 1, 3, 4, 9, 7, 5, -1
- C. 1, 3, 4, 9, 5, 0, 8
- D. 1, 3, 4, 9, 5, 0, 2

??? success "答案与解析"
    **答案：B. 1, 3, 4, 9, 7, 5, -1**

    双重哈希的探测公式为：

    $$
    h_i(X)=\big(h_1(X)+i\cdot h_2(X)\big)\bmod 10
    $$

    其中 $h_1(X)=X\bmod 10$，$h_2(X)=7-(X\bmod 7)$。

    1. `4371`：$h_1=1$，放入下标 1。
    2. `1323`：$h_1=3$，放入下标 3。
    3. `6173`：$h_1=3$ 冲突，$h_2=1$，下一位置为 4。
    4. `4199`：$h_1=9$，放入下标 9。
    5. `4344`：$h_1=4$ 冲突，$h_2=3$，下一位置为 7。
    6. `9679`：$h_1=9$ 冲突，$h_2=2$，依次探测 1、3、5，放入下标 5。
    7. `1989`：$h_1=9$，$h_2=6$，探测序列在 9、5、1、7、3 之间循环，这些位置均已占用，插入失败，记为 $-1$。

    `1989` 失败的根本原因是 $\gcd(6,10)=2\ne1$，步长 6 与表长 10 不互质，无法遍历整张表。

### 2-4

Suppose that the numbers {4371, 1323, 6173, 4199, 4344, 9679, 1989} are hashed into a table of size 10 with the hash function h(X)=X%10, and hence have indices {1, 3, 4, 9, 5, 0, 2}. What are their indices after rehashing using h(X)=X%TableSize with linear probing?

- A. 11, 3, 13, 19, 4, 0, 9
- B. 1, 3, 4, 9, 5, 0, 2
- C. 1, 12, 9, 13, 20, 19, 11
- D. 1, 12, 17, 0, 13, 8, 14

??? success "答案与解析"
    **答案：C. 1, 12, 9, 13, 20, 19, 11**

    Rehashing 时，新表大小通常取至少为原表两倍的质数。原表大小为 10，所以新表大小取

    $$
    \mathrm{TableSize}_{new}=23
    $$

    用新的表长重新计算每个 key 的哈希值：

    $$
    4371,1323,6173,4199,4344,9679,1989
    \xrightarrow{\bmod 23}
    1,12,9,13,20,19,11
    $$

    这些位置互不冲突，不需要继续线性探测，因此选择 C。注意 rehash 不能直接沿用旧表中的下标，所有有效元素都必须按新表长重新计算位置。

### 2-5

Rehashing is required when an insertion to a hash table fails. Which of the following is **NOT** necessary to rehashing?

- A. change the collision resolution strategy
- B. use a new function to hash all the elements into the new table
- C. build another table that is bigger than the original one
- D. scan down the entire original hash table for non-deleted elements

??? success "答案与解析"
    **答案：A. change the collision resolution strategy**

    Rehashing 的必要步骤包括：

    1. 建立一个更大的新表，表长通常取至少为原表两倍的质数；
    2. 扫描原表，找出所有未删除的有效元素；
    3. 根据新表的大小重新计算哈希位置，并把元素插入新表。

    **为什么 B 是必要的？** 原来的哈希函数为

    $$
    h_{old}(x)=x\bmod \mathrm{TableSize}_{old}
    $$

    扩容后 `TableSize` 发生变化，实际使用的哈希函数也随之变为

    $$
    h_{new}(x)=x\bmod \mathrm{TableSize}_{new}
    $$

    即使“取模”这个基本方法没有改变，模数改变后，同一个 key 的哈希值通常也会改变。因此必须用新的 `TableSize` 对所有有效元素重新计算位置，不能把它们直接复制到原下标。

    冲突解决策略则可以继续使用原来的方法，不要求更换。因此 A 不是 rehashing 的必要操作。

### 2-6

In Robin Hood hashing, when a newly inserted key $k_1$​ displaces an existing key $k_2​$ before probing the last hash table cell, which of the following best describes k1​'s condition?

- A. k1​ has a smaller hash value than k2​.
- B. k1​ was inserted earlier in the sequence than k2​.
- C. The load factor of the hash table exceeds 0.75.
- D. The probe distance of k1​ at the current position is shorter than that of k2​.

??? success "答案与解析"
    **答案：A. $k_1$ has a smaller hash value than $k_2$.**

    当 $k_1$ 探测到存放 $k_2$ 的位置时，$k_2$ 比 $k_1$ **rich**，说明 $k_2$ 离自己的原始哈希位置更近，而 $k_1$ 为了走到当前位置已经探测了更多步。因此：

    $$
    d(k_1)>d(k_2)
    $$

    按照 Robin Hood Hashing 的“劫富济贫”规则，较 poor 的 $k_1$ 会抢占较 rich 的 $k_2$ 的位置，$k_2$ 再继续向后探测。

    题目的关键限定是 **before probing the last hash table cell**，也就是说探测过程尚未越过数组末尾、绕回下标 0。设发生交换的当前位置为 $c$，此时不需要考虑取模回绕：

    $$
    d(k_1)=c-h(k_1),\qquad d(k_2)=c-h(k_2)
    $$

    把上面的距离关系代入：

    $$
    c-h(k_1)>c-h(k_2)
    \Longrightarrow h(k_1)<h(k_2)
    $$

    因此，$k_1$ 从较小的原始哈希位置出发，走到当前位置所用的步数比 $k_2$ 多，所以 $k_1$ 的哈希值比 $k_2$ 小，选择 A。

    D 说 $k_1$ 的探测距离更短，与 Robin Hood 的交换条件恰好相反。

### 2-7

Insert keys { 21, 15, 36, 9, 49, 7 } one by one into a Robin Hood hash table of size 7, using linear probing and the given hash function h(key)=key%7. When search for the number 8, for how many probes it takes to realize that 8 is not in the table?

- A. 3
- B. 4
- C. 5
- D. 6

??? success "答案与解析"
    **答案：C. 5**

    依次插入后，Robin Hood 哈希表为：

    ```text
    index:   0    1    2    3    4    5    6
    key:    21   49    7   15   36    9   空
    d(x):    0    1    2    2    3    3    -
    ```

    查找 8 时，$h(8)=1$。从下标 1 开始：

    1. 探测下标 1，当前距离 0，槽中 `49` 的距离为 1；
    2. 探测下标 2，当前距离 1，槽中 `7` 的距离为 2；
    3. 探测下标 3，当前距离 2，槽中 `15` 的距离为 2；
    4. 探测下标 4，当前距离 3，槽中 `36` 的距离为 3；
    5. 探测下标 5，当前距离 4，槽中 `9` 的距离为 3。

    到第 5 次探测时，当前距离 $4$ 已大于槽中元素的距离 $3$。根据 Robin Hood Hashing 的提前终止规则，可以确定 8 不在表中，因此共需 5 次探测。
