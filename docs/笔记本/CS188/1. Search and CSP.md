# CS188 Midterm — Search & CSP 速记

> 每个概念：一句定义 + 一道简短例题。`g` 为已走代价，`h` 为估计剩余代价。

## Part 1. Search

### 1. Search Problem / State / Frontier

**概念：** Search Problem 指从初始 State 经合法 Actions 到达 Goal；Frontier 存放已发现、尚未扩展的节点。State 是问题状态，Node 是搜索记录（可含路径和 cost）。

**例题：** Pacman 在格子 (2,3)，可以向上下左右走但左侧有墙。最大可生成几个后继？**答：3。**

### 2. DFS（Depth-First Search）

**概念：** 用 Stack（LIFO，后进先出），优先沿一条分支向深处走；一般不保证最短路径。

**例题：** 栈从栈顶到栈底为 `[C, B, A]`，下一次扩展谁？**答：C。**

### 3. BFS（Breadth-First Search）

**概念：** 用 Queue（FIFO，先进先出），按深度从浅到深扩展；所有动作 cost 相等时能找最短路径。

**例题：** 队列从队首到队尾为 `[A, B, C]`，下一次扩展谁？**答：A。**

### 4. UCS（Uniform Cost Search）

**概念：** 用 Priority Queue，每次扩展累计路径代价 `g(n)` **最小**的 Frontier 节点；发现更便宜的路径要更新相应代价。

**例题：** Frontier 中 `A:g=7, B:g=3, C:g=5`，扩展谁？**答：B。**

### 5. Greedy Best-First Search

**概念：** 只按预计剩余代价 `h(n)` 最小来扩展；通常不保证最优。

**例题：** `h(A)=4, h(B)=1`，扩展谁？**答：B。**

### 6. A* Search

**概念：** 按 `f(n)=g(n)+h(n)` 最小扩展；可以理解为带剩余代价预测的 UCS。

**例题：** `A:g=2,h=6`；`B:g=5,h=1`。扩展谁？**答：B**（`f(B)=6<8`）。

### 7. Admissible Heuristic

**概念：** 启发函数不高估到 Goal 的真实最小剩余代价：`h(n) ≤ h*(n)`；常取 `h(n)≥0`。这是标准 A* Tree Search 最优性的重要条件。

**例题：** 到目标最便宜还需 5，估计 `h=7`，是否 admissible？**答：否，7>5。**

### 8. Consistent Heuristic

**概念：** 每条有向边 `n→n'` 都满足 `h(n)≤c(n,n')+h(n')`；因此沿一条路径 `f` 不下降，标准 A* Graph Search 可以安全地不重开已扩展节点。

**例题：** `h(A)=5, c(A,B)=2, h(B)=1`，是否 consistent？**答：否，5>2+1。**

## Part 2. CSP

### 9. CSP / Variables / Domains / Constraints

**概念：** CSP（Constraint Satisfaction Problem）是为变量从各自 Domain 中选值，使所有 Constraints 成立。

**例题：** `A,B∈{1,2,3}`，约束 `A<B`；`A=2,B=3` 是否是解？**答：是。**

### 10. Assignment vs Domain Pruning

**概念：** Assignment 是确定一个变量取值；Pruning 是删除 Domain 中不可能合法的候选值，**不等于赋值**。

**例题：** `D_A={1,2,3}` 被删成 `{2}`，是否必然代表算法已正式 assign `A=2`？**答：否。**

### 11. Backtracking

**概念：** 逐个变量尝试赋值，冲突时撤回最近的选择并尝试其他值。

**例题：** 约束 `A≠B`，已经 `A=1`，尝试 `B=1` 失败后怎么办？**答：撤销 `B=1`，尝试其他值。**

### 12. MRV（Minimum Remaining Values）

**概念：** 优先选择 Domain 最小的未赋值变量。

**例题：** `|D_A|=3, |D_B|=1`，先选谁？**答：B。**

### 13. Degree Heuristic

**概念：** 优先选约束其他未赋值变量最多的变量；在 CS188 常用作 MRV 平局时的 tie-breaker。

**例题：** A、B 的 Domain 都有 2 个值，A 连接 1 个未赋值变量，B 连接 3 个，选谁？**答：B。**

### 14. LCV（Least Constraining Value）

**概念：** 选定变量后，优先尝试使其他变量剩余合法候选值最多的取值。

**例题：** `X=1` 会删邻居 1 个值，`X=2` 会删 3 个；先试哪个？**答：1。**

### 15. Forward Checking

**概念：** **刚给 X 赋值后**，从直接相关的未赋值邻居 Domain 删除与此赋值冲突的值；不继续跨未赋值变量传播。

**例题：** `X<Y<Z`，三个 Domain 原为 `{1,2,3}`，assign `X=2` 后只做 FC：**`D_Y={3}`，`D_Z={1,2,3}`。**

### 16. Arc Consistency（有向弧的一致性）

**概念：** 检查弧 `X→Y` 时，**X 的每个候选值**都必须在 Y 中找到至少一个满足约束的 Support；否则**删除 X 的值**。反向 `Y→X` 则检查并可能删除 Y 的值。它是性质，不是一个特定算法。

**例题：** `X<Y`，`D_X={1,2,3}`、`D_Y={2,3}`；检查 `X→Y` 后：**`D_X={1,2}`**（X=3 无 Support）。

### 17. AC-3 Algorithm

**概念：** 用队列反复检查有向弧；某个 Domain 缩小后重新检查可能受影响的弧，直到无法继续删值（或出现空 Domain）。可以在未赋值时执行。

**例题：** `X<Y<Z`，`D_X={1,2}`、`D_Y={1,2,3}`、`D_Z={2,3,4}`；执行完整 AC-3 后：**`D_X={1,2}, D_Y={2,3}, D_Z={3,4}`**。它不要求每个 Domain 只剩一个值。

**一句话区别：** Forward Checking 是赋值后检查直接邻居；Arc Consistency 是“每个值都有 Support”的性质；AC-3 是反复检查有向弧直至稳定的算法。# CS188 Midterm — Search & CSP 速记
