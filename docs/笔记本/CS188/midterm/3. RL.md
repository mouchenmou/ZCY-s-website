

> 衔接 Game Trees & MDP；聚焦未知环境下的学习：Model-Based / Model-Free、TD、Q-Learning、ε-Greedy、On/Off-Policy、Approximate Q-Learning。

## 1. 统一符号

| 符号 | 名称 | 含义 |
|---|---|---|
| $s,s'$ | State, Next State | 当前状态、下一状态 |
| $a,a'$ | Action, Next Action | 当前动作、下一步动作 |
| $T(s,a,s')$ | Transition Probability | 在 $s$ 执行 $a$ 后，到达 $s'$ 的概率 |
| $R(s,a,s')$ | Reward | 这次转移获得的奖励（有些题目写成 $R(s,a)$） |
| $r$ | Observed Reward | **实际交互**中观察到的一次奖励 |
| $\pi(a\mid s)$ | Policy | 在状态 $s$ 选择动作 $a$ 的概率 |
| $V^\pi(s)$ | State Value | 从 $s$ 出发遵循 $\pi$ 的预期累计折扣奖励 |
| $Q^\pi(s,a)$ | Action Value | 从 $s$ 先做 $a$，再遵循 $\pi$ 的预期累计折扣奖励 |
| $V^*,Q^*$ | Optimal Value | 最优策略下的状态价值、动作价值 |
| $\gamma$ | Discount Factor | 未来奖励的折扣，通常 $0\leq\gamma<1$ |
| $\alpha$ | Learning Rate | 一次更新走多大一步 |
| $\epsilon$ | Exploration Rate | ε-Greedy 进入随机探索分支的概率 |
| $\delta$ | TD Error | 本次 Target 减去原来的估计 |

**核心区别：** $R$ 是一次转移的奖励；$V(s)$ 是某状态的未来累计价值；$Q(s,a)$ 是在状态 $s$ **选择特定动作 $a$** 的未来累计价值。


## 2. Agent、Environment、Environment Model

- **Agent**：观察 State，选择 Action。
- **Environment**：执行 Action 后决定实际的 Next State 和 Reward。
- **Environment Model（环境模型）**：预测执行动作后环境会怎样变化，主要涉及 $T$ 和 $R$。

例：Pacman 在 A 选 Right，游戏规则使其有 $80\%$ 概率到 B、$20\%$ 到 C：

$$
T(A,\mathrm{Right},B)=0.8,\qquad T(A,\mathrm{Right},C)=0.2.
$$

这两个概率由**环境的状态转移规则**决定，和 Agent 多大概率*选择* Right 不同：

- $\pi(\mathrm{Right}\mid A)$：Agent 选 Right 的概率；
- $T(A,\mathrm{Right},B)$：**已经选了 Right** 后，环境让它到 B 的概率。

确定性环境也有 Transition Model，只是对应概率为 0 或 1。

### Model-Based vs. Model-Free RL

| | Model-Based RL | Model-Free RL |
|---|---|---|
| 核心 | 利用环境模型预测或规划 | 不依赖显式环境模型进行规划，直接从经验学价值或策略 |
| 是否需要知道/学习 $T,R$ | 要用到环境模型（可以学习） | 不必学习 $T,R$ |
| 典型例子 | 估计 $\hat T,\hat R$ 后用 Value Iteration 规划 | TD Learning、Q-Learning |

**注意：** “Model” 在这里特指 **Environment Model**，不等于“神经网络”。即使使用神经网络估计 $Q_\theta(s,a)$，也可以是 Model-Free。


## 3. TD(0) Learning（时序差分学习）

**目标：** 不知道完整环境转移模型，利用一次真实交互 $(s,a,r,s')$ 更新当前 Policy 的 State Value。

$$
\underbrace{\mathrm{Target}}_{\text{本次学习目标}}=r+\gamma V(s')
$$

$$
\delta=\mathrm{Target}-V(s)
$$

$$
\boxed{V(s)\leftarrow V(s)+\alpha\delta}
$$

例：$V(A)=5,V(B)=10,r=4,\gamma=0.9,\alpha=0.5$：

- Target $=4+0.9(10)=13$；
- TD Error $=13-5=8$；
- $V_{\mathrm{new}}(A)=5+0.5(8)=9$。

**TD(0) vs. Value Iteration：** TD 使用**一次采样到的** $(r,s')$，不需要完整的 $T$；Value Iteration 使用已知的环境模型，对所有可能 $s'$ 求期望并对 Action 取 max。


## 4. Q-Learning

**目标：** 不需要环境转移模型，直接学习最优 Action Value $Q^*(s,a)$。

$$
\mathrm{Target}=r+\gamma\max_{a'}Q(s',a')
$$

$$
\delta=r+\gamma\max_{a'}Q(s',a')-Q(s,a)
$$

$$
\boxed{Q(s,a)\leftarrow Q(s,a)+\alpha\delta}
$$

如果 $s'$ 是 Terminal State，未来价值通常视为 0，Target $=r$。

**计算例子：** 当前 $Q(A,\mathrm{Right})=4$；实际执行 Right 到 B 获得 $r=5$；B 可选 Left/Right，Q 分别为 6/10；$\gamma=0.9,\alpha=0.5$：

- Target $=5+0.9\max(6,10)=14$；
- $\delta=14-4=10$；
- $Q_{\mathrm{new}}(A,\mathrm{Right})=4+0.5(10)=9$。

**每次只更新实际经历的那个 $(s,a)$**（对于 Q-Table 而言）。


## 5. Exploration、Exploitation、ε-Greedy

- **Exploitation（利用）**：选当前 Q 最大的动作。
- **Exploration（探索）**：尝试其他动作以获得新经验。
- **ε-Greedy**：以概率 $1-\epsilon$ 直接选 Q 最大的 Action；以概率 $\epsilon$ 在**所有合法 Action 中均匀随机选**，包含最优 Action。

假设 3 个动作，Right 唯一最优，$\epsilon=0.3$：

$$
P(\mathrm{Right})=0.7+\frac{0.3}{3}=0.8,
\quad P(\mathrm{Left})=P(\mathrm{Up})=0.1.
$$

**训练和部署：** ε-Greedy 通常用于**训练时选动作、收集经验**；部署或评测时一般设 $\epsilon=0$，直接选最优动作。在线持续学习是例外。

**它与 Q-Learning 的关系：**

1. ε-Greedy 选择本次实际执行的动作；
2. 环境返回 $(s,a,r,s')$；
3. Q-Learning 使用这次经验更新 $Q(s,a)$；
4. 重复。

即使本次因为探索而选了非最优动作，**Q-Learning 的下一状态 Target 仍使用 $\max_{a'}Q(s',a')$**。


## 6. Off-Policy vs. On-Policy

- **Behavior Policy（行为策略）**：Agent 实际按什么策略收集数据。
- **Target Policy（目标策略）**：算法希望评估/学习什么策略。
- **Off-Policy（离策略）**：两者可以不同。例如 Q-Learning 用 ε-Greedy 收集经验，却学习 Greedy 最优策略的 Q 值。
- **On-Policy（同策略）**：学习所用的目标与产生经验的策略一致。例如 SARSA。

假设下一状态 B：$Q(B,L)=4,\ Q(B,R)=8$，但 ε-Greedy 实际选了 L：

- **Q-Learning（Off-Policy）Target：** $r+\gamma\max(4,8)=r+8\gamma$。
- **SARSA（On-Policy）Target：** $r+\gamma Q(B,L)=r+4\gamma$。

> **Model-Free / Model-Based** 讨论“是否利用环境模型”；**Off-Policy / On-Policy** 讨论“行为策略与目标策略是否一致”。这是两条独立的分类维度。


## 7. Approximate Q-Learning（近似 Q 学习）

**动机：** State-Action Pairs 太多时，Q-Table 难存、难以泛化。改为学习**共享的 Weights**，通过 Features 计算 Q-Value。

**线性函数近似：**

$$
\boxed{Q(s,a)=\sum_i w_i f_i(s,a)}
$$

- $f_i(s,a)$ **始终是 Feature**（特征）。不同 $s,a$ 的 Feature Values 通常不同；
- $w_i$ 是在不同 State-Action Pairs 之间共享的 Weight；
- 因而不同 $(s,a)$ 即使共用一组 Weight，也能有不同 Q-Value。

例：$w_1=2,w_2=-1$：

- 若 $f(A,\mathrm{Right})=(2,0)$，$Q(A,\mathrm{Right})=4$；
- 若 $f(B,\mathrm{Left})=(3,0)$，$Q(B,\mathrm{Left})=6$。

### Target 和更新公式

Approximate Q-Learning 的 **Target 与普通 Q-Learning 相同**：

$$
\mathrm{Target}=r+\gamma\max_{a'}Q(s',a'),\qquad \delta=\mathrm{Target}-Q(s,a).
$$

不同的是：不直接改某个表项，而是改共享 Weight：

$$
\boxed{w_i\leftarrow w_i+\alpha\delta f_i(s,a)}
$$

**为什么乘 Feature？** 对于固定的 $(s,a)$，Feature Values 是常数。例如：

$$
Q=w_1(2)+w_2(3)\quad\Longrightarrow\quad
\frac{\partial Q}{\partial w_1}=2=f_1(s,a).
$$

这里**Feature 并没有变成导数**；只是 Q 对 Weight 是线性的，求偏导后的**结果刚好等于对应的 Feature Value**。

令平方损失 $L=\frac12(\mathrm{Target}-Q)^2$，将 Target 视为固定（semi-gradient），则

$$
\frac{\partial L}{\partial w_i}=-\delta f_i(s,a),\qquad
w_i\leftarrow w_i-\alpha\frac{\partial L}{\partial w_i}
=w_i+\alpha\delta f_i(s,a).
$$

### 完整小例子

给定 $w=(2,-1)$，$f(A,\mathrm{Right})=(2,0)$，所以原 Q 为 4。Agent 执行 Right 后到 B，实际得到 $r=5$。在 B：

$$
Q(B,L)=6,\quad Q(B,R)=1,\quad \gamma=0.5,\quad\alpha=0.1.
$$

1. Target $=5+0.5\max(6,1)=8$；
2. TD Error $=8-4=4$；
3. $w_1\leftarrow2+0.1\times4\times2=2.8$；
4. $w_2\leftarrow-1+0.1\times4\times0=-1$；
5. 新 Q：$Q_{\rm new}(A,\mathrm{Right})=2.8\times2=5.6$，**从 4 朝 Target 8 靠近**。

因为 Weight 是共享的，其他 $(s,a)$ 的估计 Q 也可能改变：这就是 Generalization。


## 8. 考前最容易混淆的 7 点

1. **$T$ vs. $\pi$**：$T$ 是环境“动作后去哪里”的概率；$\pi$ 是 Agent“选择什么动作”的概率。
2. **Reward vs. Value**：Reward 是当前一步奖励；Value 是累计折扣奖励的期望。
3. **$V$ vs. $Q$**：$V$ 只给 State 打分；$Q$ 给 State-Action Pair 打分。
4. **Model-Free 不等于没有神经网络**：它是不依赖 Environment Model（如 $T$）做规划。
5. **TD Target 不是正确答案**：它由实际 $r$ 和当前下一状态估计组合而成，可能不准确，会变化。
6. **ε-Greedy 的随机分支可能选中最优动作**；不是 $\epsilon$ 概率必选非最优动作。
7. **Feature 不等于导数**：在线性近似中 $\partial Q/\partial w_i=f_i$ 是求导的结果，不是 Feature 的定义。


## 9. 公式速查

| 算法 | 核心公式 |
|---|---|
| Bellman Expectation | $V^\pi(s)=\sum_a\pi(a\mid s)\sum_{s'}T(s,a,s')[R+\gamma V^\pi(s')]$ |
| Bellman Optimality / Value Iteration | $V_{k+1}(s)=\max_a\sum_{s'}T(s,a,s')[R+\gamma V_k(s')]$ |
| TD(0) | $V(s)\leftarrow V(s)+\alpha[r+\gamma V(s')-V(s)]$ |
| Q-Learning | $Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma\max_{a'}Q(s',a')-Q(s,a)]$ |
| SARSA | $Q(s,a)\leftarrow Q(s,a)+\alpha[r+\gamma Q(s',a')-Q(s,a)]$ |
| Approximate Q | $Q(s,a)=\sum_iw_if_i(s,a)$ |
| Approximate Q update | $w_i\leftarrow w_i+\alpha[r+\gamma\max_{a'}Q(s',a')-Q(s,a)]f_i(s,a)$ |
