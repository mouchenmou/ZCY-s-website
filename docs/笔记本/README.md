# CV课后作业：视频目标跟踪定位

本文件夹内完成了题目要求的三种传统 OpenCV 跟踪定位方法：RGB 区域生长、HSV 区域生长、直方图反投影。程序默认会自动选取当前文件夹中的第一个 mp4，从视频后半段开始处理，并以该帧中的章鱼主体作为初始目标区域。

## 文件说明

- `track_object.py`：主程序，读取视频并输出带三种方法定位框的结果视频。
- `requirements.txt`：普通 Python 环境需要安装的依赖。
- `outputs/tracking_result.mp4`：运行程序后生成的展示视频。

## 运行方法

在本目录打开终端，先安装依赖：

```bash
pip install -r requirements.txt
```

然后运行：

```bash
python track_object.py
```

程序会生成：

```text
outputs/tracking_result.mp4
```

如果要手动调整初始目标框，可以修改 `--roi` 参数，格式是 `x,y,w,h`：

```bash
python track_object.py --roi 230,245,250,160
```

如果只想快速测试一小段：

```bash
python track_object.py --max-frames 120
```

## 实现思路

1. 从视频总帧数的 50% 位置开始读取，符合题目中“后半段目标物”的要求。
2. 在起始帧设置一个初始 ROI，默认值为 `230,245,250,160`，覆盖后半段开始处的章鱼主体。
3. RGB 方法：在 BGR/RGB 颜色空间中，从上一帧目标中心点开始做 `cv2.floodFill` 区域生长，得到和中心颜色相近且连通的目标区域。
4. HSV 方法：把帧转到 HSV 空间，再从上一帧目标中心点做 `cv2.floodFill` 区域生长。HSV 对光照变化比 RGB 更稳一些。
5. 直方图反投影方法：在 ROI 中建立 H-S 二维颜色直方图，然后对每帧做 `cv2.calcBackProject`，找出和目标颜色分布相似的位置。
6. 三种方法得到的二值图都会做中值滤波、开运算、闭运算，保留类似“泛洪填充/连通域”的效果，去掉零散噪声并连接目标区域。
7. 每帧只在上一帧目标框附近扩大搜索，选择面积较大且距离上一帧中心较近的连通区域作为当前目标位置。

## 结果标注

输出视频中三种颜色框分别表示：

- 红色：RGB 区域生长定位。
- 黄色：HSV 区域生长定位。
- 绿色：直方图反投影定位。

这三种都是传统图像处理方法，没有使用 CamShift、MeanShift、AI 模型或网上现成识别结果。
