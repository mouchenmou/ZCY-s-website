## Bound Method
- All objects have attributes, which are name-value pairs.
    - 无论是类还是实例，它们在 Python 底层其实都像是一个“字典”，里面装着一对对的名字（Name）和具体的值（Value）。
    - Name: `'balance'` -> Value: `0`
    - Name: `'holder'` -> Value: `'Tom'`
- A class is a type (or category) of objects
- Classes are objects too, so they have attributes
    - `Account` 这个类本身也是个对象。它身上绑定的属性有什么呢？
     - Name: `'interest'` -> Value: `0.02`
    - Name: `'deposit'` -> Value: `<function deposit...>`
    - 可以像操作普通对象一样，对类进行赋值操作：`Account.interest = 0.04`
- Instance attribute: attribute of an instance
    - `tom_account.balance` 是实例属性
- Class attribute: attribute of the class of an instance
    - `Account.interest` 是类属性

## Methods and Functions
Python distinguishes between:

- Functions, which we have been creating since the beginning of the course.
- Bound methods, which couple together a function and the object on which that method will be invoked.
![](附件/Pasted%20image%2020260308223715.png)

## 1. `Account.deposit` 为什么是 function

```
Account.deposit
```

因为我们是通过**类 `Account`** 去获取 `deposit`。

这时 Python 只拿到了类中定义的原始函数：

```
def deposit(self, amount):
    ...
```

它还不知道 `self` 到底是哪一个账户，因此它只是一个普通的 `function`。

```
type(Account.deposit)
# <class 'function'>
```

调用时，你必须手动把对象传给 `self`：

```
Account.deposit(tom_account, 1001)
```

这里参数对应关系是：

```
self   = tom_account
amount = 1001
```

等价于进入函数后：

```
tom_account.balance += 1001
```

## 2. `tom_account.deposit` 为什么是 method

```
tom_account.deposit
```

这是通过一个具体对象 `tom_account` 获取 `deposit`。

Python 看到：

```
对象.类中的函数
```

就会自动把这个对象与函数绑定在一起：

```
tom_account + Account.deposit
              ↓
        bound method
```

即：

```
Object + Function = Bound Method
```

因此：

```
type(tom_account.deposit)
# <class 'method'>
```

这个 bound method 已经记住了：

```
以后调用我的时候，self 就是 tom_account
```

所以你只需要提供 `amount`：

```
tom_account.deposit(1007)
```

Python 会自动把它转换为类似：

```
Account.deposit(tom_account, 1007)
```

---

# 两种写法完全等价

```
Account.deposit(tom_account, 1007)
```

和：

```
tom_account.deposit(1007)
```

做的是同一件事。

区别只是：

### 通过类调用

```
Account.deposit(tom_account, 1007)
```

你要手动传入 `tom_account` 作为 `self`。

### 通过对象调用

```
tom_account.deposit(1007)
```

Python 自动把点号前面的 `tom_account` 作为 `self` 传进去。

也就是：

```
tom_account.deposit(1007)
```

可以近似看成：

```
Account.deposit(tom_account, 1007)
```

# 为什么一个叫 function，一个叫 method

因为它们处于不同状态。

## 原始函数

```
Account.deposit
```

只知道代码是什么，但不知道要操作哪个对象：

```
deposit(self, amount)
        ↑
还不知道 self 是谁
```

所以是：

```
function
```

## 绑定方法

```
tom_account.deposit
```

不仅知道代码，还知道对象是谁：

```
函数：Account.deposit
对象：tom_account
```

它已经把：

```
self = tom_account
```

绑定好了，所以叫：

```
bound method
```
