## 1. Assignment to Attributes
Assignment statements with a dot expression on their left-hand side affect attributes for the object of that dot expression（这句话的意思是，当你写出 `A.B = C` 这种代码时，点号左边的那个 `A`，就是你要修改或添加属性的目标。代码只会去改变 `A` 的肚子里的东西。）

- If the object is an instance, then assignment sets an instance attribute
- If the object is a class, then assignment sets a class attribute

## 3. Transaction 例子：共享的 class attribute

这个例子专门用来说明：**class attribute 不是每个实例各自复制一份，而是所有实例共享同一个值。**

```python
class Transaction:
    """A logged transaction.

    >>> s = [20, -3, -4]
    >>> ts = [Transaction(x) for x in s]
    >>> ts[1].balance()
    17
    >>> ts[2].balance()
    13
    """
    log = []

    def __init__(self, amount):
        self.amount = amount
        self.prior = list(self.log)
        self.log.append(self)

    def balance(self):
        return self.amount + sum([t.amount for t in self.prior])
```

这里最容易误解的是 `log = []`。它不是每个 `Transaction` 实例各自有一个空列表，而是整个 `Transaction` 类共享同一个列表。

执行：

```python
s = [20, -3, -4]
ts = [Transaction(x) for x in s]
```

过程是：

1. 创建 `Transaction(20)`：
    - `self.amount = 20`
    - `self.prior = []`
    - 把自己 append 到 `Transaction.log`
2. 创建 `Transaction(-3)`：
    - `self.amount = -3`
    - `self.prior = [第一个 transaction]`
    - 再把自己 append 到 `Transaction.log`
3. 创建 `Transaction(-4)`：
    - `self.amount = -4`
    - `self.prior = [前两个 transaction]`
    - 再把自己 append 到 `Transaction.log`

所以：

```python
ts[1].balance()
```

算的是：

```python
-3 + 20
```

得到 `17`。

而：

```python
ts[2].balance()
```

算的是：

```python
-4 + 20 + (-3)
```

得到 `13`。

### 我的疑惑：

`self.log.append(self)` 这里的 `self.log` 到底是在改实例属性还是类属性？

### 解答：

这里要分清楚两件事：

1. `self.log` 是一次属性查找。
2. `.append(self)` 是对找到的那个列表对象做修改。

因为实例自己没有 `log`，所以 `self.log` 会找到 `Transaction.log` 这个 class attribute。然后 `.append(self)` 修改的是这个共享列表本身。

这和下面这种赋值不一样：

```python
self.log = []
```

如果写成这样，左边是 dot expression 的赋值语句，会直接给当前实例新建一个 instance attribute，名字也叫 `log`。这样它就会遮住 class attribute。

## 4. Practice: Attributes

课件中的练习代码大概是：

```python
Foo = 1

class Foo:
    bar = 2

    def __init__(self, baz, qux):
        self.baz = baz
        Foo.bar = qux

    def a(self, x):
        self.bar = x

a = Foo(3, 4)
b = a.a
print(a.bar)
b(5)
print(a.bar)
Foo.bar = 6
print(a.bar)
```

### 执行过程

一开始：

```python
Foo = 1
```

这里 `Foo` 是全局变量，值是 `1`。

然后执行：

```python
class Foo:
    ...
```

这个新的 class object 会重新绑定名字 `Foo`，所以原来的数字 `1` 被覆盖了。

执行：

```python
a = Foo(3, 4)
```

调用 `__init__`：

```python
self.baz = 3
Foo.bar = 4
```

所以此时：

```python
Foo.bar == 4
```

而 `a` 自己没有 `bar`。

因此第一次：

```python
print(a.bar)
```

输出的是 class attribute：

```python
4
```

接着：

```python
b = a.a
```

这里 `b` 是一个 bound method，已经记住了 `self = a`。

所以：

```python
b(5)
```

等价于：

```python
Foo.a(a, 5)
```

也就是执行：

```python
self.bar = 5
```

这会给实例 `a` 自己添加一个 instance attribute `bar = 5`。

因此第二次：

```python
print(a.bar)
```

输出：

```python
5
```

最后：

```python
Foo.bar = 6
```

虽然 class attribute 被改成了 `6`，但是 `a` 自己已经有 instance attribute `bar = 5`，所以第三次：

```python
print(a.bar)
```

还是输出：

```python
5
```
