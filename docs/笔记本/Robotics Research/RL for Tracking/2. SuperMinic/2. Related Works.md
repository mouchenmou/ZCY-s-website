# SuperMimic — Section 2: Related Work 阅读笔记

## 0. 阅读本节前必须弄清的基本概念

SuperMimic 主要涉及三个组件：

|组件|本质|作用|
|---|---|---|
|Actor / Policy|神经网络|决定机器人执行什么 Action|
|World Model|学习动力学的神经网络|预测执行 Action 后，机器人状态会如何变化|
|Critic|价值网络|估计未来累计 Reward，辅助训练 Policy|

在 SuperMimic 的多目标控制架构中：

**Actor（Policy）= Goal Encoder + Shared Decoder。**

- **Encoder**：把参考动作或速度指令等目标转换为内部数字表示。
    
- **Decoder**：结合内部表示和机器人状态，输出关节 Action。
    
- **World Model**：不负责输出最终控制动作，而是用于训练 Actor。
    

SuperMimic 的训练循环：

1. Actor 在 MuJoCo Warp 中执行 Action，收集状态转移数据。
    
2. 用仿真数据训练 World Model。
    
3. 利用 World Model 预测未来运动，通过 BPTT 更新 Actor。
    
4. 重复上述流程，World Model 和 Actor 交替优化。
    

**Deployment（真实部署）时，运行的是训练好的 Actor，不需要 World Model 和 Critic 参与实时控制。**

## 1. Large-scale Physics-based Motion Tracking

### 核心问题：如何让机器人学会大量不同的人类动作？

**Physics-based Motion Tracking**：基于物理仿真的运动轨迹跟踪。

例如给机器人一段人类走路的动作轨迹，让机器人在物理仿真环境中学习跟踪这些动作。

这一节介绍三项已有研究：

- **DeepMimic**：通过 Model-free RL 学习复杂的角色运动技能。
    
- **PHC**：将这种运动模仿方法扩展到更大的动作集合，并提高恢复能力。
    
- **SONIC**：通过增加动作数据、Policy 容量和训练计算资源，学习可以覆盖大量动作的通用控制器，并迁移到真实人形机器人。
    

### Q1. 为什么这些方法需要大量 Simulator Rollouts？

**Simulator Rollout**：机器人在仿真器中连续执行 Action，产生一段状态、动作和奖励记录。

Model-free RL（例如 PPO）不显式学习一个预测物理运动的 Dynamics Model，而是依靠不断采样的结果来估计如何更新 Policy。

动作数据越多，需要覆盖的不同运动情况通常也越多，训练成本可能随之增加。

### Q2. SuperMimic 不也需要 Simulator Rollouts 吗？

**需要。SuperMimic 并没有取消物理仿真。**

区别在于：

- PPO：主要通过采样轨迹来估计 Policy Gradient。
    
- SuperMimic：利用仿真数据训练一个可微 World Model，再通过 World Model 的预测和梯度优化 Policy。
    

SuperMimic 的优势来自三个方面：

1. **Shared Dynamics（共享动力学）**：不同动作使用同一台机器人，遵循相同的物理规律，因此可以复用一个 World Model。
    
2. **Fast Imagined Rollouts（快速想象轨迹）**：World Model 可以比复杂物理仿真器更快地预测未来状态。
    
3. **Analytic Gradients（解析梯度）**：通过可微 World Model 使用 BPTT 更新 Policy，在论文的实验中比基于采样概率的梯度估计更高效。
    

论文报告：World Model 在实际使用的批量规模下，比 MuJoCo Warp 快 10 倍以上；在特定 PPO-WM 对照实验中，BPTT 方法使用约少 64 倍的想象步数达到对照方法的最佳训练回报。

**本节结论：SuperMimic 不是不要 Simulator，而是更高效地利用 Simulator 数据。**

## 2. Table 1 — 不同方法的训练流程对比

### 2.1 表格中的每一列是什么意思？

|英文|中文|通俗解释|
|---|---|---|
|Method|方法|哪篇论文提出的方法|
|Mimic|动作模仿|让机器人学习跟踪参考动作|
|Latent|潜在表示|学习神经网络内部使用的动作特征|
|Downstream|下游控制|利用已有运动能力完成新的控制目标|
|Task Signal|任务训练信号|用什么反馈训练下游控制接口|
|Real Robot|真实机器人|是否进行了真实机器人部署验证|

**注意：Mimic、Latent、Downstream 是作者为了比较不同方法而划分的环节，不意味着所有模型都必须分别训练三次。**

### 2.2 Latent 到底是什么？

Latent Representation（潜在表示）是神经网络内部用来表示信息的一组数字。

例如 Encoder 把参考动作转换成：

`z = [0.2, -0.5, 0.8, ...]`

这组数字可以交给 Decoder，让 Decoder 产生机器人关节 Action。

Latent 不是 Reward，也不是最后执行的 Action。

### 2.3 Downstream 到底是什么？

假设机器人已经学会跟踪人类走路动作。

现在我们希望它不再依赖完整的参考轨迹，而是接收新指令，例如：

“向前走，速度 1 m/s。”

利用已有运动控制能力完成这种新目标，就是 Downstream Control。

### 2.4 Task Signal 是什么？

**Task Signal：训练时用来判断做得好不好、指导网络更新的反馈。**

Table 1 主要比较两种：

- **RL / Task Reward**：看新任务完成得好不好，例如实际速度和目标速度有多接近。
    
- **Distill / Reference-tracking Signal**：看机器人能不能根据给定目标，重现参考动作。
    

这里的 Distill 是表格对参考跟踪式下游训练的归类，**不一定是 GALATEA 那种通过 BC + DAgger 合并多个 Expert 的策略蒸馏**。

### 2.5 Merged Cells 和 Unmerged Cells

- **Merged Cells（合并单元格）**：表示相关环节联合训练。
    
- **Unmerged Cells（未合并单元格）**：表示分阶段训练。完成前一阶段并冻结相关模型权重后，再训练下一阶段。
    
- **Freezing（冻结）**：保持网络参数不变，不再更新这些权重。
    

### 2.6 表格里的算法缩写

|缩写|全称|核心思想|
|---|---|---|
|PPO|Proximal Policy Optimization|通过采样得到的 Advantage 等信息优化 Policy|
|BC|Behavior Cloning|使用专家的 Observation–Action 数据进行监督学习|
|DAgger|Dataset Aggregation|Student 自己执行，Expert 为 Student 遇到的状态提供 Action 标签，不断增加训练数据|
|MBRL|Model-Based Reinforcement Learning|使用动力学模型辅助强化学习|
|SVG(0)|Stochastic Value Gradients|使用可微动力学的一步梯度及价值估计训练 Policy|
|A2C|Advantage Actor-Critic|利用 Actor 和 Critic，以及 Advantage 更新策略的强化学习算法|
|CGD|Classifier Guidance Diffusion|利用分类器指导扩散生成过程|
|RL|Reinforcement Learning|强化学习|

**BC 与 DAgger 属于模仿学习方法；PPO、A2C、SVG(0) 是具体的强化学习算法；MBRL 则是一大类强化学习方法。**

它们不是同一个层级的概念。

### 2.7 Table 1 中 SuperMimic 那一行

SuperMimic 使用 MBRL 进行联合训练，并支持：

- 使用参考运动跟踪信号训练下游 Goal Encoder。
    
- 使用下游任务自身的 Reward 训练 Goal Encoder。
    

论文还报告了真实 Unitree G1 运动跟踪控制器的部署结果。

## 3. Learned Differentiable Dynamics for Motion Control

**标题翻译：用于运动控制的、通过学习得到的可微动力学模型。**

### 3.1 Dynamics 是什么？

Dynamics（动力学）指机器人执行 Action 后，物理状态会如何变化。

例如：

当前膝关节弯曲 30°，执行某个 Action 后，下一时刻变成 33°。

这个状态变化就是动力学所描述的内容。

### 3.2 Differentiable 是什么？

Differentiable（可微的）表示可以求梯度。

如果预测下一状态的神经网络是可微的，我们就可以利用 Backpropagation 计算 Action 怎样影响未来运动和 Reward。

### 3.3 Surrogate 是什么？

Surrogate（替代模型）是用于近似另一个系统的模型。

例如：

- MuJoCo Warp：通过刚体物理规则计算下一状态。
    
- World Model MLP：通过学习的数据预测下一状态。
    

这里 World Model 可以充当物理仿真器的可微替代模型。

它不一定和真实仿真器完全一样，但可以辅助计算梯度。

### 3.4 作者介绍了哪些研究？

- **SuperTrack**：使用学到的可微仿真替代模型优化运动控制 Policy。
    
- **ControlVAE**：联合学习 Dynamics Model、内部运动表示和生成式控制器。
    
- **MoConVQ**：将学到的模型用于离散运动表示，扩展到数十小时运动数据。
    
- **SuperDyno**：将可微神经动力学扩展到数万段动作。
    

作者想说：以前已经有人证明学习可微动力学有用，而且已经有人研究如何扩大数据规模。

**SuperMimic 则进一步研究：这种方法能否在单张 GPU 上训练大规模人形机器人运动跟踪器，并部署到真实机器人？**

### 3.5 Q：World Model conditions on simulator context 是什么意思？

原文：

“its world model conditions on simulator context”

**Condition on = 将……作为模型的输入条件。**

Simulator Context 指仿真环境中的物理参数。

本文包括：

- Friction Coefficients：摩擦系数。
    
- Joint Calibration Offsets：关节校准偏移。
    
- Torso Center-of-mass Offset：躯干重心偏移。
    

为什么需要？

因为相同的 Action 在不同摩擦、重心等物理条件下，可能产生不同的运动结果。

所以 SuperMimic 的 World Model 不仅接收当前状态和 Action，还接收相关仿真物理参数：

`当前状态 + Action + Simulator Context → 预测下一状态`

### 3.6 Q：Deployed Actor uses noisy proprioceptive observations and a goal input 是什么意思？

- **Deployed Actor**：部署在真实机器人上的 Policy。
    
- **Proprioceptive Observations**：机器人通过自身传感器获得的身体状态信息，例如关节角度、关节速度、身体方向。
    
- **Noisy**：这些信息可能存在传感器测量误差。
    
- **Goal Input**：机器人要完成的目标，例如参考人体动作。
    

整句话的意思：

**World Model 在训练时利用额外的仿真物理参数，而真实部署的 Actor 则依靠自身观测信息和目标指令来输出 Action。**

### 3.7 Q：Throughput 是什么？

**Throughput（吞吐量）= 单位时间能够完成多少计算工作。**

**Rollout Throughput**：单位时间能够模拟多少个机器人运动时间步。

例如：

- 仿真器每秒计算 10,000 步。
    
- World Model 每秒预测 200,000 步。
    

那么 World Model 的 Rollout Throughput 是仿真器的 20 倍。（数字仅为示例）

作者评估三个因素对训练效率的贡献：

1. Model Accuracy：World Model 预测是否准确。
    
2. Rollout Throughput：World Model 运行速度是否足够快。
    
3. Differentiable Policy Updates：通过梯度更新 Policy 是否更高效。
    

**本节结论：重点讨论 World Model 的学习、预测能力和大规模应用。**

## 4. Model-based Policy Optimization and Robot Deployment

**标题翻译：基于模型的策略优化和机器人部署。**

### 4.1 这一节和上一节有什么区别？

- **上一节**：主要关注如何学习可微动力学，以及这种模型能否扩展到大量动作。
    
- **这一节**：主要关注有了动力学模型之后，如何利用它优化 Policy，以及能否应用于真实机器人。
    

两节存在交叉，不是两个独立的算法步骤。

### 4.2 Dreamer / DreamerV3

作者说它们学习 **Latent Dynamics** 并进行 Imagination-based Actor–Critic Learning。

**Latent Dynamics**：预测神经网络内部的状态表示怎样随着 Action 改变。

例如：

`当前 Latent State + Action → 下一时刻 Latent State`

**Imagination-based Learning**：使用 World Model 模拟未来的状态和 Reward，再利用这些预测训练 Actor 和 Critic。

Dreamer 和 DreamerV3 体现了这种思路。

### 4.3 TD-MPC

作者强调两个概念：

**Short-horizon Planning（短期规划）**：只预测未来有限几个时间步。

**Terminal-value Prediction（末端价值预测）**：让 Value Function 估计这些步骤之后还能获得多少未来回报。

例如预测未来 3 步：

- 第一步 Reward = 2。
    
- 第二步 Reward = 3。
    
- 第三步 Reward = 1。
    

假设忽略折扣，前三步奖励合计为 6。

但任务没有在第三步结束，因此再用 Critic 估计第三步后的未来回报，例如 10。

这样得到的目标可以利用 `6 + 10` 这样的结构，兼顾短期奖励与之后的预期结果。

注意：这只是教学示例，真实算法会考虑折扣等因素。

### 4.4 DayDreamer

DayDreamer 展示了可以直接使用真实机器人数据学习 World Model。

而 SuperMimic 主要用物理仿真器生成的数据训练 World Model。

### 4.5 SHAC

**SHAC 使用可微物理仿真器进行短期 Actor–Critic 更新。**

关键区别：

- SHAC：通过可微仿真器计算梯度。
    
- SuperMimic：通过学到的可微 World Model 计算梯度。
    

这意味着 SuperMimic 不要求 MuJoCo Warp 自身能够进行 Backpropagation。

### 4.6 Critic-bootstrapped Objective 是什么？

**Bootstrap** 在这里是利用已有的价值估计，补充没有直接模拟到的未来回报。

假设 World Model 只预测未来 32 步。

但机器人任务可能持续超过 32 步。

于是 SuperMimic 使用 Critic 估计第 32 步之后的未来累计 Reward。

这样 Policy 不只优化眼前 32 步，还能考虑之后的未来结果。

### 4.7 High-fidelity Forward Simulator 是什么？

- **High-fidelity**：高保真的，尽量准确地反映物理现象。
    
- **Forward Simulator**：输入当前状态和 Action，向前计算下一状态的仿真器。
    
- **Simplified Surrogate**：简化的替代模型。
    

作者介绍一种已有研究方向：结合高保真物理仿真器和简化的可微替代模型，让物理计算和梯度计算分别发挥作用。

### 4.8 RWM / RWM-U 和 SuperMimic 的区别

这是本节最重要的比较。

||RWM / RWM-U|SuperMimic|
|---|---|---|
|是否学习 World Model|是|是|
|如何更新 Policy|使用 PPO|使用 BPTT|
|World Model 数据来源|预先使用其他 Policy 的轨迹|训练过程中由当前 Policy 持续收集|
|是否能迁移到真实机器人|论文报告可以|论文报告可以|

**RWM / RWM-U** 使用 World Model 产生 Imagined Rollouts，但仍通过 PPO 更新 Policy。

**SuperMimic** 则直接对 World Model 预测的累计回报求梯度，通过 BPTT 更新 Policy。

因此：

**有 World Model 不代表必须使用 BPTT。World Model + PPO 也是一种 MBRL 方案。**

RWM-U 另外采用了 Uncertainty-penalized Offline Optimization，即在离线优化中对不可靠的模型预测引入不确定性惩罚。

### 4.9 Q：World Model 不是已经学好了吗？为什么还要训练？

SuperMimic 的 World Model 不是一次性预训练完就固定不变。

它的训练循环是：

`Simulator Collect → Fit World Model → Improve Policy → 再次 Collect`

Policy 不断改变，收集到的数据也不断更新，World Model 因而持续学习。

**本节结论：SuperMimic 利用持续学习的 World Model，以 BPTT 代替 PPO 的策略梯度估计来优化 Actor。**

## 5. Reusable Motion Representations and Downstream Control

**标题翻译：可复用的动作表示和下游控制。**

### 5.1 这一节究竟研究什么？

假设机器人已经学会跟踪大量走路、跑步、跳跃动作。

现在希望它完成新任务，例如：

“向前走，速度 1 m/s。”

我们希望它复用已有的运动控制能力，而不是从零训练。

### 5.2 相关工作

- **NPMP / PhysicsVAE**：从 Expert Behavior 中学习内部运动表示。
    
- **PULSE / LATENT**：利用学到的运动表示，进一步通过 RL 学习下游任务。
    
- **MaskedMimic**：通过 Motion Inpainting（动作补全）支持部分身体目标等多种目标形式。
    
- **BeyondMimic**：通过 Guided Diffusion（引导扩散）实现目标控制。
    
- **SONIC**：联合训练 Goal Encoder 和运动跟踪控制器，使用 Motion Tracking Reward 与 Latent Alignment Loss。
    
- **ControlVAE**：冻结已有技能控制器，利用学到的模型优化下游 Policy。
    

### 5.3 SuperMimic 的 Actor 到底是什么结构？

**Actor = Encoder + Decoder。**

其中：

**Motion Encoder**

输入：未来 10 帧参考动作。

输出：32 维 Latent Representation。

**Velocity Encoder**

输入：速度指令 `(vx, vy, ωz)` 以及最近的 Observation 特征。

输出：32 维 Latent Representation。

**Shared Decoder**

输入：Encoder 输出的 Latent，以及机器人最近的身体状态观测。

输出：29 维 Action。

所以不是 Actor、Encoder、Decoder 三个彼此独立的控制器。Encoder 和 Decoder 组合起来才是完整的 Actor。

### 5.4 Q：Encoder 输出一组数字以后，干什么？

例如目标是向前走 1 m/s。

1. Velocity Encoder 接收速度指令。
    
2. Encoder 将目标转换成 32 维数字 (z)。
    
3. Decoder 接收 (z) 和机器人当前及最近的 Observation。
    
4. Decoder 输出 29 维关节 Action。
    
5. 机器人执行 Action，并读取新的 Observation。
    
6. 重复控制过程。
    

**Encoder 负责表达目标；Decoder 负责生成 Action。**

### 5.5 Q：目标指令从哪里来？

不是 World Model 自己凭空生成的。

**Motion Tracking：**

训练程序从人体参考动作数据集中读取 Goal。

**Velocity Tracking：**

训练程序提供目标速度 `(vx, vy, ωz)`。

论文 Appendix G 明确说明，RL Velocity Encoder 的训练指令来自两种来源：

- 从参考运动中读取速度指令。
    
- 在指定范围内随机采样速度指令。
    

作者分别以 50% 的概率选择这两种来源，并按训练设置重新采样指令。

部署时则需要由外部控制系统提供相应格式的目标。

### 5.6 Q：为什么只有两个 Encoder？

**这是论文实际训练和测试的主要接口，不是架构规定只能有两个。**

Appendix B 还列举了其他可能的目标类型：

- End-effector Poses：机械臂或人体末端部位的位置和姿态目标。
    
- SMPL Body-pose Target：人体参数化姿态目标。
    

理论上可以增加新的 Goal Encoder，但需要设计对应的输入、奖励和训练过程。

原论文并没有证明任意新 Encoder 都能自动完成对应任务。

特别是自然语言指令，例如“拿起杯子”，不能直接认为现有 Velocity Encoder 可以理解。

### 5.7 Q：为什么两个 Encoder 可以共享 Decoder？

因为两个 Encoder 最后都输出相同格式的内部表示 (z)。

共享 Decoder 接收这些表示和机器人自身状态，再输出 Action。

但**相同维度不意味着新 Encoder 天然与 Decoder 兼容**，仍然需要通过训练使其输出有意义的特征。

### 5.8 Q：Distillation 和 RL-trained Encoder 有什么区别？

论文研究了两种训练 Velocity Encoder 的方法。

**Distillation Baseline：**

从参考动作获得速度指令，利用 Motion Tracking Reward 训练 Velocity Encoder，使机器人尽量重现参考动作。

**RL-trained Encoder：**

利用 Velocity Tracking Reward，直接训练 Velocity Encoder，让机器人尽量准确达到目标速度。

两种方法都通过 World Model 优化，而不是一个用 World Model、另一个不用。

论文实验中，RL-trained Encoder 在 672 个速度指令测试中的 650 个测试上具有较低的稳态误差。

### 5.9 Q：下游 Encoder 训练时 Shared Decoder 也更新吗？

根据 Appendix B：

下游任务的 Reward 梯度可以通过 Shared Decoder 传递到对应 Encoder，但会阻止这部分梯度更新 Decoder 的权重。

**Shared Decoder 仍然通过 Motion Tracking 目标训练。**

因此，不能简单理解为速度任务奖励会同时更新 Encoder 和 Decoder 的所有参数。

### 5.10 Q：World Model 在 Deployment 时还需要吗？

在 SuperMimic 原论文的部署方式中，不需要。

**训练时：**

`Actor → Action → World Model 预测 → Reward / BPTT → 更新 Actor`

同时持续使用仿真器数据训练 World Model。

**部署时：**

`Goal + Observation → Actor（Encoder + Decoder）→ Action`

真实机器人运行的是训练好的 Actor，不需要通过 World Model 在每一个控制时间步进行预测或优化。

注意：这是 SuperMimic 的设计，并不代表所有 MBRL 方法都只在训练阶段使用 World Model。

**本节结论：SuperMimic 希望复用已经学到的运动控制能力，通过新的 Goal Encoder 支持其他控制目标，并且可以直接利用新任务自身的 Reward 训练这些 Encoder。**

## 6. 与 GALATEA 迁移方案的关系

### Q：GALATEA 不是有两次 Policy Distillation 吗？

严格来说，不是。

**SAPG 阶段：**

多个具有不同探索设置的 PPO Policy / Agent 参与训练，通过经验聚合和策略优化更新共享策略。

这不等同于 BC 意义上的 Teacher–Student Policy Distillation。

**Multi-skill Expert 阶段：**

GALATEA 按不同物体类别及轨迹组训练多个 Expert Policy。

**最终 Policy Distillation：**

通过 BC 将多个 Expert 合并成 Unified Policy，再通过 DAgger 进行微调。

所以：

`SAPG/PPO → 多个 Experts → BC + DAgger → Unified Policy`

### Q：迁移 SuperMimic 后，还需要蒸馏吗？

按照目前与学长讨论的方案，**保留最终的 BC + DAgger**。

计划：

`SuperMimic-style MBRL → 按物体类别训练 Experts → BC + DAgger → Unified Policy`

要替换的是训练 Expert 的 SAPG/PPO，而不是必然取消最后的策略蒸馏。

SuperMimic 原论文直接训练统一运动跟踪 Policy 的设计，和目前准备尝试的 GALATEA 多 Expert 方案并不相同。

### Q：直接取消多个 Expert，训练一个 Unified Policy 行不行？

可以作为另一条研究方向，但不能假定一定更好。

SuperMimic 主要研究的是人形机器人运动跟踪。GALATEA 的灵巧手操作还涉及手指与物体的复杂碰撞、接触、摩擦、滑动和抓取。

这些动力学更难预测。

而 SuperMimic 原论文也将物体交互列为尚未完成的扩展方向。

因此，当前优先验证：

**World Model + BPTT 能否在单个 GALATEA Expert 上稳定训练，并获得优于 SAPG/PPO 的效率或效果。**

## 8. 本节最终总结

Section 2 Related Work 主要讨论四个问题：

**① Large-scale Physics-based Motion Tracking**

如何让机器人学会大量不同的参考动作？为什么传统 Model-free RL 需要大量仿真采样？

**② Learned Differentiable Dynamics**

能不能学习一个快速、准确、可微的 World Model，并把它应用于大量动作？

**③ Model-based Policy Optimization**

有了 World Model，怎样利用它更新 Policy？SuperMimic 为什么选择 BPTT，而不是 PPO？

**④ Reusable Motion Representations and Downstream Control**

能否复用已经学到的运动能力，让机器人通过新的 Goal Encoder 理解不同类型的控制目标？

### 最重要的三个认识

1. **SuperMimic 的 World Model 用于训练 Actor，部署时主要运行训练好的 Actor。**
    
2. **Actor = Goal Encoder + Shared Decoder；Decoder 负责输出 Action，World Model 负责预测 Action 的后果。**
    
3. **SuperMimic 的核心不是首次发明 World Model，而是使用共享的可微 World Model 和 BPTT，高效学习大规模人形机器人运动跟踪策略，并探索可复用的下游控制接口。**
