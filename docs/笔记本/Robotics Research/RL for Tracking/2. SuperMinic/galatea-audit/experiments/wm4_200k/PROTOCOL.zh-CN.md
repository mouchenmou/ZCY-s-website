# 四组 Power Drill WM 对照：执行协议

本文件取代首轮报告中的3/12条、20万/80万矩阵。用户已授权在环境及必要检查通过后执行，无需再次批准设计。

- A/B/C/D：3/12/20/30条嵌套集合；A固定g16/g25/g26。
- 每组恰好200000条真实控制周期transitions，各自从零初始化WM；不加载旧WM。
- 测试隔离：g3、g9、g14、g22、g33。按固定salt的ID哈希抽取，不依据轨迹特征或性能；详见split_lock.json。它们不得进入归一化、调参、容量/预算选择或训练。
- 其余30条用于候选筛选；B/C排序只使用这30条的参考运动与参考接触/有效reset特征。B/C ID已固定于nested_groups.json，实际PhysX接触覆盖仍须独立统计，不能把参考接近判为真实接触。
- 原三条内的独立episode测试与五条未见Motion测试分别汇报；两者均与训练episodes及窗口隔离。
- 各组保持结构、loss、初始化seed、采集方式、探索策略、更新步数、batch与优化器相同；归一化只能来自各自训练数据，规则一致。
- 不进行Actor训练或BPTT，不新增Response Loss，不修改环境Reward、Termination和Critic，不扩大到80万。
- 20万按均衡配额分配：A平均66666.7、B16666.7、C10000、D6666.7条/Motion；余数按冻结顺序分配。总配额不含独立测试数据与预检数据。
- 采集检查保存command、delay后动作、实际PD target、控制history、mask及其变化、真实物理参数、reset/terminal标记；窗口不跨episode。
- 8/32步按当前30Hz对应0.267/1.067秒。官方referenceFps=60保持原样，先记录含义，不能把它当作控制频率。
- 核心评价：手指方向/响应幅度、q/qd、指尖、物体平移旋转、pad接触、8/32步误差、Reward差方向；与persistence及简单恒速基线比较。
- 数据覆盖：command与实际PD target均统计，独立接触episode/事件、首次/持续/释放/无接触阶段分别统计；不能把逐帧contact数量当独立事件。
- 固定测试集只用于完成四组后的最终比较；程序正确性和预算pilot只使用训练候选中的独立预检episodes。最终看到结果后不再改超参重跑本轮。

## 尚需通过的运行门槛

1. GPU PhysX基础smoke、MANO与官方loader、g16小规模环境运行。
2. 原始控制到物理标签的接口检验；四组共用一套修复后的实现。
3. 训练候选参考/接触诊断后冻结嵌套ID。
4. 采集器和WM在本机的吞吐与总显存实测；据此确定统一更新次数、硬时间上限、checkpoint间隔。
5. 2026-11-05用户明确取消全部实例外备份要求；数据、checkpoint和日志仅保存在当前服务器本地。

基础PhysX smoke的吞吐不能用作完整GALATEA或WM训练预算。外部备份不再是运行门槛。

## 预训练采集器的隔离问题

官方Expert可能在全部35条Motion上训练，其输入归一化也可能包含五条测试Motion。若使用它，只能称WM拟合数据留出，不能称整个管线完全未见测试。为遵守本轮严格隔离，不能未经处理直接把该Expert及其归一化用于正式采集器；正式采集方式须在训练候选上确定，并记录是否含预训练知识。官方Expert在g16上的环境兼容性检查与本轮训练数据分开。

## 2026-11-05正式执行补充（看到独立测试结果之前冻结）

- 外部备份要求已由用户撤销；本轮不配置R2、不上传文件，所有输出在local_run/。
- 正式数据是每组200000条有效训练转移；reset后的首步因刚体状态尚未完整刷新而不作为训练起点。原始仿真步数（含这些预热步及均衡配额之外的步）另行记录，不能宣称真实交互成本恰好等于200000。
- 采集使用120环境、固定每环境Motion、每条Motion均衡配额；脚本策略为arm reference tracking加固定分布的相关探索噪声，手指使用统一部分张开基准加相关噪声。不加载或训练Actor，不加载官方Expert归一化。沿用已通过预检的完整重力和constant tightening设置；官方Reward/Termination代码没有修改。
- 新WM是709维输入、292维状态、3×2048 SiLU MLP（10447141参数），显式复用正确的PD控制映射。输入包含动作、控制历史、已采样的延迟/mask、实际质量和随机化参数、当前Reference；输出为连续状态残差、5个pad-contact概率及官方原始Reward监督值。不是旧WM的恢复，也不是SuperMimic作者完整实现。
- 归一化只在各组被选入的200000条训练转移上计算。相同seed=45初始化；Adam默认参数、lr=0.0003、batch=128、5000更新；8步自回归状态/接触/Reward监督，窗口在reset边界截断；没有Response Loss、termination head或Actor/Critic更新。
- 动力学误差按q、qd、物体位置/旋转/速度、手部位置/速度、腕姿态、接触力及力矩10块等权求均值；训练数据的单步变化标准差用于缩放。Contact使用BCE，Reward使用归一化MSE，三项权重均为1。
- 预测时延迟和mask随机结果作为已知外生条件；每步从预测q和预测控制历史重算PD target，不输入未来真实状态或未来真实PD target。因此本轮测的是具有已知控制随机性的条件WM，不能直接证明边际化未知延迟后的Actor BPTT可用。
- 全部四组训练结束后才生成和使用共同测试集；core与unseen的种子均独立于采集和pilot。每个split、每个horizon最多2048个冻结抽样窗口；8/32步普通误差只包含不跨reset的合法窗口，需报告可用窗口数以显示存活选择偏差。
- 受控响应测试采用新建PhysX进程并完整重放相同seed、参数和历史，比较base/repeat/plus/minus；首8步对每个案例的一个手指动作加减0.2，然后撤回到共同的基准命令。不是只恢复q/qd。另行报告官方Termination之前的案例，以及不reset但继续物理演化的全部诊断分支；后者不能当作有效任务episode或Actor成功。
- 硬预算为全流程45分钟、40GiB显存、local_run目录20GiB、磁盘至少保留20GiB；单组采集/训练各10分钟上限。超过则停止，不自动扩大预算。每500次更新或5分钟保存本地Checkpoint；已完成模型做读回前向一致性验证。完整冻结配置见execution_lock.json。
- 这是单一训练seed、单一嵌套集合的首轮对照。episode bootstrap区间仅表示固定Motion集合上的采样误差，不表示跨训练seed或跨Motion划分的不确定性。
