# SuperMimic / GALATEA：动作噪声到底加在哪、起什么作用

> 这份笔记整理自一次关于两篇论文的长讨论，核心问题是：**训练时给动作加的噪声，到底加在流程的哪个位置、分别起什么作用、和"抗干扰能力"是什么关系。**

---

## 0. 先认清是哪两篇论文

| 名字 | 出处 | 一句话概括 |
|---|---|---|
| **SuperMimic** | Berkeley，CoRL 2026，arXiv 2610.28480（Qiayuan Liao 等，BeyondMimic 同组） | 人形机器人（Unitree G1）全身动作跟踪。学一个**可微的 world model** 代替仿真器给策略求梯度，单卡 3 小时超过 128 卡训 7 天的 SONIC |
| **GALATEA** | Berkeley + Sharpa Robotics，arXiv 2609.10050 | 灵巧手（Franka 臂 + Sharpa Wave 手）。用**生成视频**重建出手-物参考轨迹，在仿真器里直接用 **SAPG（PPO 一族）** 训练跟踪控制器。**它没有 world model** |

注意：arXiv 上还有一篇港科广的 "Super-Mimic"（2509.22205，人类视频 + 视频生成做零样本操作规划），和本笔记讨论的 Berkeley SuperMimic **同名但完全是两回事**。

## 1. 基础概念（完全不懂 RL 也能看）

- **大脑（策略 / actor）**：一个神经网络。输入 = 机器人当前身体状态 + 要模仿的参考动作；输出 = 发给每个电机的命令（29 个关节一次性全部输出，不是一次动一个）。
- **仿真器**：电脑里按物理定律算的"假机器人"程序。输入 = 当前状态 + 电机命令；输出 = 0.02 秒后的新状态。它是个**黑盒**：只能喂进去、读出来，不能问它"命令改一点结果会怎么变"。
- **world model**：另一个神经网络，任务是**模仿仿真器**（输入输出和仿真器一样）。它是个**透明的公式**：电脑可以沿着公式倒推出"命令改一点点，结果/分数会怎么变"。
- **打分（reward）**：一段运行跑完后，按"离参考动作有多近、摔没摔"等算一个分数。
- **调大脑（训练）**：根据分数调整大脑网络的参数。规则只有一条：**把大脑往"在打分发生的那个世界里，平均分最高的习惯"上调。**
- **一次更新的粒度**：不是每走一步调一次，而是每条轨迹连续走一段（SuperMimic 想象 32 步）后调一次；同时有几千条轨迹（如 4096 个并行环境）在跑，每条轨迹每一步**各自独立**抽一次噪声，不存在"同一步试好几次"。
- **reference 条数 vs 并行环境数**：两个不相干的数。BONES-SEED 过滤后有 129,514 条动作片段，LAFAN1 只有 40 条；4096 是**同时跑的机器人个数**，每个机器人重置时被分到某条片段的某个时间点。

## 2. 为什么 SuperMimic 比 PPO 快 1000 倍（和噪声无关，先说清）

两边都是几千条支线同时跑、每条支线每步只执行一次。区别在**每条支线跑完后能带回多少信息**：

- **PPO（仿真器是黑盒）**：一条支线跑完只得到一个模糊信号——"这次总分比预期高/低了一点"。但这一段里 29 个关节 × 几十步全在动，分数好坏是谁的功劳分不出来，只能靠海量支线 + 几十万轮更新把趋势**统计平均**出来。方向模糊，所以每次只敢小步更新。
- **SuperMimic（world model 是公式）**：一条支线（想象 32 步）跑完，电脑沿公式**倒推一遍**（BPTT），直接得到"每一步、每个关节，各自该往哪调、调多少"，32×29 个精确方向，一次计算全部拿到，不靠统计。

论文数字：
- 同在 world model 里，"倒推方向"比"PPO 试方向"达到同样回报少用约 **64 倍**练习步数；
- world model 跑一步比 MuJoCo Warp 快 **10 倍以上**；
- PPO 从 4 卡加到 8 卡几乎没提升；SuperMimic 1 卡 1.2h 超过 PPO 8 卡 18h；
- 最终：1 张 H100 × 3h 超过 SONIC 128 张 L40 × 168h。

**仿真器没有被丢掉**：它从"练习场"变成了"给 world model 出教材的地方"。

## 3. ★ 三种加噪声方式的完整流程对比（本笔记的核心）

> 噪声 = 大脑说 30，实际执行变成 30 + 随机数（如 33）。真机上它天然存在（电机有延迟、磨损，说 30 执行不到精确的 30）；训练里是人为写一行代码模拟它。

### 方式一：PPO / GALATEA（没有 world model，只有一条线）

```
┌────────────── 一轮训练 ──────────────┐
第1步  大脑看状态，输出命令 30
第2步  加噪声：30 → 33                ← 噪声在这
第3步  仿真器执行 33，走到新状态
       （回到第1步，连走一段）
第4步  这段运行结束，打分
第5步  用分数调大脑：
       "你想说30，这次抽到33，分数比预期高
        → 以后往33靠；低 → 往反方向躲"
└────────── 回到第1步，下一轮 ──────────┘
```

- 仿真器里这段运行**直接被打分、直接用来调大脑**。
- 打分时 30 和 33 **都用到**：33 决定运行结果，30 是"被调整的那个习惯"。
- **噪声夹在"大脑输出"和"打分"之间 → 大脑的成绩受抖动影响 → 大脑在"会抖的世界"里被打分。**

### 方式二：SuperMimic 原版（论文的实际做法，三个环节 A/B/C）

```
┌──────────────── 一轮训练（A、B、C 都做）────────────────┐

【A. 采数据】（地点：仿真器）
A1  大脑看状态，输出命令 30
A2  加噪声：30 → 33            ← 全流程唯一一处动作噪声
A3  仿真器执行 33，走到新状态
A4  往 replay buffer 抄一行：
    （刚才的状态，执行了33，变成了什么/得了几分/摔没摔）
    ★ 抄的是 33，30 没抄 —— 不是记不下来，是这个环节不需要 30：
      物理规律只取决于"实际执行了什么"
A5  到此结束。这段运行【不打分、不调大脑】，跑完就只剩存档。

【B. 教 world model】（地点：buffer → world model，只改 world model）
B1  从 buffer 抽连续 8 步
B2  world model 从第一步的真实状态出发，按记录的命令（33等）
    自回归推算 8 步（自己的预测喂回自己）
B3  推算结果 vs 存档真值（状态/奖励/观测/终止），差哪补哪
B4  ★ 这一步训练的是 world model，不是大脑。
    world model 学到的是"发33→33的结果"，一个【说多少执行多少、
    完全不抖的世界】——噪声在写存档那一刻就被"洗掉"了，
    因为存的是抖完之后的数。

【C. 调大脑】（地点：world model 里，"想象"，world model 冻结）
C1  从 buffer 抽一个状态当起点
C2  大脑看状态（会加回观测噪声 η），输出命令 30
C3  world model 按 30 【原样】推算下一状态
    ★ 这里没有"加噪声"那一行，论文公式是
      a_t = π_θ(ô̄_t + η_t, g_t)，ŝ_{t+1} = f_ω(ŝ_t, a_t, ξ)
      动作噪声 ε 只出现在 A（"During data collection"）
    （C2~C3 连走 H=32 步）
C4  给这段想象的运行打分（BeyondMimic 跟踪奖励 + critic 补 32 步之后）
C5  沿 world model 倒推梯度（BPTT），精确调大脑；ω 不动
└───────────────── 回到 A，下一轮 ─────────────────┘
```

- **噪声在 A，打分在 C，不在同一个环节。** 大脑的每一次成绩都是在"说 30 就执行 30"的世界里测的。
- 所以大脑从没体验过"说 30 却执行了 33"，**练不出对执行抖动的防备**。

### 方式三：SuperMimic + 想象里加噪声（讨论中自己推出的改法，论文没做）

A、B 与方式二完全相同，只在 C 里加一行：

```
【C'. 调大脑】
C1  从 buffer 抽起点
C2  大脑输出命令 30
C2.5 加噪声：30 → 33           ← 新增的唯一一行
C3  world model 按 33 推算
    （每步都各抖一次，连走32步）
C4  打分
C5  调大脑（梯度照常回传：33 = 30 + 噪声，这次抽到的噪声
    是个改不了的定数，"33该变小"自动等于"大脑输出该变小"）
```

- 打分的运行里重新有了抖动，**大脑又在"会抖的世界"里被打分了**，这一点上和 PPO 等效。
- A 里的噪声仍要保留：想象里会执行 33 附近的数，world model 必须在那附近学准过。

### 三种方式一张总表

| | 仿真器里有噪声吗 | 调大脑发生在哪 | **调大脑（打分）的那段运行里有噪声吗** | 大脑学到的形态 |
|---|---|---|---|---|
| 方式一 PPO / GALATEA | 有 | 仿真器（同一段运行） | **有** | 会抖世界的最优：留余量 |
| 方式二 SuperMimic 原版 | 有 | world model（环节 C） | **没有** | 不抖世界的最优：贴极限 |
| 方式三 想象里加噪声 | 有 | world model（环节 C'） | **有** | 同方式一 |

> **一句话判据：大脑在哪个世界里被打分，就长成哪个世界的最优形态。**

## 4. 讨论中卡壳最久的几个点（Q&A）

### Q1. "SuperMimic 明明也在仿真器里加了噪声，怎么就说大脑没感受到？"
因为 **SuperMimic 的大脑不在仿真器里上课**。仿真器那次"执行 33"的运行跑完只做一件事：存档（33 → 结果），**一个分都没打过，对大脑参数零影响**。大脑被打分、被调整全部发生在环节 C（想象），而 C 里没有加噪声那行代码。
- PPO：仿真器里的运行 **=** 大脑的练习 → 仿真器的噪声大脑直接感受到
- SuperMimic：仿真器里的运行 **≠** 大脑的练习 → 仿真器的噪声与大脑无关

### Q2. "为什么 30 没被存下来？GALATEA 怎么就能用到 30？"
不是"能不能记"，是**各自的用途不同**：
- PPO 调大脑的那句话是"你**本来想说 30**，这次试了 33，分数不错 → 往 33 靠"。这句话离了 30 说不出来，所以必须记 30。
- SuperMimic 的仿真器运行只回答物理问题"执行 33 会怎样"，物理只看实际执行的 33，大脑心里想的 30 不影响结果（朝墙扔球，墙只管球实际的速度），记了也没人用。

### Q3. "直接用 30 配上执行 33 的结果去训 world model 不就有噪声了？"
可以这么做，但那是**另一种设计**：world model 会把噪声"吸收进世界"，学到"说 30 有时会得到 33 的后果"。论文没这么做——它要的是**准确的物理计算器**，存（30 → 33 的结果）等于教它一条错误物理规律。
所以关键从来不是"噪声加在哪个设备里"，而是：**world model 的教材里，命令写的是"喊的"还是"实际执行的"。** SuperMimic 写的是"实际执行的"，噪声对大脑就消失了。

### Q4. "想象里加噪声后，梯度怎么还能传回 30？万一最优是 32，这次抽到 +3 执行 33，推出'该变小'，30 不就被推得更偏了？"
- **传回 30**：计算图里存着算式 `命令 = 大脑输出 + 噪声 = 30 + 3`。这次抽到的 +3 是个**定数，改不了**，算式里唯一能动的是大脑输出，且大脑输出减 1 命令就减 1，所以"命令该减" ≡ "大脑输出该减"。
- **单次会推错，没错**：抽到 +3 那次确实把 30 往更偏的方向推了。但每次只挪极小一步，同一情形被经历成千上万次：30 在最优点 32 左边，噪声 ±3 对称，执行结果落在 32 **左边的次数更多**（要抽到 +2 以上才会到右边），且偏得越远"往回"的劲越大。海量小步平均下来，净效果是往 32 挪，到 32 附近左右打平、停住。**错误推导被正确推导在平均中淹没**——PPO 的单次方向比这更不可靠，同样靠平均。

### Q5. "抗干扰能力到底是什么？为什么打分世界有抖动就能练出来？"
抗干扰不是一种被单独教的技能，**它就是"留余量"这个输出习惯本身**。
- 设定：目标点贴着"越线就摔倒（大负分）"的线，执行有 ±3 的抖动。
- **不抖的世界**：最优习惯 = 正好踩在目标点上（贴线）。反正永远不偏，贴线满分。
- **会抖的世界**：贴线的习惯每次随机偏一下，偏过线的那些次大负分，**平均分很低**；"离线远一点"的习惯怎么抖都不越线，平均分反而高。
- 训练只认平均分 → 在会抖的世界里打分，摔倒的大负分把大脑一次次往后推，自动长成"留余量"。**没人教它抗干扰，是摔出来的。**
- 真机 ≈ 会抖的世界（电机不精确），所以"留余量"的大脑上真机不摔，"贴线"的隔三差五摔——这就是"抗干扰更好"的全部含义。
- 直觉版（也成立）：打分带噪声 = 优化"一个范围内的平均表现"；不带 = 只优化"一个点"。真机执行本来就落在一个范围里。

### Q6. "那环节 A 的噪声到底图什么？干脆别加？"
不能不加，**A 的噪声是环节 C 能工作的前提**，但和抗干扰无关：
- 大脑是确定性的：同一状态永远输出同一个数。不加噪声，buffer 里每个状态只配一个命令（永远是 30），world model 只见过 30——它知道"发 30 会怎样"，但"发 29/31 会怎样"只能瞎猜。
- 而 C 调大脑问的恰恰是"**命令改一点点，结果会怎么变**"（求导），这必须靠见过 30 附近不同的数才学得准。
- 加了噪声，buffer 里出现 27、29、31、33……world model 把"附近"学准，给大脑指的方向才是对的。
- 论文原话：噪声"只服务于模型拟合，是可选的"（widens the range of actions on which the world model is fit; it serves only the model fit）。
- 用公式类比：world model 要学 `下一位置 = 0.1 × 命令` 里的那个 0.1。只见过一个命令值时，`位置+3`、`0.2×命令−3` 等错误公式也都能完美拟合那一个点；见过多个命令值才能把 0.1 定准。

### Q7. "PPO 的噪声算抗干扰训练吗？"
主要身份是**探索**（在 30 附近找更好的数），证据：PPO 训练后期会自己把噪声越调越小，部署时也不带噪声。"顺带练出一点抗人为抖动的耐受"是**副作用**（因为打分恰好发生在带抖动的运行里）。
两篇论文**真正的抗干扰主力都是域随机化**：每个 episode 随机摩擦、质量、电机增益、延迟、标定偏移、观测噪声等——真机上的干扰主要长这个样子，而不是"每 0.02 秒给命令加独立随机数"。SuperMimic 原版没补"想象里加噪声"这一课也能真机翻跟头，说明在它的设定下这不是瓶颈；执行误差更大的场景（灵巧手、老化电机）里，方式三就值得加。

### Q8. 还澄清过的两个小误会
- "在 world model 里加噪声" ≠ 训练 world model 时加噪声（环节 B 不加任何噪声），指的是**冻结 world model、在想象里调大脑时**给大脑的输出加噪声（环节 C'）。
- 29 个关节是**每一步同时全部输出、全部动**，不是一步动一个；"调大脑"是每段轨迹（32 步）结束后调一次网络参数，不是每步调一次。

## 5. 两个噪声位置的终极对照

| 噪声加在哪 | 环节 | 目的 | 缺了会怎样 |
|---|---|---|---|
| 采数据时（大脑输出 → 仿真器之间） | A | 铺开教材覆盖面，让 world model 学准"命令变一点、结果变多少"——**服务于指方向** | world model 在大脑常说的数附近一片模糊，C 的方向指错，**训练直接跑不动** |
| 想象打分时（大脑输出 → world model 之间） | C'（论文没做） | 让大脑在会抖的世界里被打分——**服务于抗执行误差** | 大脑长成"贴极限"形态，少一层鲁棒性（可由域随机化部分弥补） |

**两个位置、两个完全不同的目的。**

## 附：两篇论文核心公式速查（SuperMimic）

- 采数据（环节 A）：仿真器执行 $a_t + \epsilon_t,\ \epsilon_t \sim \mathcal{N}(0, 0.1^2)$，buffer 存执行过的带噪动作
- world model（环节 B）：$\hat{s}_{t+1} = f_\omega(\hat{s}_t, a_t, \xi)$，8 步自回归，损失
  $\mathcal{L}_{\text{WM}} = \sum_{j=1}^{8}\big[\|\hat{s}_j - s_j\|^2 + (\hat{r}_j - r_j)^2 + \|\hat{\bar{o}}_j - \bar{o}_j\|^2 + \mathrm{BCE}(\hat{d}_j, d_j)\big]$，标签全是仿真器真值
- 调大脑（环节 C）：$a_t = \pi_\theta(\hat{\bar{o}}_t + \eta_t, g_t)$（$\eta$ 是**观测**噪声，不是动作噪声），
  $\hat{J}(\theta) = \mathbb{E}\big[\sum_{t=0}^{H-1}\gamma^t \hat{c}_t \hat{r}_{t+1} + \gamma^H \hat{c}_H V_\psi(\hat{s}_H, g_H, \xi)\big]$，$H=32$，BPTT 穿过冻结的 $f_\omega$ 只更新 $\theta$
- critic（环节 C 内）：$\hat{R}_H = V_H$，$\hat{R}_t = \hat{r}_{t+1} + \gamma(1-\hat{d}_{t+1})[(1-\lambda)V_{t+1} + \lambda\hat{R}_{t+1}]$，只在想象转移上拟合
