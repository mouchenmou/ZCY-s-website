## 3. 方法演进与实际结果

  

### 0）起点：放弃预训练 PPO Actor 的 Warm-start

  

历史路线是官方 PPO Actor + 自训 World Model，通过 BPTT 微调，结果不理想。用户决定改为从零训练公平比较。旧 Candidate B、官方 PPO 模型和历史结果没有删除。

  

后续 scratch 实验的 Actor、WM、Critic 随机初始化，不读取这些历史权重、旧 Expert replay 或旧 normalization statistics。零初始化的 WM 最后一层是零残差先验，不是预训练。

  

历史背景见 `SUPERMIMIC_BACKEND.zh-CN.md`、`SUPERMIMIC_REPLACEMENT_AUDIT.zh-CN.md` 及旧 MBRL 报告；这些不应与新 scratch 结果混算。

  

### 1）从零训练审计、接口修复和 Smoke Test

  

方法：尽量保留原生 SAPG/PPO；独立 SuperMimic-style backend 执行真实采样 → WM 8-step 拟合 → 32-step imagination/BPTT → Critic → 再采样。它是面向 GALATEA 的移植，不是原论文全部细节的逐项复现。

  

发现并处理：收紧课程的 context 原先记在物理步前，而真实奖励/终止使用步后值，造成一次 hard termination disagreement；修为步后记录再验证。增加数值/梯度保护。正式比较前处理 reference clock 和 partial reset：reset 只刷新对应环境，避免别的环境参考帧被提前；保留原生 reset 观测 f+1、奖励 f、步后 progress=f+1 的约定。评估与训练课程/RNG 隔离。

  

实测：PPO 3 epochs、6,912 条训练 transitions、10 次 optimizer step；SM 3 个交替轮、12,288 条训练 transitions、WM30/Actor3/Critic60。两者参数确实更新，保存恢复测试通过，恢复后继续更新；均未学会任务，独立评估均 0/96。工程可恢复不等于精确恢复 PhysX 接触缓存。

  

继承：scratch 防误加载、统一轨迹/时序、原生真实奖励、评估隔离、监控和保存机制。

  

证据：`GALATEA_SUPERMIMIC_SCRATCH_COMPARISON.zh-CN.md`；具体短测目录见该报告。

### 3）拇指退化诊断与奖励审计

  

使用现有 checkpoint/replay 和冻结权重短探针，不进行长期训练。观察到：按原始规则已经拇指越界，学习终止头仍可能给较高存活权重；随机手指屏蔽记忆不是模型显式输入，几何和梯度也有疑点。

  

这些只是不同模块的诊断线索，**尚未完成用户后来澄清要求的 Termination、Critic 两项系统性专项检查，也没有证明它们是唯一根因**。

  

奖励审计确认：当时 Actor 使用 Learned Reward Head；原计划平滑 Lift/Contact/Lift Reward 尚未进入解析 BPTT。预测奖励有误会通过模型产生错误的 Actor 梯度，但必须实际验证，不能只凭真实回报下降推断所有责任都在一个头。

### 4）实现独立 Analytic Differentiable Reward

  

新路径：Actor → WM 下一状态 → 解析平滑奖励 → BPTT。旧 Learned Head、旧 checkpoint 保留。两个同目标分支分别为 head 学习预测 R_smooth 和直接计算同一个 R_smooth；历史 learned-hard 不是同目标对照。

  

实现平滑 Lift Gate、连续 Contact Gate、平滑举升阈值；保留原手/物跟踪、Near 距离奖励（没有新增 progress）、其余完整项，共 12 项：hand/object/lift/power/multi_contact/near/constant/arm_velocity/hand_velocity/arm_action/hand_action/torque。最近表面距离等采用可导近似；不声称硬接触能被精确解析复现。

  

V1 的接触历史尺度 1N 对小接触过弱；随后 V2 将奖励侧接触历史尺度校准为 .02N，适配旧 WM 的历史代理编码，**没有改变 WM 动力学历史更新**。平滑阈值/温度可配置。梯度通过 WM 回到动作，解析分支不读取 Learned scalar reward head，兼容旧 checkpoint。

  

真实样本 R_smooth 对原始奖励平均绝对差 .130385（原均值 4.777373，约 2.73%），均值偏差 -.005603；少量阈值附近误差仍大。样本未覆盖活跃举升高度条件，举升边界只做合成测试。原始奖励诊断复现误差 MAE 5.84e-5。

  

12 项新奖励测试和 9 项旧测试通过；纯初始零残差 WM 的动作物理 Jacobian 可为零，自身真实数据拟合后才非零。

  

短测 V2 每组 12 次 Actor、WM120/Critic240、39,936 训练 transitions，初始真实回报 487.374/长度116.917；learned_smooth 最终123.406/26.771，analytic 最终65.781/13.073，均0/96。解析分支不改善，不能据此宣布奖励替换解决失败；最终先由其他手指终止也不等于拇指已学好。

  

继承：后续使用 **R_smooth_v2 解析分支**；真实 PhysX 仍原奖励。两组共同保持 learned termination，不只给单组修正。

  

证据：`GALATEA_ANALYTIC_REWARD_IMPLEMENTATION.zh-CN.md`；`rl/runs/analytic_reward_smoke_20261103/`、`analytic_reward_v2_smoke_20261103/`。

  

### 5）WM 更新 10/40/100 次消融

  

每轮只改变 WM 更新数，其余一致；每组实际完成 6 次 Actor、Critic120、21,504 训练 transitions。独立 heldout 不参与训练和统计。

  

首次 Actor 前，8-step MSE 为 .15259/.09834/.07854，手指 q 误差 .03389/.02035/.01082 rad：更多拟合有帮助。末期 8-step MSE .10204/.06820/.06810，40→100 收益很小；接触误差没有同步改善。

  

最终真实回报 121.742/87.321/176.894，跟踪25.760/15.531/39.948，全部比初始差，成功0/96。总约475.85秒，峰值12,159MiB。

  

结论：Loss 和部分预测能改善，不等于 Actor 变好。**后续固定 WM40 是为了控制变量，不是认定40最好。**

  

证据：`GALATEA_WM_UPDATE_ABLATION.zh-CN.md`；`rl/runs/wm_update_ablation_20261104/`。

  

### 6）Actor 每轮 1/2/4 次消融

  

固定 WM40、Critic20。每次 Actor 都用最新参数重新生成 rollout 和计算图。原定最多10轮；按共同退化规则三组均在第6轮停止，执行0/3/6评估，第10轮未执行。

  

各组 WM240/Critic120/21,504 训练 transitions，Actor6/12/24。首次单次更新动作均值变化 .054801、最大 .216123，梯度144.24：原来一次更新并不微小。首轮累计净变化 .0548/.1161/.2687；最后 .3785/.6738/.9841。4次组动作饱和比例达86.6%。

### 10）最新：q/qd/FK/PD 时序一致性只读诊断

  

使用既有A800/B800和96条独立PhysX验证轨迹，CPU只读，不训练，不采集，不修改模型/Loss/奖励。检查完整时间序列，不只选第8或16步。

  

已证实：

  

1. 机器人URDF FK约定经真实状态校验：link origin几何误差约微米；误用COM会达约13mm，因此约定可区分。真实手腕局部FK一致性均值约 .00084mm，WM A约6.07mm、B约6.54mm。**模型独立预测的手指角度与指尖坐标并非同一只手的几何关系，第一步就出现。**

2. B第8步通过速度差积分解释的位置响应仅约2.74%，真实约87.59%；B位置响应与速度积分方向相反64/96，第32步75/96。真实相应0/96、6/96。**q响应被放大，但qd没有形成相应运动。**

3. PD目标在撤回后衰减与真实相符；61个全程未屏蔽样本未见选中target误差>1e-4rad。响应q/qd偏差通常在实际指令送达即开始，而不是统一在某个未来步数出现。撤回后B有95/96出现过响应，明显偏差起点中位14、范围5–29，绝非固定第16步。

4. 直接把真实端点qd按 q+=dt*qd 积分，也不能精确还原真实q；控制dt=1/30、仿真1/60、controlInv2、substeps2。真实端点速度不是已验证的区间平均速度，**不能立刻强制Euler关系并宣称物理正确**。

  

合理解释但未隔离证明：独立输出q/qd/指尖允许网络走不一致的捷径；Response Loss能在指定短窗口拟合q，却未约束通用回弹/速度/几何。足以解释既有现象，尚不证明唯一根因或已找到修复。

  

证据：`GALATEA_WM_DYNAMICS_CONSISTENCY_DIAGNOSIS.zh-CN.md`；`rl/runs/wm_kinematic_consistency_20261104/`，其中含 `diagnosis.json`、`diagnostic_tensors.pt`、`timecourse.csv`、`fk_convention.json`、`fk_metadata.json`、`coarse_integration_oracle.json`、`verification.json` 和源码快照。

  

## 4. 改进怎么传给下一阶段

  

不是“每次多加一个Loss直到成功”，也不是“把每个训练好的权重接着训练”。实际分支如下：

  

```text

旧预训练Actor+WM微调（弃用；保留历史）

→ scratch协议/接口/公平评估

├─ 原生PPO正式对照（独立随机初始化，留作参照）

└─ SM learned-hard正式对照（失败）

→ 审计 → learned-smooth vs analytic-smooth（同目标、各从零）

→ 固定analytic R_smooth_v2

├─ WM10/40/100消融（不是累积训练）

├─ WM40下Actor1/2/4消融（不是选中Actor4）

└─ 现有checkpoint动作后果诊断

→ WM-only普通/受控数据对照（新同初始化）

→ 同受控数据 原Loss/ResponseLoss（重新同初始化）

→ 同checkpoint只读q/qd/FK诊断

→ 建议：单因素FK解码（尚未实施）

```

  

真正继承的是：轨迹和公平协议、R_smooth_v2、数据与日志记录、可靠的配对/独立验证方法。失败或有副作用的方案保留为对照，不自动变成默认配置。Termination/Critic一直未在这些单因素实验里同步修改。

  

## 5. 下一步最小方案：只提案，未执行

  

优先候选是把WM的 **keypoint_pos独立预测替换为“预测手腕位姿 + 手指q经FK解码”**：

  

`p_keypoint = p_wrist_pred + R_wrist_pred * FK_hand(q_hand_pred)`。

  

原因：真实FK已经微米级校验；比立即强行 q+=dt*qd 更有依据。这只解决手指位置/角度的几何一致性，不能声称解决q/qd时序、手腕/机械臂动力学、pad_pos和keypoint_vel。训练和rollout都应使用同一解码，不能只后处理旧权重结果。

  

若继续，应做独立A/B，只动这一因素，其他网络动力学、数据、损失、更新数等固定，不训练Actor。不要同时叠加重力课程、Termination、Critic修正或更多固定时刻Loss。

  

通用性验证计划：训练仍用原8步动作数据，测试使用独立物理历史、随机干预起点，持续1/2/3/6/12/16步并复测4步，按实际PD送达/撤回对齐，覆盖无接触/初触/持续接触；看撤回后32–64步、峰值、衰减、q/qd/指尖误差及奖励变化方向。零响应和屏蔽样本单列。FK误差被构造为零本身不是动力学成功证据；需真PhysX误差和奖励方向同时改善。

  

**这只是交接方案，不是新的训练授权。暂停后不要自动执行。**
