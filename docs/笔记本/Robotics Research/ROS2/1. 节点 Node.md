

## 1. 什么是 ROS2？

ROS2（Robot Operating System 2）是一个机器人软件开发框架。

机器人往往需要同时执行很多任务，例如：

- 摄像头采集图像
    
- 使用 YOLO 识别物体
    
- 计算机械臂的运动轨迹
    
- 控制电机运动
    

如果所有功能都写在一个程序中，程序会变得非常复杂。

ROS2 的一种核心设计思想是：**把机器人系统拆分成多个节点（Node），每个节点负责不同的任务，节点之间通过 ROS2 提供的通信机制交换信息。**

## 2. 节点（Node）

### 2.1 Node 的概念

**Node 是 ROS2 中执行特定功能的软件组件。**

例如，一个机器人可以有：

|Node|功能|编程语言|
|---|---|---|
|Camera Node|获取摄像头图像|Python|
|Detection Node|YOLO 识别物体|Python|
|Planning Node|计算运动轨迹|Python / C++|
|Control Node|控制机械臂运动|C++|

ROS2 允许不同节点使用不同编程语言。

常见的 ROS2 客户端库：

- `rclpy`：Python 客户端库
    
- `rclcpp`：C++ 客户端库
    

只要通信接口兼容，Python 节点和 C++ 节点就能交换数据。

**注意：Node 不是机器人本身，也不等于一个线程或进程。它是一个逻辑上的软件功能单元。**

### 2.2 节点之间如何通信？

ROS2 提供了多种通信机制：

- Topic（话题）：发布 / 订阅消息
- Service（服务）：请求 / 响应
- Action（动作）：适合持续较长时间、需要反馈或取消的任务
    

例如：

摄像头节点 → 发布图像 → YOLO 节点 → 发布目标坐标 → 机械臂控制节点

不过本节只学习如何创建 Node，暂时不涉及通信。

## 3. ROS2 Python 节点示例

```
import rclpy
from rclpy.node import Node
import time

def main(args=None):
    rclpy.init(args=args)
    node = Node("node_helloworld")
    while rclpy.ok():
        node.get_logger().info("Hello World")
        time.sleep(0.5)
    node.destroy_node()
    rclpy.shutdown()
```

**程序功能：创建名为** `**node_helloworld**` **的 ROS2 节点，每隔约 0.5 秒输出一次** `**Hello World**`**。**

### 3.1 导入模块

```
import rclpy
from rclpy.node import Node
import time
```

- `rclpy`：ROS2 的 Python 客户端库。
- `Node`：ROS2 提供的节点类。
- `time`：Python 标准库中的时间模块。
    

其中：

```
from rclpy.node import Node
```

表示从 `rclpy` 包中的 `node` 模块导入 `Node` 类。

这里的 `node` 是模块名称，`Node` 是类的名称。
### 3.2 输出 ROS2 日志

```
node.get_logger().info("Hello World")
```

这是 Python 的对象方法调用语法。

可以拆成两行：

```
logger = node.get_logger()
logger.info("Hello World")
```

第一步：

```
node.get_logger()
```

调用 Node 对象的 `get_logger()` 方法，获取 Logger 对象。

第二步：

```
logger.info("Hello World")
```

调用 Logger 对象的 `info()` 方法，输出 INFO 级别的日志。

整体效果类似于：

```
print("Hello World")
```

但 ROS2 Logger 还可以记录时间、日志级别、节点名称等信息。

**语法规律：**

```
object.method()
```

表示调用某个对象的方法。

```
object.method1().method2()
```

表示先调用 `method1()`，然后对其返回的对象调用 `method2()`。

### 3.3 销毁节点

```
node.destroy_node()
```

销毁前面创建的 Node 对象，并清理它所管理的相关 ROS2 资源。

为什么需要销毁？

因为 ROS2 节点可能会创建并管理：

- Publisher
- Subscriber
- Timer
- Service
- 底层通信资源

不再需要节点时，应适当释放这些资源。

`**destroy_node()**` **不会删除 Python 文件，也不会销毁实体机器人。**

对于简单的 Hello World 程序，省略显式销毁通常也不会造成明显问题，但规范地清理资源更适合大型机器人程序。

## 4. ROS2 节点运行：`rclpy.spin()`

```python
#!/usr/bin/env python3
import rclpy
from rclpy.node import Node

def main(args=None):
    rclpy.init(args=args)
    node = Node("py_test")
    node.get_logger().info("Hello world")
    rclpy.spin(node)
    rclpy.shutdown()

if __name__ == "__main__":
    main()
```

#### 1. `rclpy.spin(node)`

`rclpy.spin(node)` 用于让 ROS2 节点持续运行（除非遇到control+c这种停止键），等待并处理 ROS2 事件。

**与 `while` 循环的区别：**

- `while`：反复执行程序员指定的循环体。
- `spin()`：由 ROS2 执行器负责等待事件并执行对应的回调函数。

**注意：** `spin()` 不会自动重复执行前面的代码。因此，上述程序只输出一次 `Hello world`，随后进入 `spin()`，持续等待 ROS2 事件。

#### 2. `if __name__ == "__main__":`

这是 Python 的标准语法，并非 ROS2 特有。

首先，`__name__` 是 Python 自动设置的一个特殊变量，用于表示当前模块的名称。

它的值取决于 Python 文件是如何被使用的。

**情况一：直接运行 Python 文件**

假设文件名为 `node_test.py`，执行：

```bash
python3 node_test.py
```

此时 Python 会设置：

```python
__name__ = "__main__"
```

因此条件成立：

```python
if __name__ == "__main__":
    main()
```

程序就会执行 `main()` 函数。

**情况二：文件被其他 Python 文件导入**

假设在另一个文件中执行：

```python
import node_test
```

此时 `node_test.py` 中的：

```python
__name__ = "node_test"
```

因此：

```python
if __name__ == "__main__":
    main()
```

条件不成立，`main()` 不会自动执行。

**为什么需要这样写？**

因为我们希望同一个 Python 文件既可以：

- 作为独立程序运行，自动调用 `main()`。
- 作为模块被其他程序导入，而不自动执行 `main()`。

**总结：**

```python
if __name__ == "__main__":
    main()
```

表示：**只有当前 Python 文件被直接运行时，才执行 `main()` 函数。**

它相当于给程序设置了一个入口（Entry Point）。

## 5. ROS2 Python 功能包：setup.py 与 console_scripts

![](附件/Pasted%20image%2020261027003352.png)

#### 1. ROS2 Python 功能包的目录结构

```text
src/
└── my_py_pkg/                  # 外层：ROS2 功能包目录
    ├── package.xml             # ROS2 功能包信息
    ├── setup.py                # Python 包安装及可执行程序配置
    ├── setup.cfg
    ├── resource/
    ├── test/
    │
    └── my_py_pkg/              # 内层：Python 包目录
        ├── __init__.py
        └── my_first_node.py    # Python 节点程序
```

这里有两个同名的 `my_py_pkg`，但它们的作用不同：

- **外层 `my_py_pkg`**：ROS2 功能包的项目目录，包含 `setup.py`、`package.xml` 等配置文件。
- **内层 `my_py_pkg`**：Python 包目录，存放真正的 Python 程序。

两个目录通常使用相同的名字，但并不是必须相同。

#### 2. setup.py 中的 console_scripts

在 `setup.py` 中：

```python
entry_points={
    'console_scripts': [
        'py_node = my_py_pkg.my_first_node:main',
    ],
},
```

其中最重要的是：

```python
'py_node = my_py_pkg.my_first_node:main'
```

它的格式为：

```text
'可执行命令名 = Python包名.Python文件名:函数名'
```

逐个解释：

| 部分 | 含义 |
|---|---|
| `py_node` | 自定义的可执行命令名称 |
| `my_py_pkg` | 内层 Python 包的名称 |
| `my_first_node` | Python 文件 `my_first_node.py` |
| `main` | 文件中定义的 `main()` 函数 |

因此，这一行的意思是：

**把 `py_node` 注册为一个可执行命令，运行它时调用 `my_py_pkg/my_first_node.py` 中的 `main()` 函数。**

这里使用的是 Python 模块导入路径，而不是从 `src` 开始的完整文件路径，因此不需要写两次 `my_py_pkg`。

#### 3. 如何通过 ROS2 运行节点？

完成构建、安装并加载对应的 ROS2 环境后，可以使用：

```bash
ros2 run my_py_pkg py_node
```

其格式为：

```bash
ros2 run <ROS2功能包名> <可执行命令名>
```

其中：

- `ros2 run`：ROS2 用于启动可执行程序的命令。
- `my_py_pkg`：ROS2 功能包名，对应外层的功能包。
- `py_node`：在 `setup.py` 的 `console_scripts` 中注册的可执行命令名称。

执行过程：

```text
ros2 run my_py_pkg py_node
              │        │
              │        └── 找到注册的 py_node 命令
              │
              └── 找到 ROS2 功能包 my_py_pkg
                           │
                           ▼
                  查看已安装的可执行入口
                           │
                           ▼
              my_py_pkg.my_first_node:main
                           │
                           ▼
                  执行 main() 函数
```

#### 4. 两个 my_py_pkg 的区别

需要特别区分下面两种情况。

**情况一：终端命令**

```bash
ros2 run my_py_pkg py_node
```

这里的 `my_py_pkg` 是 **ROS2 功能包名**，对应外层功能包。

**情况二：setup.py**

```python
'py_node = my_py_pkg.my_first_node:main'
```

这里的 `my_py_pkg` 是 **Python 包名**，对应内层 Python 包。

虽然名字相同，但含义不同。

#### 5. 可执行命令名与节点名的区别

假设 `my_first_node.py` 中写的是：

```python
node = Node("hello_robot")
```

而 `setup.py` 中写的是：

```python
'py_node = my_py_pkg.my_first_node:main'
```

那么运行：

```bash
ros2 run my_py_pkg py_node
```

其中：

- `my_py_pkg`：ROS2 功能包名称。
- `py_node`：可执行命令名称。
- `hello_robot`：程序创建的 ROS2 节点名称。

**可执行命令名称不等于 ROS2 节点名称。**

#### 总结

记住两种格式：

**1. 在 setup.py 中注册可执行命令**

```python
'命令名 = Python包名.Python文件名:函数名'
```

**2. 在终端运行程序**

```bash
ros2 run ROS2功能包名 命令名
```

`setup.py` 负责告诉系统应该运行哪个 Python 函数，`ros2 run` 则负责启动已安装的可执行程序。
